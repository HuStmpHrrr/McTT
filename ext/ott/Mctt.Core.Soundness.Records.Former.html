The Type Former of a Record in the Gluing Model

A record found in a well-formed global context is typed there, so valid in the PER model (record_model_at); Core/Completeness/Records/Model.v then gives the values of its type former and its fields' types. At a declaration whose judgments are glued (glu_record_decl), the type former at glued parameters is glued at the sort (record_former_base), and the type former is glued at its type (glu_rel_exp_record0); the fields over the parameters are a context glued with its types (record_fctx_glued). The projections and the tuples are in Records/Model.v.

A Record of a Well-Formed Global Context

A record found in a well-formed global context is valid there in the PER model: it is typed where it is found, and the identity embedding is sound.
Lemma record_model_at : forall p R, ⊢ᵍ gc_deps ⍮ gc_stack -> record_lookup gc_deps gc_stack p = Some R ->
    record_model p R.
Proof.
  intros * Hg Hl.
  pose proof (record_model_of_embedding _ _ _ _ _ _ (valid_gctx_embedding_refl _ _ Hg) Hl) as H.
  destruct GC; exact H.
Qed.

Record glu_typ_value_at (u : universe_index) (Δ : ctx) (A : typ) (σ : sub) (ρ : env) (a : domain) : Prop := mk_glu_typ_value_at
  {
A evaluates to a at ρ

  ; glu_typ_value_at_per : Dom a ≈ a ∈ per_univ u

  ; glu_typ_value_at_glu : forall P El, DG a ∈ glu_univ_elem u ↘ P ↘ El -> Δ ⊢ A[σ] ® P }.
