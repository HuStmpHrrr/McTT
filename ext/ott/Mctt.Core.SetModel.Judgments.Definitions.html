The Set Judgments

The judgments of the set model, at a universe tower T and a valuation γ of the global context. Environments of a context are related (set_env_rel) when their entries are equal and of the entries' types, definitions and units; a term denotes a function of the environment (set_denotes) when that function is its value at every environment of the context and every value of it at a related environment equals the function's. Existence and uniqueness are thus proved together, by the fundamental theorem, for well-formed terms only.
The judgments then follow the syntactic ones: equal terms of a type denote one function into the type's carriers (set_rel_exp_eq), a subtype has the smaller carriers (set_rel_subtyp), equal extensions relate the same environments (set_ext_eq_with), equal module expressions and units denote one module and are valid (set_rel_modexp_eq, set_rel_unit_eq): what they are built of denotes, so that their members are of their types.
Those are read at one global context. The valuations that model a global context come next (set_gctx_ok), then what it is for one to model a context at a bigger one (set_gctx_embedding), and last the judgments the fundamental theorem concludes (set_exp_eq and the rest), each its one-context judgment read at every context its own is modelled at, as the gluing model's are.

set_assumption_with Γ ρ κ A e e' x x' a: the entries e and e' of an assumption of A of the kind κ are equal values x and x' of A's value a.
Record set_assumption_with (Γ : ctx) (ρ : set_env) (κ : abs_kind) (A : exp) (e e' : set_entry) (x x' a : aczel_set) : Prop :=
  {
The left entry is the term x
    set_assumption_left : e = set_entry_term κ x
    
The right entry is the term x'
  ; set_assumption_right : e' = set_entry_term κ x'
    
A denotes a
  ; set_assumption_type : set_interp T γ Γ ρ A a
    
x is of a
  ; set_assumption_mem : set_mem x (code_carrier a)
    
The two are equal
  ; set_assumption_eq : set_eq x x' }.

set_definition_with Γ ρ M r e e' v v' w: the entries e and e' of a definition of M are values v and v' of the tag r, equal to M's value w. The tag is any: the interpretation reads only the values, and a body stores each definition at its own tag (set_interp_ge_def), which body_ctx does not keep. In module M where def p : ⊤ ≔ tt; def q : ⊤ ≔ p end, p's entry is a proof's, and q is read at it as at a definition of body_ctx.
Record set_definition_with (Γ : ctx) (ρ : set_env) (M : exp) (r : abs_kind) (e e' : set_entry) (v v' w : aczel_set) : Prop :=
  {
The left entry is the term v
    set_definition_left : e = set_entry_term r v
    
The right entry is the term v'
  ; set_definition_right : e' = set_entry_term r v'
    
M denotes w
  ; set_definition_value : set_interp T γ Γ ρ M w
    
v is w
  ; set_definition_left_eq : set_eq v w
    
v' is w
  ; set_definition_right_eq : set_eq v' w }.

set_entry_rel Γ ρ ce e e': e and e' are related entries of the context entry ce of Γ, at ρ.
Definition set_entry_rel (Γ : ctx) (ρ : set_env) (ce : centry) (e e' : set_entry) : Prop :=
  match ce with
  | ce_ass κ A => exists x x' a, set_assumption_with Γ ρ κ A e e' x x' a
  | ce_def _ M => exists r v v' w, set_definition_with Γ ρ M r e e' v v' w
  | ce_mod U => exists m m' n, set_module_slot_with Γ ρ U e e' m m' n
  | ce_dm _ M U => exists v v' w m m' n, set_definition_module_with Γ ρ M U e e' v v' w m m' n
  end.

set_env_rel Γ ρ ρ': ρ and ρ' are related environments of Γ; below the context their entries are equal, as a term read past its context would read them.
Fixpoint set_env_rel (Γ : ctx) (ρ ρ' : set_env) : Prop :=
  match Γ with
  | nil => set_env_eq γ ρ ρ'
  | ce :: Γ' => set_env_rel Γ' (set_env_tail ρ) (set_env_tail ρ') /\ set_entry_rel Γ' (set_env_tail ρ) ce (ρ 0) (ρ' 0)
  end.

ρ is an environment of Γ.
Definition set_env_in (Γ : ctx) (ρ : set_env) : Prop := set_env_rel Γ ρ ρ.

Denotations

set_denotes Γ M F: M denotes F in Γ.
Record set_denotes (Γ : ctx) (M : exp) (F : set_env -> aczel_set) : Prop :=
  {
F ρ is M's value at every environment
    set_denotes_exists : forall ρ, set_env_in Γ ρ -> set_interp T γ Γ ρ M (F ρ)
    
Every value of M at a related environment is F's
  ; set_denotes_unique : forall ρ ρ' v, set_env_rel Γ ρ ρ' -> set_interp T γ Γ ρ' M v -> set_eq v (F ρ) }.

set_modexp_denotes Γ H F: the module expression H denotes F in Γ.
Record set_modexp_denotes (Γ : ctx) (H : modexp) (F : set_env -> set_module) : Prop :=
  {
F ρ is H's module at every environment
    set_modexp_denotes_exists : forall ρ, set_env_in Γ ρ -> set_interp_modexp T γ Γ ρ H (F ρ)
    
Every module of H at a related environment is F's
  ; set_modexp_denotes_unique : forall ρ ρ' m, set_env_rel Γ ρ ρ' -> set_interp_modexp T γ Γ ρ' H m -> set_module_eq γ m (F ρ) }.

set_member_known Θ1 Ξ1 Γ H x: x is a member of H's module part here that the context Θ1 ⍮ Ξ1 this one grew from already has (set_member_at). It is read off the module part, not off H, as H and the unit it is equal to share their module part (set_modexp_valid_with): for H = A.B with A ≔ C, the unit is C.B, of which the smaller context need know nothing.
Definition set_member_known (Θ1 : gdeps) (Ξ1 : gstack) (Γ : ctx) (H : modexp) (x : string) : Prop :=
  forall R0 R0m, mdenote gc_deps gc_stack Γ H R0 -> mdesc_mod R0 = Some R0m -> set_member_at Θ1 Ξ1 gc_deps gc_stack R0m x.

set_members_valid Θ1 Ξ1 Γ H F: every term member of H that the context Θ1 ⍮ Ξ1 already has, of F's modules, is of its type, and is its δ-reduct when it has one. A member of a submodule is one of the submodule's, valid in its turn.
Definition set_members_valid (Θ1 : gdeps) (Ξ1 : gstack) (Γ : ctx) (H : modexp) (F : set_env -> set_module) : Prop :=
  forall x R A FA, set_member_known Θ1 Ξ1 Γ H x -> mdenote gc_deps gc_stack Γ (me_mem H x) R -> mdesc_type R = Some A ->
    set_denotes Γ A FA -> forall ρ, set_env_in Γ ρ ->
    set_mem (select_term γ (F ρ) x) (code_carrier (FA ρ)) /\
    (forall N FN, mdesc_reduct R = Some N -> set_denotes Γ N FN -> set_eq (select_term γ (F ρ) x) (FN ρ)).

The Judgments

set_exp_eq_with Γ A M M' FA FM FM': A denotes FA, M and M' the equal FM and FM', of FA's carriers. The two are equal, not the same function: a denotation is a term's exact value, and equal terms such as (λ A M) N and M[N] have equal values, not the same.
Record set_exp_eq_with (Γ : ctx) (A M M' : exp) (FA FM FM' : set_env -> aczel_set) : Prop :=
  {
The type's denotation
    set_exp_eq_type : set_denotes Γ A FA
    
The left term's
  ; set_exp_eq_left : set_denotes Γ M FM
    
The right term's
  ; set_exp_eq_right : set_denotes Γ M' FM'
    
The two are equal
  ; set_exp_eq_eq : forall ρ, set_env_in Γ ρ -> set_eq (FM ρ) (FM' ρ)
    
Of the type
  ; set_exp_eq_mem : forall ρ, set_env_in Γ ρ -> set_mem (FM ρ) (code_carrier (FA ρ)) }.

M and M' are equal terms of the type A in Γ, at this one global context: the building block of set_exp_eq.
Definition set_rel_exp_eq (Γ : ctx) (A M M' : exp) : Prop := exists FA FM FM', set_exp_eq_with Γ A M M' FA FM FM'.

set_subtyp_with Γ A A' FA FA': A and A' denote FA and FA', the first's carriers in the second's.
Record set_subtyp_with (Γ : ctx) (A A' : exp) (FA FA' : set_env -> aczel_set) : Prop :=
  {
The subtype's denotation
    set_subtyp_left : set_denotes Γ A FA
    
The supertype's
  ; set_subtyp_right : set_denotes Γ A' FA'
    
The subtype's carriers are in the supertype's
  ; set_subtyp_sub : forall ρ, set_env_in Γ ρ -> set_sub (code_carrier (FA ρ)) (code_carrier (FA' ρ)) }.

A is a subtype of A' in Γ, at this one global context: the building block of set_subtyp.
Definition set_rel_subtyp (Γ : ctx) (A A' : exp) : Prop := exists FA FA', set_subtyp_with Γ A A' FA FA'.

set_modexp_rel_with Γ H H' F F': H and H' denote the equal F and F' in Γ.
Record set_modexp_rel_with (Γ : ctx) (H H' : modexp) (F F' : set_env -> set_module) : Prop :=
  {
The left expression's denotation
    set_modexp_rel_left : set_modexp_denotes Γ H F
    
The right expression's
  ; set_modexp_rel_right : set_modexp_denotes Γ H' F'
    
The two are equal
  ; set_modexp_rel_eq : forall ρ, set_env_in Γ ρ -> set_module_eq γ (F ρ) (F' ρ) }.

H and H' denote equal modules in Γ.
Definition set_modexp_rel (Γ : ctx) (H H' : modexp) : Prop := exists F F', set_modexp_rel_with Γ H H' F F'.

set_entry_valid Γ ce: the context entry ce is valid in Γ: its type, definition or unit denotes. A slot's unit is valid besides (set_valid_slots).
Definition set_entry_valid (Γ : ctx) (ce : centry) : Prop :=
  match ce with
  | ce_ass _ A => exists FA, set_denotes Γ A FA
  | ce_def A M => set_rel_exp_eq Γ A M M
  | ce_mod U => set_modexp_rel Γ (me_lit U) (me_lit U)
  | ce_dm A M U => set_rel_exp_eq Γ A M M /\ set_modexp_rel Γ (me_lit U) (me_lit U)
  end.

set_ctx Γ: every entry of Γ is valid in the context before it.
Fixpoint set_ctx (Γ : ctx) : Prop :=
  match Γ with
  | nil => True
  | ce :: Γ' => set_ctx Γ' /\ set_entry_valid Γ' ce
  end.

Valid Units and Module Expressions

A unit is valid when its parts are: a filed module at arguments valid against its telescope; a local body whose context denotes, whose submodules are valid units in the context the body before each makes, and whose opens' targets are valid; an alias whose target is. A module expression is valid when it denotes a module equal to a valid unit's of the same module part. The members of a valid module expression are of their types (set_members_valid).
set_args_valid Γ T Tr Tf Ns: the arguments Ns fill the outermost parameters Tf of the closed telescope T = Tr ++ Tf, each of its parameter's type, instantiated by the arguments before it, of an evaluated sort.
Record set_args_valid (Γ T Tr Tf : ctx) (Ns : list exp) : Prop :=
  {
The telescope splits at the arguments
    set_args_split : T = Tr ++ Tf
    
One argument per filled parameter
  ; set_args_length : List.length Tf = List.length Ns
    
The filled parameters are assumptions
  ; set_args_assumptions : all_assumptions Tf
    
They are closed
  ; set_args_scoped : ctx_scoped 0 Tf
    
Each argument is of its type
  ; set_args_typed : forall k N A, nth_error Ns k = Some N -> nth_error (tele_insts Tf sb_id Ns) k = Some A ->
      set_rel_exp_eq Γ A N N
    
Each type is of an evaluated sort
  ; set_args_evaluated : forall k A, nth_error (tele_insts Tf sb_id Ns) k = Some A ->
      exists Srt, evaluated_sort Srt /\ set_rel_exp_eq Γ Srt A A }.

set_params_evaluated Γ Δ l: each parameter of Δ is a type of the universe at l or a type of levels, in the context after it.
Definition set_params_evaluated (Γ Δ : ctx) (l : nat) : Prop :=
  forall Δ1 κ A Δ2, Δ = Δ1 ++ ce_ass κ A :: Δ2 ->
    set_rel_exp_eq (Δ2 ++ Γ) (a_typ l) A A \/ set_rel_exp_eq (Δ2 ++ Γ) a_level_sort A A.

set_body_sorts_valid Φ D: each term part of the body Φ over D, filled in, is of the sort its kind tag says, in D: the typing of a body unit types its definitions filled in.
Fixpoint set_body_sorts_valid (Φ : gmod) (D : ctx) : Prop :=
  match Φ with
  | gm_nil => True
  | gm_ext Φ0 _ E =>
      set_body_sorts_valid Φ0 D /\
      forall A M σ, entry_tm E = Some (A, M) -> gm_fill Φ0 = Some σ ->
        exists i, set_rel_exp_eq D (abs_kind_sort (entry_kind E) (a_typ i)) (exp_sub A σ) (exp_sub A σ)
  (* read on expansions only, which have no open *)
  | gm_open Φ0 _ _ _ => set_body_sorts_valid Φ0 D
  end.

set_slots_coherent Γ κs: κs gives each slot of Γ the proofness of its unit, read past the slot. An environment of Γ gives such slots (env_slot_proofs); so do slots pushed past assumptions, at which no environment need exist.
Fixpoint set_slots_coherent (Γ : ctx) (κs : nat -> member_proofness) : Prop :=
  match Γ with
  | nil => True
  | ce :: Γ' =>
      set_slots_coherent Γ' (fun s => κs (S s)) /\
      forall U, centry_unit ce = Some U -> forall ys x, κs 0 ys x = unit_member_proofs γ (fun s => κs (S s)) U ys x
  end.

set_modexp_valid_with Γ H K R Rm RK: H, well formed and denoting R of the module part Rm, is equal to K, which denotes RK of the same module part, and has K's proofness.
Record set_modexp_valid_with (Γ : ctx) (H K : modexp) (R Rm RK : mdesc) : Prop :=
  {
H is well formed
    set_modexp_valid_wf : gc_deps ⍮ gc_stack ⍮ Γ ⊢ᵐ H ≈ H
    
It denotes R
  ; set_modexp_valid_desc : mdenote gc_deps gc_stack Γ H R
    
Of the module part Rm
  ; set_modexp_valid_mod : mdesc_mod R = Some Rm
    
Its module is K's
  ; set_modexp_valid_rel : set_modexp_rel Γ H K
    
K denotes RK
  ; set_modexp_valid_unit_desc : mdenote gc_deps gc_stack Γ K RK
    
Of the same module part
  ; set_modexp_valid_unit_mod : mdesc_mod RK = Some Rm
    
Its members are proofs where K's are, read off the syntax at slots coherent with Γ, not at environments: in module N where def k : ℕ ≔ 0 end and module M (n : ℕ) (z : Empty) ≔ N, M.k is the function n ↦ ∅ of Π ℕ (Π Empty ℕ) only if N's proofness says k is no proof, and N is read in z : Empty, n : ℕ, which has no environment: there N's equality to K says nothing
  ; set_modexp_valid_proofs : forall κs, set_slots_coherent Γ κs -> forall ys x,
      modexp_member_proofs γ κs H ys x = modexp_member_proofs γ κs K ys x }.

set_valid_unit Γ K: the unit K is valid in Γ.
Inductive set_valid_unit : ctx -> modexp -> Prop :=
A filed module at valid arguments
| set_valid_unit_filed : forall Γ p T Φ Tr Tf Ns,
    gc_deps ⍮ gc_stack ⍮ Γ ⊢ᵐ me_apps (qname_mod p) Ns ≈ me_apps (qname_mod p) Ns ->
    gc_loc gc_deps gc_stack p = Some (T, Φ) -> set_ctx Γ -> set_args_valid Γ T Tr Tf Ns ->
    set_valid_unit Γ (me_apps (qname_mod p) Ns)
A local body: its parts denote, its submodules are valid units in the context the body before each makes, and its opens' targets are valid
| set_valid_unit_body : forall Γ Δ Φ Φx, set_body_ok Γ Δ Φ Φx ->
    (forall y Φ0 E U, gm_prefix_upto Φx y = Some (gm_ext Φ0 y E) -> entry_unit E = Some U ->

Valuations That Model a Global Context

A valuation models the global context (set_gctx_ok) when what it gives each global is what the global's stored description denotes:
  • a filed module or frame reads its global module at its path, over a denoting closed telescope; a term member of it has its stored kind, is the empty set at a proof, and, applied to an environment of an outer part of the telescope, is of the Π over the rest and is its reduct's value (set_filed_mod, set_filed_term_with);

  • a group of inductive types has the parameter and argument types its declaration's telescopes denote, the carriers of Carriers, type formers and constructors of their closed types and values, and a view the carriers of what it views (set_group_ok);
  • a record type has the parameter and field types its declaration denotes, the tuples of its fields as elements, and a type former of its closed type and value (set_record_ok).
A type read off the values of a telescope is a function of those values (set_reads, set_tele_types), the value of the type at every environment of the telescope.

Modelling a Context Where It Grows

A valuation models a global context at a bigger one (set_gctx_embedding) when everything the smaller context resolves is modelled there. One valuation serves the whole growth, as in the gluing model (glu_gctx_embedding): the context grows, the valuation does not. set_gctx_ok is the instance where the two contexts are the same (set_gctx_embedding_refl).
