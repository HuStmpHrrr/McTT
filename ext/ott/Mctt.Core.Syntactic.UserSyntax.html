Mctt.Core.Syntactic.UserSyntax

The User Syntax

The syntax after name resolution (level-1 elaboration), before the typed pass (level-2 elaboration, TypedElab) fills it into the core syntax (Syntax). It holds what a user writes and nothing else: names are resolved to de Bruijn indices and paths, but no relevance tag, no eliminator group, no inferred annotation is present. Where a user may omit an annotation the syntax has a hole (surface_hole), which the typed pass fills; a term followed by a field name (surface_proj_term) is resolved there too, once the term's type is known.
The core syntax keeps every annotation explicit; the typed pass maps each user term to exactly one core term.
