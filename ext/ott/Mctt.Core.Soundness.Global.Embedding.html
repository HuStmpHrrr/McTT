Mctt.Core.Soundness.Global.Embedding

Glued Global Contexts

The soundness counterpart of Core/Completeness/Global/Embedding.v: what an entry of a global context is worth at a target (glu_entry, glu_mod_tele, glu_ind_decl_entry), and the sound embedding that the validity of every entry gives (glu_gctx_embedding_of, glu_gctx_embedding_of_bodies_valid). The validity of an entry is that the type of a definition glues; a stored axiom or abstract definition then glues as the neutral of its path. Nothing here uses the fundamental theorem; that each entry is valid where it is checked, and so that a well-formed global context embeds soundly into itself, is proved with it in FundamentalTheorem.v.

1. A stored axiom or abstract definition is a neutral

A global is a neutral annotated with its type evaluated at nil. Since nil_glu_sub_pred leaves the environment free, the ⋅-judgment can be instantiated at nil, where the type glues at the neutral's annotation. The member's value applies as the neutral does (app_sim): it is the neutral at a saturated module, and a member closure at one lacking a parameter (glob_member_sim), glued as the neutral is (app_sim_glu); its gluing at the type's value in the given environment is then the move along the type values with the type's gluing there as the witness (glu_univ_elem_exp_conv).

2. Valid entries make a sound embedding

A definition A ≔ oM of the kind r, stored over the telescope T, at Θ2 ⍮ Ξ2: closed, as it is stored, and over T, as it was checked.
Record glu_stored_def (Θ2 : gdeps) (Ξ2 : gstack) (T : ctx) (r : abs_kind) (A : typ) (oM : option exp) : Prop :=
  mk_glu_stored_def
  {
The type glues, in the empty context, at the sort of its kind (abs_kind_sort)
    glu_stored_def_type : exists i, @glu_rel_exp (gc_mk Θ2 Ξ2) ⋅ A (abs_kind_sort r Typeω@i)
    
The body, if any, glues there at the type: the value a member with a δ-reduct is read off is the body's (eval_sel_global)
  ; glu_stored_def_body : forall M, oM = Some M -> @glu_rel_exp (gc_mk Θ2 Ξ2) ⋅ M A
    
Both glue over the telescope, before they are closed over it (glu_def_over_tele)
  ; glu_stored_def_tele : exists A0 (i : nat), glu_def_over_tele Θ2 Ξ2 T r A oM A0 i }.

What an entry filed over the telescope T is worth at Θ2 ⍮ Ξ2: a definition is glued as stored (glu_stored_def); an alias, filed closed with its full telescope, is a deep unit over no context (glu_unit_deep), so its literal is glued there as a global alias submodule is selected (eval_selm_global_alias, glu_alias_modexp_of_deep), and what it denotes is deep (glu_desc_deep_of_source). A definition with a module part is valid as its two views, a definition and an alias (ge_valid).
Definition glu_entry (_ : gdeps) (_ : gstack) (Θ2 : gdeps) (Ξ2 : gstack) (T : ctx) (E : gentry) : Prop :=
  match E with
  | ge_def _ _ r A oM => glu_stored_def Θ2 Ξ2 T r A oM
  | ge_mod _ (gu_mk Δ (md_alias E')) => @glu_unit_deep (gc_mk Θ2 Ξ2) ⋅ (gu_mk Δ (md_alias E'))
  | _ => True
  end.

The telescope of a stored module is a context glued with its types at Θ2 ⍮ Ξ2: the types of the parameters a global module value lacks.
Definition glu_mod_tele (Θ2 : gdeps) (Ξ2 : gstack) (T : ctx) : Prop := @glu_rel_ctx_types (gc_mk Θ2 Ξ2) T.
