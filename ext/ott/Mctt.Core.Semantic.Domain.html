The Semantic Domain

An environment is the list of the values of the variables in scope, indexed by de Bruijn index; for Θ ⍮ Ξ ⍮ Γ these are the variables of Γ. A term variable holds a term value and a module slot a module value (dentry). The global context does not change during NbE, so it is not part of the environment; evaluation takes it as a separate argument. Module parameters are λ-variables and so live in the environment.
Module values are their own sort (dmod), closures like λ:
  • dm_global p args: the global body module at p, applied to args, outermost first;
  • dm_local Δ D ρ, ⟨Δ ⊢ D, ρ⟩: the definition D of a unit, a body or an alias, over the environment ρ, Δ the parameters it still lacks: an application pushes the argument onto ρ and drops the outermost parameter of Δ. The value is saturated when Δ is empty; a saturated alias is never a value, it is its target's value;
  • dm_member m ch: the submodule at the chain ch of a local module m still lacking arguments.
d_member m ch is the term member at the chain ch of such a module: the semantic λ of a member of a module that is not yet applied to all its parameters.
The atoms of a flat level and the fields of a record value are lists of tuples; list, prod and option have All schemes registered (Core.Base), so domain_ind carries the hypotheses about the values they hold.

The entry past the end of an environment: the value env_var gives a variable no entry binds, at no type (entry_type_none). Never read by a well-scoped term; only for totality of the read.
Definition absent_entry : dentry := de_term d_prop entry_type_none.

The entry of the variable #x, or absent_entry past the end of the list. env_entry is nth, but defined by recursion on the index so that ρ↯ x is ρ (S x) by conversion.
Fixpoint env_entry (ρ : env) (x : nat) : dentry :=
  match x with
  | 0 => List.hd absent_entry ρ
  | S x' => env_entry (List.tl ρ) x'
  end.

The value of the variable #x as a term, and as a module. A well-typed term only reads variables of its sort in its context, so it never sees the values an entry of the other sort gives, which are the values of the closed terms of sentry_exp and sentry_modexp. As a coercion, env_var lets an environment be applied as a function, ρ x.
Definition env_var (ρ : env) (x : nat) : domain :=
  match env_entry ρ x with
  | de_term d _ => d
  
never a user value: the value Propᵈ of the term Propₘ a module entry gives a term variable (sentry_exp), only for totality of the read
  | de_mod _ _ => d_prop
  | de_dm d _ _ _ => d
  end.
#[warning="-uniform-inheritance"]
Coercion env_var : list >-> Funclass.

The type the entry of #x is stored at.
Definition env_type (ρ : env) (x : nat) : entry_type :=
  match env_entry ρ x with
  | de_term _ t => t
  | de_mod _ _ => entry_type_none
  | de_dm _ t _ _ => t
  end.

Definition env_mod (ρ : env) (x : nat) : dmod :=
  match env_entry ρ x with
  | de_mod m _ => m
  
never a user value: a term entry read as a module, only for totality of the read; the empty global module
  | de_term _ _ => dm_global (q_abs nil nil) nil
  | de_dm _ _ m _ => m
  end.

Lemma env_entry_nth : forall ρ x, env_entry ρ x = List.nth x ρ absent_entry.
Proof. intros ρ x; revert ρ; induction x; intros [| d ρ]; cbn; auto; rewrite IHx; destruct x; reflexivity. Qed.

Lemma env_var_nth : forall ρ x,
    env_var ρ x = match List.nth x ρ absent_entry with de_term d _ | de_dm d _ _ _ => d | de_mod _ _ => d_prop end.
Proof. intros; unfold env_var; rewrite env_entry_nth; reflexivity. Qed.

The environment extended by a value d of the type t.
Definition extend_env (ρ : env) (d : domain) (t : entry_type) : env := de_term d t :: ρ.
Arguments extend_env _ _ _ /.

The environment extended by a module value m of the declared unit U, written over ρ.
Definition extend_env_mod (ρ : env) (m : dmod) (U : gunit) : env := de_mod m U :: ρ.
Arguments extend_env_mod _ _ _ /.

The environment extended by a definition with a module part, its unit U written over ρ.
Definition extend_env_dm (ρ : env) (d : domain) (t : entry_type) (m : dmod) (U : gunit) : env := de_dm d t m U :: ρ.
Arguments extend_env_dm _ _ _ _ _ /.

env_extend_typed ρ vts: the environment ρ extended by the values of vts, each at the type paired with it, outermost first.
Definition env_extend_typed (ρ : env) (vts : list (domain * entry_type)) : env :=
  List.fold_left (fun ρ vt => extend_env ρ (fst vt) (snd vt)) vts ρ.

Lemma env_extend_typed_app : forall ρ vs ws, env_extend_typed ρ (vs ++ ws) = env_extend_typed (env_extend_typed ρ vs) ws.
Proof. intros; unfold env_extend_typed; rewrite List.fold_left_app; reflexivity. Qed.

The type an entry of a telescope gives its term variable; a module slot binds no term variable.
Definition centry_type (e : centry) : option exp :=
  match e with
  | ce_ass _ A | ce_def A _ | ce_dm A _ _ => Some A
  | ce_mod _ => None
  end.

The type the head of a telescope gives a variable over ρ: none at a module slot and past its end.
Definition tele_head_type (ρ : env) (T : list centry) : entry_type :=
  match T with
  | e :: _ => match centry_type e with Some A => entry_type_closure A ρ | None => entry_type_none end
  | nil => entry_type_none
  end.

The values vs at the telescope T, outermost first, with their types: each the type its entry gives, as a closure in ρ extended by the values before it. Every value is kept: one past the end of T is at no type.
Fixpoint tele_entries (ρ : env) (T : list centry) (vs : list domain) : list (domain * entry_type) :=
  match vs with
  | nil => nil
  | v :: vs' => (v, tele_head_type ρ T) :: tele_entries (extend_env ρ v (tele_head_type ρ T)) (List.tl T) vs'
  end.

The values of a telescope's entries are the values given.
Lemma tele_entries_values : forall vs ρ T, List.map fst (tele_entries ρ T vs) = vs.
Proof. induction vs as [| v vs IH]; intros ρ T; cbn; [ reflexivity | f_equal; apply IH ]. Qed.

The environment ρ extended by the values vs at the telescope T, outermost first, as a unit's parameters are: the types are closures in the environment extended so far.
Definition env_tele (ρ : env) (T : list centry) (vs : list domain) : env := env_extend_typed ρ (tele_entries ρ T vs).

A telescope's entries read only as many of its types as there are values.
Lemma tele_entries_firstn : forall vs T ρ, tele_entries ρ T vs = tele_entries ρ (List.firstn (List.length vs) T) vs.
Proof.
  induction vs as [| v vs IH]; intros [| e T] ρ; cbn [tele_entries List.length List.firstn]; try reflexivity;
    f_equal; apply IH.
Qed.

Lemma env_tele_firstn : forall ρ T vs, env_tele ρ T vs = env_tele ρ (List.firstn (List.length vs) T) vs.
Proof. intros; unfold env_tele; rewrite tele_entries_firstn; reflexivity. Qed.

Two telescopes one after the other, the first one's values all given.
Lemma tele_entries_app : forall T1 T2 vs1 vs2 ρ, List.length vs1 = List.length T1 ->
    tele_entries ρ (T1 ++ T2) (vs1 ++ vs2) = tele_entries ρ T1 vs1 ++ tele_entries (env_tele ρ T1 vs1) T2 vs2.
Proof.
  induction T1 as [| e T1 IH]; intros T2 [| v vs1] vs2 ρ Hl; cbn in Hl; try discriminate; [ reflexivity |].
  cbn [List.app tele_entries tele_head_type List.tl]; f_equal.
  injection Hl as Hl; rewrite (IH _ _ _ _ Hl); reflexivity.
Qed.

Lemma env_tele_app : forall ρ T1 T2 vs1 vs2, List.length vs1 = List.length T1 ->
    env_tele ρ (T1 ++ T2) (vs1 ++ vs2) = env_tele (env_tele ρ T1 vs1) T2 vs2.
Proof. intros * Hl; unfold env_tele at 1; rewrite tele_entries_app, env_extend_typed_app by exact Hl; reflexivity. Qed.

One more value, at the closure of its type.
Lemma env_tele_snoc : forall ρ T vs κ A v, List.length vs = List.length T ->
    env_tele ρ (T ++ ce_ass κ A :: nil) (vs ++ v :: nil) = extend_env (env_tele ρ T vs) v (entry_type_closure A (env_tele ρ T vs)).
Proof. intros * Hl; rewrite env_tele_app by exact Hl; reflexivity. Qed.

Semantic Notations

Value notations share constr with expression notations, so the spellings the two would otherwise share (ℕ, zero, succ, ⊤, ⋆, ⊥, Π and the closure's λ) carry a superscript ᵈ. Notations specific to values (↦, ↯, 𝕌ω@n, ⇑, ⇓, ⇑!, #ᵈ n) follow the paper.

Definition universe_index_value (u : universe_index) : domain :=

Level Values

The sort of a neutral level, read off its type: a neutral of type Levelᵈ@n is an atom of sort n. No other type has neutral levels, so the default is never used.
Definition domain_level_sort (a : domain) : nat :=
  match a with d_level n => n | _ => 0 end.

The Kind of a Type Value

The kind of a type value is read from its head, with no evaluation: ⊤, ⊥, a Σₚ and a neutral at Prop are propositions; Level@n and a neutral at LevelSort are types of levels; a Π is of its codomain's tag; every other value is a type of a universe. Kind-directed evaluation never evaluates a term of a propositional type: it keeps it (⋆ᵈ) in its place.
Definition domain_kind (a : domain) : abs_kind :=
  match a with
  | d_pi _ κc _ _ _ => κc
  | d_True | d_False | d_and _ _ _ | d_neut d_prop _ => ak_propositional
  | d_level _ | d_neut d_level_sort _ => ak_level
  | _ => ak_relevant
  end.

A case whose premise gives a value with a known head the wrong kind is impossible: inversions leave such cases, and mauto closes them.
#[export]
Hint Extern 1 =>
  match goal with
  | H : domain_kind _ = _ |- _ => progress cbn in H; discriminate H
  | H : evaluated_kind (domain_kind _) |- _ => progress cbn in H; inversion H
  end : mctt.

The flat view of a value of type Level: a flat level is its own view, and a neutral is the single atom (0, n, m) at the sort of its type. No other value has type Level, so the default is never used.
Definition domain_level_view (d : domain) : o2 * list (nat * nat * domain_ne) :=
  match d with
  | d_lvl c xs => (c, xs)
  | d_neut a m => (ordinal_zero, (0, domain_level_sort a, m) :: nil)
  | _ => (ordinal_zero, nil)
  end.

Definition domain_level_const (d : domain) : o2 := fst (domain_level_view d).
Definition domain_level_atoms (d : domain) : list (nat * nat * domain_ne) := snd (domain_level_view d).

The successor and the join of levels: both only flatten.
Definition domain_level_suc (d : domain) : domain :=
  d_lvl (ordinal_succ (domain_level_const d)) (List.map (fun ka => (S (fst (fst ka)), snd (fst ka), snd ka)) (domain_level_atoms d)).

Definition domain_level_max (d e : domain) : domain :=
  d_lvl (ordinal_max (domain_level_const d) (domain_level_const e)) (domain_level_atoms d ++ domain_level_atoms e).

Definition domain_level_lit (o : o2) : domain := d_lvl o nil.

The Realiser of a Level Value

The value of a level when every atom is 0. It is the index of a small universe in the PER and gluing models: those are indexed by ordinals, and a level's canonical form depends on the length of the context, so no finer index would be stable. See Core.Syntactic.Levels.Levels.lvl_real. The maximum of the offsets of the atoms and the constant. The constant is the base of the fold rather than an ordinal_max on top of it, so that the realiser of a literal level is that literal by computation.
Fixpoint domain_level_max_offset (c : o2) (xs : list (nat * nat * domain_ne)) : o2 :=
  match xs with
  | nil => c
  | ka :: r => ordinal_max (ordinal_of_nat (fst (fst ka))) (domain_level_max_offset c r)
  end.

Definition domain_level_real (d : domain) : o2 := domain_level_max_offset (domain_level_const d) (domain_level_atoms d).

Fact domain_level_real_lit : forall o, domain_level_real (domain_level_lit o) = o.
Proof. reflexivity. Qed.

Fact domain_level_real_neut : forall a m, domain_level_real (d_neut a m) = ordinal_zero.
Proof. reflexivity. Qed.

Fact domain_level_max_offset_app : forall c c' xs ys,
    domain_level_max_offset (ordinal_max c c') (xs ++ ys) = ordinal_max (domain_level_max_offset c xs) (domain_level_max_offset c' ys).
Proof.
  intros c c' xs ys; induction xs as [| ka xs IH]; cbn [domain_level_max_offset List.app].
  - induction ys as [| ka ys IH]; cbn [domain_level_max_offset]; [ reflexivity |].
    rewrite IH; generalize (domain_level_max_offset c' ys); intros; ordinal_solve.
  - rewrite IH; generalize (domain_level_max_offset c xs) (domain_level_max_offset c' ys); intros; ordinal_solve.
Qed.

Fact domain_level_max_offset_suc : forall c xs,
    domain_level_max_offset (ordinal_succ c) (List.map (fun ka => (S (fst (fst ka)), snd (fst ka), snd ka)) xs) = ordinal_succ (domain_level_max_offset c xs).
Proof.

Pointwise Equality

Two environments are equal when they agree at every index, entry by entry. Evaluating a substitution determines its result only up to this equality, since a list can end in any number of absent_entrys. Evaluation does not respect it, because λᵈ a ρ M carries its environment; values from pointwise-equal environments are related by the PER model instead.
Definition env_eq : relation env := fun ρ ρ' => forall x, env_entry ρ x = env_entry ρ' x.

Agreement on a Prefix

Two environments agree up to n when they have the same entries below n. Evaluating a substitution into a context of n entries determines its result only up to this agreement: a substitution into a context says nothing of the entries past it.
Definition env_agree_upto (n : nat) : relation env := fun ρ ρ' => forall x, x < n -> env_entry ρ x = env_entry ρ' x.

#[export]

Weakening an Environment

A weakening renames variables, so (⟪φ⟫ ρ) x is ρ (φ x). The list ⟪φ⟫ ρ has one entry for each x with φ x among the variables of ρ. For weakenings built from ↑ and wk_q, which are strictly increasing, those x form an initial segment. Hence ⟪φ⟫ ρ is ρ ∘ φ at every index, and as lists ⟪↑⟫ ρ is ρ↯ and ⟪wk_id⟫ ρ is ρ.

Fixpoint wk_count (φ : wk) (n m : nat) : nat :=
  match m with
  | 0 => 0
  | S m' => wk_count φ n m' + (if φ m' <? n then 1 else 0)
  end.

How many variables φ keeps among n.
Definition wk_len (φ : wk) (n : nat) : nat := wk_count φ n n.

Definition eval_wk (φ : wk) (ρ : env) : env :=
  List.map (fun x => env_entry ρ (φ x)) (List.seq 0 (wk_len φ (List.length ρ))).

Notation "'⟪' φ '⟫' ρ" := (eval_wk φ ρ) (at level 2, φ constr at level 60, ρ at level 0) : mctt_scope.

A weakening that preserves the order of variables. WkMono is a class so that lemmas needing it obtain it by instance resolution.
Definition wk_mono (φ : wk) : Prop := forall x y, x < y -> φ x < φ y.

Class WkMono (φ : wk) : Prop := wk_mono_of : wk_mono φ.

Lemma wk_mono_id : wk_mono wk_id.
Proof.
  intros x y; cbn; lia.
Qed.

Lemma wk_mono_shift : wk_mono ↑.
Proof.
  intros x y; cbn; lia.
Qed.

Lemma wk_mono_q : forall φ, wk_mono φ -> wk_mono (wk_q φ).
Proof.
  intros φ H [| x] [| y] ?; cbn; try lia; specialize (H x y); lia.
Qed.

Lemma wk_mono_compose : forall φ ψ, wk_mono φ -> wk_mono ψ -> wk_mono (φ ⊙ ψ).
Proof.
  intros * Hφ Hψ x y ?; cbn; apply Hψ, Hφ; assumption.
Qed.

Lemma wk_mono_ge : forall φ, wk_mono φ -> forall x, x <= φ x.
Proof.
  intros φ H; induction x; [ lia |].
  specialize (H x (S x) ltac:(lia)); lia.
Qed.

Lemma nat_eq_of_lt_iff : forall a b, (forall x, x < a <-> x < b) -> a = b.
Proof.
  intros a b H; destruct (Nat.lt_trichotomy a b) as [Hlt | [? | Hgt]]; [ | assumption |].
  - specialize (H a); lia.
  - specialize (H b); lia.
Qed.

Lemma wk_count_le : forall φ n m m', m <= m' -> wk_count φ n m <= wk_count φ n m'.
Proof.
  intros * H; induction H; [ lia |]; cbn [wk_count]; lia.
Qed.

The variables kept form an initial segment: those below the first variable that φ sends past n.
Lemma wk_count_spec : forall φ n m, wk_mono φ ->
    forall x, x < wk_count φ n m <-> x < m /\ φ x < n.
Proof.
  intros φ n m Hφ; induction m as [| m IH]; intros x; cbn [wk_count]; [ lia |].
  destruct (Nat.ltb_spec (φ m) n) as [Hm | Hm].
  - (* every variable below m is kept too, so m of them are *)
    assert (Hc : wk_count φ n m = m).
    { apply nat_eq_of_lt_iff; intros y; rewrite IH; split; [ intros [? ?]; assumption |].
      intros Hy; split; [ assumption |]. specialize (Hφ y m Hy); lia. }
    rewrite Hc; split; [ intros Hx; split; [ lia |] | lia ].
    destruct (Nat.eq_dec x m) as [-> | ?]; [ assumption |].
    specialize (Hφ x m ltac:(lia)); lia.
  - rewrite Nat.add_0_r, IH; split; intros [? ?]; split; try lia.
    destruct (Nat.eq_dec x m) as [-> | ?]; lia.
Qed.

Lemma wk_len_spec : forall φ n, wk_mono φ -> forall x, x < wk_len φ n <-> φ x < n.
Proof.
  intros; unfold wk_len; rewrite wk_count_spec by assumption.
  split; [ intros [? ?]; assumption | intros Hx; split; [| assumption ] ].
  pose proof (wk_mono_ge φ ltac:(assumption) x); lia.
Qed.

Lemma eval_wk_length : forall φ ρ, List.length (⟪φ⟫ ρ) = wk_len φ (List.length ρ).
Proof.
  intros; unfold eval_wk; rewrite List.length_map, List.length_seq; reflexivity.
Qed.

Lemma eval_wk_var : forall φ ρ x, x < wk_len φ (List.length ρ) -> env_entry (⟪φ⟫ ρ) x = env_entry ρ (φ x).
Proof.
  intros * Hx; unfold eval_wk; rewrite !env_entry_nth.
  rewrite (List.nth_indep _ _ ((fun y => env_entry ρ (φ y)) 0))
    by (rewrite List.length_map, List.length_seq; assumption).
  rewrite (List.map_nth (fun y => env_entry ρ (φ y)) (List.seq 0 _) 0 x).
  rewrite List.seq_nth, env_entry_nth by assumption; reflexivity.
Qed.

Lemma env_entry_ge : forall ρ x, List.length ρ <= x -> env_entry ρ x = absent_entry.
Proof.
  intros; rewrite env_entry_nth; apply List.nth_overflow; assumption.
Qed.

⟪φ⟫ ρ is ρ ∘ φ at every index, including past the end of the list.
Lemma eval_wk_entry : forall φ ρ, wk_mono φ -> forall x, env_entry (⟪φ⟫ ρ) x = env_entry ρ (φ x).
Proof.
  intros * Hφ x; destruct (Nat.lt_ge_cases x (wk_len φ (List.length ρ))) as [Hx | Hx].
  - apply eval_wk_var; assumption.
  - rewrite !env_entry_ge; [ reflexivity | | rewrite eval_wk_length; assumption ].
    destruct (Nat.lt_ge_cases (φ x) (List.length ρ)) as [Hy | Hy]; [| assumption ].
    exfalso; apply (proj2 (wk_len_spec _ _ Hφ x)) in Hy; lia.
Qed.

Lemma eval_wk_eq : forall φ ρ, wk_mono φ -> forall x, env_var (⟪φ⟫ ρ) x = env_var ρ (φ x).
Proof. intros * Hφ x; unfold env_var; rewrite eval_wk_entry by assumption; reflexivity. Qed.

Two environments of the same length that agree below it are equal.
Lemma env_ext : forall ρ ρ', List.length ρ = List.length ρ' ->
    (forall x, x < List.length ρ -> env_entry ρ x = env_entry ρ' x) -> ρ = ρ'.
Proof.
  intros * Hl H; apply (List.nth_ext _ _ absent_entry absent_entry); [ assumption |].
  intros; rewrite <- !env_entry_nth; auto.
Qed.

Lemma eval_wk_id : forall ρ, ⟪wk_id⟫ ρ = ρ.
Proof.
  intros; assert (Hl : wk_len wk_id (List.length ρ) = List.length ρ)
    by (apply nat_eq_of_lt_iff; intros; rewrite wk_len_spec by apply wk_mono_id; reflexivity).
  apply env_ext; rewrite eval_wk_length, Hl; [ reflexivity |].
  intros x Hx; apply eval_wk_var; rewrite Hl; assumption.
Qed.

Lemma eval_wk_shift : forall ρ, ⟪↑⟫ ρ = ρ↯.
Proof.
  intros; assert (Hl : wk_len ↑ (List.length ρ) = List.length ρ↯).
  { apply nat_eq_of_lt_iff; intros; rewrite wk_len_spec by apply wk_mono_shift.
    destruct ρ; cbn; lia. }
  apply env_ext; rewrite eval_wk_length, Hl; [ reflexivity |].
  intros x Hx; rewrite eval_wk_var by (rewrite Hl; assumption).
  cbn [wk_shift]; rewrite <- env_entry_drop; reflexivity.
Qed.

Lemma eval_wk_q_zero_entry : forall φ ρ, env_entry (⟪wk_q φ⟫ ρ) 0 = env_entry ρ 0.

  unfold wk_len; cbn [List.length].
  pose proof (wk_count_le (wk_q φ) (S (List.length ρ)) 1 (S (List.length ρ)) ltac:(lia)); cbn in *; lia.
Qed.

Lemma eval_wk_q_zero : forall φ ρ, env_var (⟪wk_q φ⟫ ρ) 0 = env_var ρ 0.

Lemma eval_wk_q_tail : forall φ ρ `{Hφ : WkMono φ}, (⟪wk_q φ⟫ ρ)↯ = ⟪φ⟫ (ρ↯).
Proof.
  intros φ ρ Hφ.
  assert (Hq : wk_mono (wk_q φ)) by (apply wk_mono_q, Hφ).
  (* wk_q φ keeps 0 and then what φ keeps of the tail *)
  assert (Hl : forall x, x < wk_len (wk_q φ) (List.length ρ) - 1 <-> φ x < List.length ρ - 1).
  { intros x; split; intros Hx.
    - assert (S x < wk_len (wk_q φ) (List.length ρ)) as H' by lia.
      apply (wk_len_spec _ _ Hq) in H'; cbn in H'; lia.
    - assert (wk_q φ (S x) < List.length ρ) as H' by (cbn; lia).
      apply (wk_len_spec _ _ Hq) in H'; lia. }
  apply env_ext.
  - rewrite eval_wk_length; cbn [drop_env]; rewrite List.length_tl, eval_wk_length.
    apply nat_eq_of_lt_iff; intros x; rewrite (wk_len_spec _ _ Hφ), List.length_tl; apply Hl.
  - intros x Hx.
    cbn [drop_env] in Hx; rewrite List.length_tl, eval_wk_length in Hx.
    rewrite env_entry_drop, !eval_wk_var; cbn [wk_q].
    + rewrite <- env_entry_drop; reflexivity.
    + rewrite (wk_len_spec _ _ Hφ); cbn [drop_env]; rewrite List.length_tl; apply Hl; assumption.
    + lia.
Qed.

Lemma eval_wk_compose : forall φ ψ ρ `{Hφ : WkMono φ} `{Hψ : WkMono ψ}, ⟪φ ⊙ ψ⟫ ρ = ⟪φ⟫ (⟪ψ⟫ ρ).
Proof.
  intros φ ψ ρ Hφ Hψ.
  assert (Hc : wk_mono (φ ⊙ ψ)) by (apply wk_mono_compose; assumption).
  assert (Hl : wk_len (φ ⊙ ψ) (List.length ρ) = wk_len φ (wk_len ψ (List.length ρ))).
  { apply nat_eq_of_lt_iff; intros x.
    rewrite (wk_len_spec _ _ Hc), (wk_len_spec _ _ Hφ), (wk_len_spec _ _ Hψ); reflexivity. }
  apply env_ext; rewrite !eval_wk_length; [ assumption |].
  intros x Hx.
  rewrite eval_wk_var by assumption.
  rewrite eval_wk_var by (rewrite eval_wk_length, <- Hl; assumption).
  rewrite eval_wk_var; [ reflexivity |].
  rewrite Hl in Hx; apply (wk_len_spec _ _ Hφ) in Hx; assumption.
Qed.
