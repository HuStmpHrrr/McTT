The Reference Checker

The direct implementation of the algorithmic judgments, rule by rule: an application normalizes the instantiated codomain B[Id,,N] of the head's type, and a check normalizes both types it compares (subtyping_env_impl). Every normalization is at the initial environment of its context, which the checker carries (checker_env) and extends under binders. It is not extracted: Extraction.Checker.TypeCheck is the checker that is, checking an application spine against the value of the head's type, and Reference.Refinement proves the two accept the same programs, at types equal up to proofs. The parts they share (orders, decisions of side conditions, the initial environment, eliminators and records) are in Extraction.Checker.TypeCheckBase, Extraction.Checker.IndCheck and Extraction.Checker.RecordCheck.

Two descriptions of one module expression, or two generated entries of one open, are one (mdenote_functional_all), and so are two values of one function.
#[local]
Ltac md_unify :=
  repeat match goal with
    | H1 : mdenote ?T ?X ?G ?M ?R1, H2 : mdenote ?T ?X ?G ?M ?R2 |- _ =>
        assert_fails (constr_eq R1 R2);
        let Hg := fresh "Hg" in
        assert (Hg : ⊢ᵍ T ⍮ X) by gctx_wf_tac;
        pose proof (proj1 (mdenote_functional_all _ _ Hg) _ _ _ H1 _ H2); subst R2; clear H2 Hg
    | H1 : items_gen ?T ?X ?G ?M ?its ?A1, H2 : items_gen ?T ?X ?G ?M ?its ?A2 |- _ =>
        assert_fails (constr_eq A1 A2);
        let Hg := fresh "Hg" in
        assert (Hg : ⊢ᵍ T ⍮ X) by gctx_wf_tac;
        pose proof (proj2 (proj2 (proj2 (proj2 (mdenote_functional_all _ _ Hg)))) _ _ _ _ H1 _ H2); subst A2; clear H2 Hg
    | H1 : ?f = Some ?a, H2 : ?f = Some ?b |- _ =>
        assert_fails (constr_eq a b); rewrite H1 in H2; injection H2; clear H2; intros; subst
    | H1 : ?f = Some _, H2 : ?f = None |- _ => rewrite H1 in H2; discriminate H2
    end.

#[local]
Ltac sort_unify :=
  repeat match goal with
    | H1 : is_sort_nf ?W ?r ?u, H2 : is_sort_nf ?W ?r' ?u' |- _ =>

    | H1 : is_univ_nf ?W ?u, H2 : is_univ_nf ?W ?u' |- _ =>
        assert_fails (constr_eq H1 H2);
        pose proof (is_univ_nf_functional _ _ _ H1 H2); clear H2; try subst
    | H1 : nbe_ty ?T ?X ?G ?A ?W1, H2 : nbe_ty ?T ?X ?G ?A ?W2 |- _ =>
