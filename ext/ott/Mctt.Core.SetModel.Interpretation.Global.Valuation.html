Mctt.Core.SetModel.Interpretation.Global.Valuation

The Valuation of a Global Context

What the globals of a global context denote, as semantic data only: the value of each term entry, the module of each module entry, and the semantics of each group of inductive types and of each record type. The interpretation of terms reads globals only through a valuation; Judgments.v states when a valuation is one of a global context (set_gctx_ok).
