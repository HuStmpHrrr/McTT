Prelude›Data›Bool

The booleans, an inductive type with the constructors tt and ff, and their connectives. The names true and True are taken: they are the keywords of the true proposition ⊤ and its proof.

Each connective is defined by cases on its first argument, so it computes as soon as that argument is a constructor: and tt b is b, or ff b is b. The laws are in Prelude›Data›Bool›Properties.

module Prelude›Data›Bool where

import Prelude›Data›Unit use (Unit; unit)
import Prelude›Data›Void use (Void)

inductive Bool : Type@0 where
| tt
| ff
end

open Bool export (tt; ff)

def not (b : Bool) : Bool ≔
  elim b at z -> Bool | tt ⇒ ff | ff ⇒ tt end
end

def and (a : Bool) (b : Bool) : Bool ≔
  elim a at z -> Bool | tt ⇒ b | ff ⇒ ff end
end

def or (a : Bool) (b : Bool) : Bool ≔
  elim a at z -> Bool | tt ⇒ tt | ff ⇒ b end
end

Exclusive or: xor a b is tt when exactly one of a and b is.

def xor (a : Bool) (b : Bool) : Bool ≔
  elim a at z -> Bool | tt ⇒ not b | ff ⇒ b end
end

Boolean equality: eqb a b is tt when a and b are the same constructor.

def eqb (a : Bool) (b : Bool) : Bool ≔
  elim a at z -> Bool | tt ⇒ b | ff ⇒ not b end
end

The proposition that a boolean is tt: IsTrue tt is Unit and IsTrue ff is Void.

def IsTrue (b : Bool) : Type@0 ≔
  elim b at z -> Type@0 | tt ⇒ Unit | ff ⇒ Void end
end

The proposition that a boolean is ff.

def IsFalse (b : Bool) : Type@0 ≔
  elim b at z -> Type@0 | tt ⇒ Void | ff ⇒ Unit end
end

The conditional, into a type of any level u.

module Cond (u : Level) where

if A b t e is t when b is tt, and e when it is ff.

def if (A : Type@{u}) (b : Bool) (t : A) (e : A) : A ≔
  elim b at z -> A | tt ⇒ t | ff ⇒ e end
end

The conditional with delayed branches: cond A b t e is t unit when b is tt, and e unit when it is ff. The branches are functions of Unit, so only the chosen one is computed; a recursive program branches with cond, since if would compute the recursive call in both cases.

def cond (A : Type@{u}) (b : Bool) (t : ∀ (x : Unit) → A) (e : ∀ (x : Unit) → A) :
    A ≔
  (elim b at z -> (∀ (x : Unit) → A) | tt ⇒ t | ff ⇒ e end) unit
end

end
