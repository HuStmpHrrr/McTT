NatTheory

A client of the Prelude library: Prelude›Arith›Equality, Prelude›Arith›Plus and Prelude›Function›Iter are separate units, loaded once each.

module NatTheory where

import Prelude›Data›Unit use (unit)
import Prelude›Builtin›Nat use (succ)
import Prelude›Arith›Equality use (Eq; refl; sym; zeroNeSucc)
import Prelude›Arith›Plus use (plus)
open Prelude›Arith›Plus.Algebra use (plusComm)
import Prelude›Function›Iter as Iter

Prelude›Function›Iter instantiated with succ: iterating it is addition.

def iterSucc : ∀ (n : ℕ) (m : ℕ) →
    Eq (Iter.iter 0l ℕ (λ (x : ℕ) → succ x) n m) (plus n m) ≔
  λ (n : ℕ) (m : ℕ) →
    elim n at x -> Eq (Iter.iter 0l ℕ (λ (y : ℕ) → succ y) x m) (plus x m)
    | zero ⇒ refl m
    | succ p, ih ⇒ ih
    end
end

A proof of a closed equation normalizes to unit, of type Unit.

eval plusComm 2 3
output
Evaluate plusComm 2 3 --> record Prelude›Data›Unit.Unit where end
  : Prelude›Data›Unit.Unit
eval sym 4 4 (refl 4)
output
Evaluate sym 4 4 (refl 4) --> record Prelude›Data›Unit.Unit where end
  : Prelude›Data›Unit.Unit
eval zeroNeSucc 5
output
Evaluate zeroNeSucc 5
  --> λ (x1 : Prelude›Data›Void.Void)
        → Prelude›Arith›Equality.zeroNeSucc 5 x1
  : ∀ (x1 : Prelude›Data›Void.Void) → Prelude›Data›Void.Void
eval iterSucc 3 4
output
Evaluate iterSucc 3 4 --> record Prelude›Data›Unit.Unit where end
  : Prelude›Data›Unit.Unit

The same unit, instantiated with doubling.

eval Iter.iter 0l ℕ (λ (x : ℕ) → plus x x) 3 1
output
Evaluate Iter.iter 0l ℕ (λ (x1 : ℕ) → plus x1 x1) 3 1 --> 8 : ℕ

A let-bound number is known in the body, so unit proves the equation; Doubling names an instance of Prelude›Function›Iter.

eval let module Doubling ≔ Iter 0l ℕ (λ (x : ℕ) → plus x x);
         n ≔ 2;
         p : Eq (Doubling.iter n 1) 4 ≔ unit
     in p
     end
output
Evaluate let module M1 ≔ Iter 0l ℕ (λ (x1 : ℕ) → plus x1 x1);
             x2 : ℕ ≔ 2;
             x3 : Eq (M1.iter x2 1) 4 ≔ unit
         in x3
         end --> record Prelude›Data›Unit.Unit where end
  : Prelude›Data›Unit.Unit
