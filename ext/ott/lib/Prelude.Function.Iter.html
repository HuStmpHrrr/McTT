Prelude›Function›Iter

Iteration of an arbitrary function: a unit parameterized by the level u of the type, the type A and the function, so each client instantiates it as it needs: Iter.iter 0l ℕ f n a iterates on numbers, Iter.iter 1l Type@0 F n A iterates a type former.

module Prelude›Function›Iter
    (u : Level)
    (A : Type@{u})
    (f : ∀ (a : A) → A) where

import Prelude›Builtin›Nat

def iter (n : ℕ) (a : A) : A ≔
  elim n at y -> A
  | zero ⇒ a
  | succ p, r ⇒ f r
  end
end

end
