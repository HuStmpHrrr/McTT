Induction

A client of Prelude›Arith›Induction and Prelude›Arith›Decide: halving by strong and by two-step induction, decisions eliminated into Bool to show which branch they compute, and the equality test eqb.

Halving, by the two induction principles; evals below compare them.

module Halving where

Halving by strong induction: half (succ (succ q)) calls itself at q, which is below succ (succ q) by leSucc q. The two case analyses give the result as a function of the hypothesis for all smaller numbers.

def half (n : ℕ) : ℕ ≔
  strongInd (λ (k : ℕ) → ℕ)
    (λ (k : ℕ) (r : ∀ (m : ℕ) (lt : Lt m k) → ℕ) →
       caseNat (λ (x : ℕ) → ∀ (r : ∀ (m : ℕ) (lt : Lt m x) → ℕ) → ℕ)
         (λ (r : ∀ (m : ℕ) (lt : Lt m 0) → ℕ) → 0)
         (λ (p : ℕ) →
            caseNat (λ (y : ℕ) → ∀ (r : ∀ (m : ℕ) (lt : Lt m (succ y)) → ℕ) → ℕ)
              (λ (r : ∀ (m : ℕ) (lt : Lt m 1) → ℕ) → 0)
              (λ (q : ℕ) (r : ∀ (m : ℕ) (lt : Lt m (succ (succ q))) → ℕ) →
                 succ (r q (leSucc q)))
              p)
         k r)
    n
end

Halving by two-step induction, which needs no order hypothesis.

def halfTwo (n : ℕ) : ℕ ≔
  twoStepInd (λ (k : ℕ) → ℕ) 0 0 (λ (k : ℕ) (h : ℕ) → succ h) n
end

end

open Halving use (half; halfTwo)

eval half 7
output
Evaluate half 7 --> 3 : ℕ
eval half 20
