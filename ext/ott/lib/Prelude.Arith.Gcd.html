Prelude›Arith›Gcd

The greatest common divisor, by Euclid's algorithm. gcd a b replaces (a, b) by (b, mod a b) until the second number is 0; the recursion is primitive, on a fuel bound above b, since every step strictly lowers the second number. Fuel is preferred to strong induction, whose recursive calls are transported along order proofs and compute slowly. gcd a 0 is a, so gcd 0 0 is 0.

import Prelude›Builtin›Nat use (succ)
import Prelude›Arith›Div use (mod)

Euclid's algorithm with fuel steps: gcdFuel (succ f) a (succ d) is gcdFuel f (succ d) (mod a (succ d)), and gcdFuel f a 0 is a for positive fuel. Without fuel it answers a; fuel above b is enough, see Prelude›Arith›Gcd›Properties.gcdFuelEnough.

def gcdFuel (fuel : ℕ) : ∀ (a : ℕ) (b : ℕ) → ℕ ≔
  elim fuel at y -> (∀ (a : ℕ) (b : ℕ) → ℕ)
  | zero ⇒ λ (a : ℕ) (b : ℕ) → a
  | succ f, r ⇒ λ (a : ℕ) (b : ℕ) →
      elim b at z -> ℕ
      | zero ⇒ a
      | succ d, s ⇒ r (succ d) (mod a (succ d))
      end
  end
end

The greatest common divisor, with fuel succ b.

def gcd (a : ℕ) (b : ℕ) : ℕ ≔ gcdFuel (succ b) a b end
