Prelude›Universe›Levels

Universe levels as data. The elements of Level are built from 0l, succl and maxl, and are compared by normalization: a level is a constant and a set of atoms with offsets. So the laws of maxl and succl hold by conversion, and their proofs are lrefl.

Levels have no eliminator, so equality of levels is Leibniz equality, LEq u v: every predicate of u holds of v. The order LLe u v is LEq (maxl u v) v. With them, the unit proves that LEq is an equivalence and a congruence, and that LLe is a preorder with maxl as least upper bound and succl monotone.

These are propositions about levels, in Type@1; they do not drive cumulativity, which only follows the normal forms of levels.

module Prelude›Universe›Levels where

Leibniz equality of levels: predicates of u are predicates of v.

def LEq (u : Level) (v : Level) : Type@1 ≔
  ∀ (P : ∀ (l : Level) → Type@0) (p : P u) → P v
end

The order of levels: u is below v when their join is v.

def LLe (u : Level) (v : Level) : Type@1 ≔ LEq (maxl u v) v end

Leibniz equality is an equivalence and a congruence.

module Equality where

def lrefl (u : Level) : LEq u u ≔
  λ (P : ∀ (l : Level) → Type@0) (p : P u) → p
end

Symmetry uses h at the predicate λ l → P l → P u, which is in Type@0 like P; the textbook motive λ l → LEq l u would be in Type@1.

theorem lsym : ∀ (u : Level) (v : Level) (h : LEq u v) → LEq v u ≔
  λ (u : Level) (v : Level) (h : LEq u v) (P : ∀ (l : Level) → Type@0) →
    h (λ (l : Level) → ∀ (q : P l) → P u) (λ (q : P u) → q)
end

theorem ltrans : ∀ (u : Level) (v : Level) (w : Level)
    (huv : LEq u v) (hvw : LEq v w) → LEq u w ≔
  λ (u : Level) (v : Level) (w : Level) (huv : LEq u v) (hvw : LEq v w)
    (P : ∀ (l : Level) → Type@0) (p : P u) →
    hvw P (huv P p)
end

Every function on levels respects equality.

theorem lcong : ∀ (f : ∀ (l : Level) → Level) (u : Level) (v : Level)
    (h : LEq u v) → LEq (f u) (f v) ≔
  λ (f : ∀ (l : Level) → Level) (u : Level) (v : Level) (h : LEq u v)
    (P : ∀ (l : Level) → Type@0) →
    h (λ (l : Level) → P (f l))
end

end

open Equality use (lrefl; lsym; ltrans; lcong)

The laws of maxl and succl. Each holds by conversion.

module Algebra where

theorem maxlComm : ∀ (u : Level) (v : Level) → LEq (maxl u v) (maxl v u) ≔
  λ (u : Level) (v : Level) → lrefl (maxl u v)
end

theorem maxlAssoc : ∀ (u : Level) (v : Level) (w : Level) →
    LEq (maxl (maxl u v) w) (maxl u (maxl v w)) ≔
  λ (u : Level) (v : Level) (w : Level) → lrefl (maxl u (maxl v w))
end

theorem maxlIdem : ∀ (u : Level) → LEq (maxl u u) u ≔
  λ (u : Level) → lrefl u
end

0l is neutral for maxl.

theorem maxlIdentityRight : ∀ (u : Level) → LEq (maxl u 0l) u ≔
  λ (u : Level) → lrefl u
end

succl distributes over maxl.

theorem succlMaxl : ∀ (u : Level) (v : Level) →
    LEq (succl (maxl u v)) (maxl (succl u) (succl v)) ≔
  λ (u : Level) (v : Level) → lrefl (succl (maxl u v))
end

A level is absorbed by its successor.

theorem maxlSuccl : ∀ (u : Level) → LEq (maxl u (succl u)) (succl u) ≔
  λ (u : Level) → lrefl (succl u)
end

end

LLe is a preorder; maxl is the least upper bound and succl is monotone. Reflexivity, the bounds and the successor step hold by conversion; transitivity and the least-upper-bound property use the equality laws.

module Order where

def lleRefl (u : Level) : LLe u u ≔ lrefl u end

def lleSuccl (u : Level) : LLe u (succl u) ≔ lrefl (succl u) end

def lleZero (u : Level) : LLe 0l u ≔ lrefl u end

def lleMaxlLeft (u : Level) (v : Level) : LLe u (maxl u v) ≔
  lrefl (maxl u v)
end

def lleMaxlRight (u : Level) (v : Level) : LLe v (maxl u v) ≔
  lrefl (maxl u v)
end

maxl u w is maxl u (maxl v w), which is maxl (maxl u v) w by conversion, hence maxl v w, hence w.

theorem lleTrans : ∀ (u : Level) (v : Level) (w : Level)
    (huv : LLe u v) (hvw : LLe v w) → LLe u w ≔
  λ (u : Level) (v : Level) (w : Level) (huv : LLe u v) (hvw : LLe v w) →
    ltrans (maxl u w) (maxl v w) w
      (ltrans (maxl u w) (maxl u (maxl v w)) (maxl v w)
         (lcong (λ (l : Level) → maxl u l) w (maxl v w) (lsym (maxl v w) w hvw))
         (lcong (λ (l : Level) → maxl l w) (maxl u v) v huv))
      hvw
end

The join is below every upper bound.

theorem lleMaxlLub : ∀ (u : Level) (v : Level) (w : Level)
    (huw : LLe u w) (hvw : LLe v w) → LLe (maxl u v) w ≔
  λ (u : Level) (v : Level) (w : Level) (huw : LLe u w) (hvw : LLe v w) →
    ltrans (maxl u (maxl v w)) (maxl u w) w
      (lcong (λ (l : Level) → maxl u l) (maxl v w) w hvw)
      huw
end

succl is monotone, since it distributes over maxl.

theorem lleSucclCong : ∀ (u : Level) (v : Level) (h : LLe u v) →
    LLe (succl u) (succl v) ≔
  λ (u : Level) (v : Level) (h : LLe u v) →
    lcong (λ (l : Level) → succl l) (maxl u v) v h
end

end
