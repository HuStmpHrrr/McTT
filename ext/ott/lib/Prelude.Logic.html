Prelude›Logic

Propositions as types, at every universe level: Unit holds, Void has no proof; negation, Church-encoded conjunction, disjunction, equivalence and existence over numbers, and decidability. The connectives of Prop, the universe of propositions, are in Propositions.

Each submodule takes the level u of the propositions it combines, so Conj.And 0l A B is the conjunction of two propositions of Type@0 and Conj.And 1l A B that of two propositions of Type@1. A Church encoding quantifies over its target proposition, so it lives one level up, in Type@{succl u}. Clients that only need propositions in Type@0 open a submodule at 0l: open Prelude›Logic.Conj 0l use (And).

module Prelude›Logic where

import Prelude›Builtin›Nat
import Prelude›Data›Void use (Void)

Negation and ex falso quodlibet for the propositions of Type@{u}.

module Negation (u : Level) where

def Not (A : Type@{u}) : Type@{u} ≔ ∀ (a : A) → Void end

From a proof of Void, anything follows.

open Prelude›Data›Void.Absurd u export (absurd)

end

open Negation 0l export (Not; absurd)

Conjunction: its introduction, projections and symmetry.

module Conj (u : Level) where

Conjunction, Church-encoded: a proof of And A B eliminates into any proposition C of the same level. It quantifies over Type@{u}, so it lives in Type@{succl u}.

def And (A : Type@{u}) (B : Type@{u}) : Type@{succl u} ≔
  ∀ (C : Type@{u}) (f : ∀ (a : A) (b : B) → C) → C
end

def andIntro (A : Type@{u}) (B : Type@{u}) (a : A) (b : B) : And A B ≔
  λ (C : Type@{u}) (f : ∀ (x : A) (y : B) → C) → f a b
end

def andFst (A : Type@{u}) (B : Type@{u}) (h : And A B) : A ≔
  h A (λ (a : A) (b : B) → a)
end

def andSnd (A : Type@{u}) (B : Type@{u}) (h : And A B) : B ≔
  h B (λ (a : A) (b : B) → b)
end

def andSwap (A : Type@{u}) (B : Type@{u}) (h : And A B) : And B A ≔
  λ (C : Type@{u}) (f : ∀ (b : B) (a : A) → C) →
    h C (λ (a : A) (b : B) → f b a)
end

end

Disjunction: its injections, case analysis and symmetry.

module Disj (u : Level) where

Disjunction, Church-encoded like And, and likewise one level up.

def Or (A : Type@{u}) (B : Type@{u}) : Type@{succl u} ≔
  ∀ (C : Type@{u}) (f : ∀ (a : A) → C) (g : ∀ (b : B) → C) → C
end

def orInl (A : Type@{u}) (B : Type@{u}) (a : A) : Or A B ≔
  λ (C : Type@{u}) (f : ∀ (x : A) → C) (g : ∀ (y : B) → C) → f a
end

def orInr (A : Type@{u}) (B : Type@{u}) (b : B) : Or A B ≔
  λ (C : Type@{u}) (f : ∀ (x : A) → C) (g : ∀ (y : B) → C) → g b
end

Case analysis on a disjunction, into a proposition C of the same level.

def orElim (A : Type@{u}) (B : Type@{u}) (C : Type@{u}) (h : Or A B)
    (f : ∀ (a : A) → C) (g : ∀ (b : B) → C) : C ≔
  h C f g
end

Swapping needs no elimination into Type@{succl u}: the result is itself a function of the target proposition.

def orSwap (A : Type@{u}) (B : Type@{u}) (h : Or A B) : Or B A ≔
  λ (C : Type@{u}) (f : ∀ (b : B) → C) (g : ∀ (a : A) → C) → h C g f
end

end

Logical equivalence and its rules.

module Equiv (u : Level) where

open Conj u use (And; andIntro; andFst; andSnd; andSwap)

Logical equivalence: implications both ways, as a conjunction. Like And, it lives one level up.

def Iff (A : Type@{u}) (B : Type@{u}) : Type@{succl u} ≔
  And (∀ (a : A) → B) (∀ (b : B) → A)
end

def iffIntro (A : Type@{u}) (B : Type@{u}) (f : ∀ (a : A) → B)
    (g : ∀ (b : B) → A) : Iff A B ≔
  andIntro (∀ (a : A) → B) (∀ (b : B) → A) f g
end

The forward implication of an equivalence.

def iffFwd (A : Type@{u}) (B : Type@{u}) (h : Iff A B) (a : A) : B ≔
  andFst (∀ (x : A) → B) (∀ (y : B) → A) h a
end

The backward implication of an equivalence.

def iffBwd (A : Type@{u}) (B : Type@{u}) (h : Iff A B) (b : B) : A ≔
  andSnd (∀ (x : A) → B) (∀ (y : B) → A) h b
end

def iffRefl (A : Type@{u}) : Iff A A ≔
  iffIntro A A (λ (a : A) → a) (λ (a : A) → a)
end

def iffSym (A : Type@{u}) (B : Type@{u}) (h : Iff A B) : Iff B A ≔
  andSwap (∀ (a : A) → B) (∀ (b : B) → A) h
end

end

Existence of a number, and its rules.

module Exist (u : Level) where

Existence of a number satisfying P, Church-encoded: a proof eliminates into any proposition C that follows from some witness and its proof. It quantifies over Type@{u}, so it lives in Type@{succl u}; an Exists at level u is a predicate for Exist (succl u), so existence proofs nest one level per quantifier.

def Exists (P : ∀ (n : ℕ) → Type@{u}) : Type@{succl u} ≔
  ∀ (C : Type@{u}) (f : ∀ (n : ℕ) (p : P n) → C) → C
end

def existsIntro (P : ∀ (n : ℕ) → Type@{u}) (n : ℕ) (p : P n) : Exists P ≔
  λ (C : Type@{u}) (f : ∀ (m : ℕ) (q : P m) → C) → f n p
end

Elimination of an existence proof into a proposition C.

def existsElim (P : ∀ (n : ℕ) → Type@{u}) (C : Type@{u}) (h : Exists P)
    (f : ∀ (n : ℕ) (p : P n) → C) : C ≔
  h C f
end

end

Decidability, and the propositions it makes classical.

module Decidable (u : Level) where

open Negation u use (Not; absurd)
open Disj u use (Or; orElim)

A proposition is decidable when it holds or is refuted. Dec A is a disjunction, so it lives one level up, and is eliminated with orElim.

def Dec (A : Type@{u}) : Type@{succl u} ≔ Or A (Not A) end

A decidable proposition is stable under double negation.

def decStable (A : Type@{u}) (d : Dec A) (h : Not (Not A)) : A ≔
  orElim A (Not A) A d (λ (a : A) → a) (λ (n : Not A) → absurd A (h n))
end

Decidability is preserved by negation. As for orSwap, the result is built as a function of the target proposition, since Dec is one level up and orElim only targets Type@{u}.

def decNot (A : Type@{u}) (d : Dec A) : Dec (Not A) ≔
  λ (C : Type@{u}) (f : ∀ (n : Not A) → C) (g : ∀ (nn : Not (Not A)) → C) →
    d C (λ (a : A) → g (λ (n : Not A) → n a)) (λ (n : Not A) → f n)
end

end

The connectives of Prop, the universe of propositions. A proposition has at most one proof up to conversion, and every connective below is itself a proposition: conjunction is the primitive ∧, disjunction and existence are encoded impredicatively, quantifying over Prop. Used as Propositions.And P Q.

module Propositions where

Conjunction: the primitive ∧ (p : P) → Q, whose second proposition does not depend on the proof of the first.

def And (P : Prop) (Q : Prop) : Prop ≔ ∧ (p : P) → Q end

A proof of a conjunction from proofs of both sides.

def andIntro (P : Prop) (Q : Prop) (p : P) (q : Q) : And P Q ≔ conj (p : P) q end

The first side of a conjunction.

def andFst (P : Prop) (Q : Prop) (h : And P Q) : P ≔ left h end

The second side of a conjunction.

def andSnd (P : Prop) (Q : Prop) (h : And P Q) : Q ≔ right h end

Equivalence: implications both ways, as a conjunction.

def Iff (P : Prop) (Q : Prop) : Prop ≔ And (∀ (p : P) → Q) (∀ (q : Q) → P) end

An equivalence from implications both ways.

def iffIntro (P : Prop) (Q : Prop) (f : ∀ (p : P) → Q) (g : ∀ (q : Q) → P) : Iff P Q ≔
  andIntro (∀ (p : P) → Q) (∀ (q : Q) → P) f g
end

Disjunction, encoded impredicatively: a proof eliminates into any proposition C that follows from either side.

def Or (P : Prop) (Q : Prop) : Prop ≔
  ∀ (C : Prop) (f : ∀ (p : P) → C) (g : ∀ (q : Q) → C) → C
end

A proof of a disjunction from its first side.

def orInl (P : Prop) (Q : Prop) (p : P) : Or P Q ≔
  λ (C : Prop) (f : ∀ (x : P) → C) (g : ∀ (y : Q) → C) → f p
end

A proof of a disjunction from its second side.

def orInr (P : Prop) (Q : Prop) (q : Q) : Or P Q ≔
  λ (C : Prop) (f : ∀ (x : P) → C) (g : ∀ (y : Q) → C) → g q
end

Case analysis on a disjunction, into a proposition C.

def orElim (P : Prop) (Q : Prop) (C : Prop) (h : Or P Q) (f : ∀ (p : P) → C) (g : ∀ (q : Q) → C) : C ≔
  h C f g
end

Existence of an element of A satisfying P, encoded impredicatively: a proof eliminates into any proposition C that follows from some witness and its proof.

def Exists (A : Type@0) (P : ∀ (a : A) → Prop) : Prop ≔
  ∀ (C : Prop) (f : ∀ (a : A) (p : P a) → C) → C
end

A proof of existence from a witness and its proof.

def existsIntro (A : Type@0) (P : ∀ (a : A) → Prop) (a : A) (p : P a) : Exists A P ≔
  λ (C : Prop) (f : ∀ (b : A) (q : P b) → C) → f a p
end

Elimination of an existence proof into a proposition C.

def existsElim (A : Type@0) (P : ∀ (a : A) → Prop) (C : Prop) (h : Exists A P)
    (f : ∀ (a : A) (p : P a) → C) : C ≔
  h C f
end

Negation: a proof of Not P turns a proof of P into one of ⊥.

def Not (P : Prop) : Prop ≔ ∀ (p : P) → ⊥ end

From a proof of ⊥, an element of any type A of Type@0.

def absurd (A : Type@0) (h : ⊥) : A ≔ exfalso h return A end

end
