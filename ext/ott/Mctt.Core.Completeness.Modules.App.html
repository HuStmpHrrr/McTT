Applications of Valid Units

A valid unit, or a module expression valid in what it denotes, lacks the parameter its description says it takes next, and applied to an argument of that parameter's type it is valid in what it denotes (valid_unit_app_all): a filed module records the argument, a literal is instantiated (valid_unit_lit_app), an alias with no parameter is its target applied.
