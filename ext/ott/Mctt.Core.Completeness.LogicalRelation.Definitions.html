The Semantic Judgments

All the definitions of the PER model's judgments, in four parts.
1. The relations at one global context GC, the building blocks: weakenings, substitutions, terms, subtyping and module expressions; semantically well-formed contexts and the parts of units (rel_ctx_wf, rel_unit_wf), and the relations of units and extensions. 2. Valid units and module expressions valid in what they denote (valid_unit, valid_modexp), with lookups read at a global context Θm ⍮ Ξm that GC extends and values at GC; and the contexts whose slots hold valid units (valid_ctx). 3. What a global context Θm ⍮ Ξm files and has open is worth at GC (valid_filed_mod, valid_filed_mods), and a declaration (valid_ind_decl, valid_record_decl); a sound embedding of Θ1 ⍮ Ξ1 into Θ2 ⍮ Ξ2 (valid_gctx_embedding). 4. The semantic judgments: a judgment of Θ ⍮ Ξ is the relation of the first two parts at every global context Θ ⍮ Ξ embeds into soundly.
The substitution and term layers state their conclusion as a four-value pattern (see Core/Semantic/PER/Chain.v): 
{⟦M[σ]⟧(ρ), ⟦M⟧(⟦σ⟧(ρ)), ⟦M'⟧(⟦σ'⟧(ρ')), ⟦M'[σ']⟧(ρ')} ⊆ R
Its three consecutive links are the commutation obligation on the left, the relatedness obligation in the middle, and the commutation obligation on the right. Substitution is an operation, so ⟦M[σ]⟧(ρ) and ⟦M⟧(⟦σ⟧(ρ)) are in general not equal, and every case of the fundamental theorem must discharge both commutations.

Semantic Weakening

A weakening is an operation, so related environments need not stay related after it is applied; the semantic judgment for weakenings requires that they do. Without its two context witnesses it is Proper (R ==> R') (eval_wk φ), for a weakening that moves no variable down: environments are lists, which is what makes weakenings compose on them (eval_wk_compose). Every weakening the proofs use is built from ↑ and wk_q, hence is of this kind.

Record rel_wk (φ : wk) (R R' : relation env) : Prop := mk_rel_wk
  { rel_wk_mono : WkMono φ
  ; rel_wk_app :> forall ρ ρ',
      Dom ρ ≈ ρ' ∈ R ->
      Dom ⟪φ⟫ ρ ≈ ⟪φ⟫ ρ' ∈ R' }.

Semantic Substitution Equality

σ and σ' must stay related after an arbitrary semantic weakening φ — the Kripke-like quantification that makes the judgment usable under context extension. The four environments are the two ways of evaluating each side: σ[φ] in ρ (the substitution sb_wk σ φ, which is σ postcomposed with φ) against σ in ⟪φ⟫ ρ. Evaluation is directed by the target context Δ, which puts the proof ⋆ᵈ at its propositions.

#[warnings="-cannot-define-projection"]

  ; rel_sub_eval_wk : ⟦ (sb_wk σ φ) : Δ ⟧s ρ ↘ ρσφ
  ; rel_sub_eval : ⟦ σ : Δ ⟧s ⟪φ⟫ ρ ↘ ρσ

The entries of the two substitutions are scoped by the source Γ, and the weakenings the body is taken under are bounded on Γ: a proof is kept as written (⋆ᵈ⟨M, ρ⟩), so its readback binds the entries of ρ up to its free bound (proof_scope), which the model knows to read back only inside the context. For example:
  • Δ ▹ P ⊨ˢ Id,, h : Δ ▹ P ▹ P with h = #0: the head is kept as ⋆ᵈ⟨#0[φ]ʷ, ρ⟩, which reads ρ at φ 0 only, inside the context ρ is related at because φ is bounded;
  • at Γ = ⋅ ▹ ℕ, Id,, #5 is not scoped: a proof h #0 substituted by it is kept as h #5, whose readback would read the sixth entry of an environment of a one-entry context.

Terms

Terms are required to be stable under semantic substitutions rather than weakenings. rel_exp is the four-value pattern of one expression pair. The two environments ρσ and ρ'σ' are parameters rather than existentials, because the type chain and the term chain must be read in the same pair of environments: closures capture their environment, so replacing it by a pointwise-equal one changes the values.

#[warnings="-cannot-define-projection"]
Record rel_exp (M : exp) (σ : sub) (ρ ρσ : env) (M' : exp) (σ' : sub) (ρ' ρ'σ' : env) (R : relation domain) : Prop := mk_rel_exp
  { mσ : domain
  ; m : domain
  ; m' : domain
  ; m'σ' : domain
  ; rel_exp_eval_sub : ⟦ M[σ] ⟧ ρ ↘ mσ
  ; rel_exp_eval : ⟦ M ⟧ ρσ ↘ m
  ; rel_exp_eval' : ⟦ M' ⟧ ρ'σ' ↘ m'
  ; rel_exp_eval_sub' : ⟦ M'[σ'] ⟧ ρ' ↘ m'σ'
  ; rel_exp_chain : rel_chain R ([mσ; m; m'; m'σ']) }.

The notation ⟦σ⟧(ρ) suggests that evaluation of σ is a function. It is a relation, and functional_eval_sub determines its result only up to env_eq. That does not allow substituting one witness for another, since evaluation does not respect env_eq (a closure captures its environment). So the two environments are quantified universally, over evaluation witnesses supplied by the caller, rather than existentially; any two proofs that σ evaluates at ρ are then interchangeable.
The relation does not itself claim that σ evaluates at ρ; that is part of rel_sub_under_ctx Γ' Γ σ σ', which every instantiation supplies. In return, each case of the fundamental theorem must produce its values at whatever environment the caller names. This is what makes the inductive cases fit: a premise's values arrive in the same environment as the conclusion's, so two instantiations of one relation share values rather than being pointwise equal, and rel_chain_merge applies.
At a type whose value is a proposition (type_propositional) the terms are proofs, which evaluation never reaches, so they are related by their typing alone: the judgment asks nothing of their values. One value of the type is enough, as the PER model relates propositions to propositions only.
The left substituted value of the type A is a proposition.
Definition type_propositional (A : typ) (σ : sub) (ρ : env) : Prop := rel_typ_propositional A[σ] ρ.

Subtyping

Not a four-value chain: per_subtyp has no symmetry, so the two commutation obligations are stated on their own sides and the subtyping obligation relates the two inner values only.

Types of Either Sort

Two types related at the index i: their four values related in per_univ i, whatever their sort. A type of a universe is one (Γ ⊨ A ≈ A' : Typeω@i relates relevant types, the elements of the universe), and so is a proposition (Γ ⊨ A ≈ A' : Prop relates propositions, which are types of every index). This is what an extension of a context, and the domain of a Π, need of a type. The values of A at the environments of Γ are not the sort LevelSort: A is a type of a sort, as the type of a variable or of the domain of a Π is (per_ctx_env_cons, per_univ_elem_core_pi).

The Sorts of a Body's Definitions

Each term part of the body Φ over D is of the sort its kind tag says (entry_kind, abs_kind_sort): a type of a universe when it is tagged ak_relevant, a type of levels (LevelSort) when it is tagged ak_level, a proposition when it is tagged ak_propositional, in the context the entries before it make, as wf_gentry_def asks. A body's environment is read by the tags (eval_body_env), while the context PER of its context (body_ctx) reads the sorts of the types, so the two agree only under this. For example, in a body def h : P := p with P : Prop tagged relevant, eval_body_env stores the value of p at h, while the context PER relates only kept proofs there. And in module K (u : Level) where def w : Level ≔ u end, the type of w is a type of levels, of no universe.
Fixpoint body_sorts_valid (Φ : gmod) (D : ctx) : Prop :=
  match Φ with
  | gm_nil => True
  | gm_ext Φ0 _ E =>
      body_sorts_valid Φ0 D /\
      forall A M, entry_tm E = Some (A, M) ->
        exists i, body_ctx Φ0 ++ D ⊨ A : abs_kind_sort (entry_kind E) Typeω@i
  (* read on expansions only (body_xp), which have no open *)
  | gm_open Φ0 _ _ _ => body_sorts_valid Φ0 D
  end.

Contexts

An inductive relation whose extension step carries both the context PER witness and the semantic well-formedness of the head (and, for a definition, of its body; for a module slot, of its unit; for a definition with a module part, of both), so rel_ctx_wf_per_ctx_env reads the PER off any derivation. The validity of a unit's parts (rel_unit_wf) is defined with it, since a body unit's parts form a context. An assumption is of a type of a sort at its kind (sort_kind), as in wf_ctx_extend; a definition is of a type of a sort (type_sort), as in wf_ctx_extend_def; a definition with a module part is of a type of a universe.

4. The Semantic Judgments

A semantic judgment is stated at a global context Θ ⍮ Ξ, as the syntactic one is, and holds at every global context Θ2 ⍮ Ξ2 that Θ ⍮ Ξ embeds into soundly: there it is the relation of the first two parts, read in the PER model of Θ2 ⍮ Ξ2, with lookups read at Θ ⍮ Ξ. Each judgment about the members of a context also states the context, with valid slots (valid_ctx). The units of ⊨ᵘ are moreover valid (valid_unit), the extended contexts of ⊨ˣ have valid slots, and the module expressions of ⊨ᵐ are valid in what they denote (valid_modexp).
