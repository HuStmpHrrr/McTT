Mctt.Core.Syntactic.Command

Commands

The core commands a unit is elaborated into: names are resolved, and an import is a load and the declaration of its items. Their meaning, as steps of the global state, is given in Core.Syntactic.System.Command.

A group of inductive declarations as written (core_cmd_inductive): one type, or the types of a mutual block, in order. The group's own uniform parameters raw_decl_uparams (innermost first, over the enclosing frames' parameters) are shared; each member has its name, its non-uniform parameters (innermost first, over the uniform ones), its sort (over the uniform ones; the members' sorts are one) and its constructors, each with its named arguments, outermost first. An argument's type is over the arguments before it, all of them binders, then the member's parameters, then the declared types themselves, Self_0 (outermost) … Self_(n-1), variables of types Π (params). S bound outside the parameters (but inside those of the enclosing frames): a recursive occurrence of the j-th type is Self_j at all its own parameters. The command classifies the arguments of each constructor on the normal forms of their types, and so finds the group's views, into the structural declaration it files.

A function of a mutual def as written (core_cmd_mdef): its name, its non-uniform parameters ys (innermost first, over the block's parameters Δ), the type of its scrutinee (over ys), its result type (over the scrutinee and ys) and its clauses, one per constructor of its member in order, each binding the non-uniform parameters, the arguments and the recursive results (over Δ).

The core commands: filled, or generated by a declaration. A module and a record are no nested command: each opens a frame (core_cmd_mod_open, core_cmd_record_open), the commands of its body run in it as the commands after it, and core_cmd_close files it.
Inductive core_cmd : Set :=
def x : A := M and axiom x : A: transparency, privacy, the kind of the type (filled from its sort), type and body. An axiom has no body; an abstract def is opaque, not bodiless.
| core_cmd_def : string -> bool -> bool -> abs_kind -> typ -> option exp -> core_cmd
core_cmd_mod_open x pv Δ: open the frame of the module x, private when pv, under its own parameters Δ
| core_cmd_mod_open : string -> bool -> ctx -> core_cmd
module x (Δ) := E: an alias, under its own parameters, private or not.
| core_cmd_alias : string -> bool -> ctx -> modexp -> core_cmd
core_cmd_load fp: load the unit fp if it is not filed yet.
| core_cmd_load : path -> core_cmd
core_cmd_open E items: check that E is a module, and declare the items, as definitions and aliases of this frame.
| core_cmd_open : modexp -> list import_item -> core_cmd
core_cmd_eval M A: eval M : A; the fill writes the type M infers when none is written
| core_cmd_eval : exp -> typ -> core_cmd
inductive x (Δ) : S where | c … with y : T where | … end, private or not: the group as written, its parameters over those of the enclosing frames. It makes an entry per declared type, each the module, over the uniform parameters, of the type's constructors (and the recursor).
| core_cmd_inductive : bool -> raw_decl -> core_cmd
mutual def (Δ) f (ys) (z : Z) : A | … with g … end, abstract and private or not: one function per member of a group, in any order, each filed as the definition λ Δ ys z. a_elim pq m Bks z of the group's eliminator at its member m.
| core_cmd_mdef : bool -> bool -> ctx -> list raw_fun -> core_cmd
builtin k := X: the module X, as written, is bound as the builtin k; the command resolves it to the inductive type it names.
| core_cmd_builtin : string -> modexp -> core_cmd
inductive x (Δ) := X: the inductive alias x of the inductive type the module X, as written, names, under its own parameters Δ.
| core_cmd_inductive_alias : string -> bool -> ctx -> modexp -> core_cmd
record x (Δ) := X: the record alias x of the record type the module X, as written, names, under its own parameters Δ.
| core_cmd_record_alias : string -> bool -> ctx -> modexp -> core_cmd
core_cmd_record_open x pv Δ S fs: open the frame of the record type x, private when pv, with its own parameters Δ over those of the enclosing frames, its sort over them, and its fields in order, each over the fields before it (innermost first) and the parameters, each at its kind (filled from the sort of its type); its field definitions run in it at once
| core_cmd_record_open : string -> bool -> ctx -> typ -> list (string * abs_kind * typ) -> core_cmd
core_cmd_close x pv: file the frame on top, of the module or the record x, private when pv, in the frame below it
| core_cmd_close : string -> bool -> core_cmd.
