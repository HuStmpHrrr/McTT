PER Lemmas: the Basic PERs

The first part of Core.Semantic.PER.Lemmas: the morphisms of the evaluation relations; per_bot, per_top, the PERs of levels and of their order, per_top_typ, per_ne, per_prop and per_proof are PERs; the tactics rewriting along equivalent relations.

Lemma per_bot_sym : forall m n,
    Dom m ≈ n ∈ per_bot ->
    Dom n ≈ m ∈ per_bot.
Proof.
  intros * H s; destruct (H s) as [L L' HL HL' HE].
  exact (mk_neutral_reads_alike _ _ _ _ _ HL' HL (symmetry HE)).
Qed.

Hint Resolve per_bot_sym : mctt.

Lemma per_bot_trans : forall m n l,
    Dom m ≈ n ∈ per_bot ->
    Dom n ≈ l ∈ per_bot ->
    Dom m ≈ l ∈ per_bot.
Proof.
  intros * Hmn Hnl s; destruct (Hmn s) as [L L1 HL HL1 HE]; destruct (Hnl s) as [L2 L' HL2 HL' HE'].
  pose proof (functional_read_ne _ _ _ _ HL1 HL2) as <-.
  exact (mk_neutral_reads_alike _ _ _ _ _ HL HL' (transitivity HE HE')).
Qed.

Hint Resolve per_bot_trans : mctt.

#[local] Instance per_bot_PER : PER per_bot.
Proof.
  split.
  - eauto using per_bot_sym.
  - eauto using per_bot_trans.
Qed.

Related levels have the same realiser: readback preserves the offsets, so the realiser is the one of the canonical form they read back as.
Lemma per_lvl_real : forall m n,
    Dom m ≈ n ∈ per_lvl ->
    domain_level_real m = domain_level_real n.
Proof.
  intros * H; destruct (per_lvl_reads _ _ H 0) as (L & HW & HW' & _).
  apply read_nf_level_real in HW as [L1 [Heq HL]], HW' as [L1' [Heq' HL']].
  apply nf_lvl_of_inj in Heq as <-; apply nf_lvl_of_inj in Heq' as <-.
  rewrite <- HL, <- HL'; reflexivity.
Qed.

Hint Resolve per_lvl_real : mctt.

The Order on Levels

per_sublvl relates two readable levels whose canonical forms are ordered. It is reflexive on related levels, transitive, and refines the order on realisers — which is what makes a subtyping between two small universes hold at the index of the smaller one.
Lemma per_sublvl_left : forall l l',
    per_sublvl l l' ->
    Dom l ≈ l ∈ per_lvl.
Proof.
  intros * H s; destruct (H s) as [L L' HL HL' _ Hp _]; exists L; assumption.
Qed.

Lemma per_sublvl_right : forall l l',
    per_sublvl l l' ->
    Dom l' ≈ l' ∈ per_lvl.
Proof.
  intros * H s; destruct (H s) as [L L' HL HL' _ _ Hp]; exists L'; assumption.
Qed.

Hint Resolve per_sublvl_left per_sublvl_right : mctt.

Lemma per_sublvl_real : forall l l',
    per_sublvl l l' ->
    ordinal_le (domain_level_real l) (domain_level_real l').
Proof.
  intros * H; destruct (H 0) as [L L' HL HL' Hle _ _].
  apply read_nf_level_real in HL as [L1 [HL1 <-]].
  apply read_nf_level_real in HL' as [L1' [HL1' <-]].
  apply nf_lvl_of_inj in HL1 as <-; apply nf_lvl_of_inj in HL1' as <-.
  apply lvl_le_real; assumption.
Qed.

Lemma per_sublvl_of_per_lvl : forall l l',
    Dom l ≈ l' ∈ per_lvl ->
    per_sublvl l l'.
Proof.
  intros * H s; destruct (per_lvl_reads _ _ H s) as (L & HW & HW' & Hp).
  exists L L; [ assumption | assumption | apply lvl_le_of_upto_proofs; reflexivity | exact Hp | exact Hp ].
Qed.

Hint Resolve per_sublvl_of_per_lvl : mctt.

Lemma per_sublvl_trans : forall l l' l'',
    per_sublvl l l' ->
    per_sublvl l' l'' ->

Proof.

  destruct (H s) as [L L1 HL HL1 Hle Hp _].
  destruct (H' s) as [L1' L2 HL1' HL2 Hle' _ Hp'].

      by (apply nf_lvl_of_inj; eapply functional_read_nf; eassumption).

Qed.

A neutral of type Level@n is a level: it reads back as the single atom at offset 0, of sort n, which is canonical. The sort is read off the neutral's type, so two neutrals are related levels only at types of one sort. Neutrals of a type of levels hold no proof (per_bot_at), and then the two read back as one.
Lemma per_bot_then_per_lvl : forall m m' a a',
    domain_level_sort a = domain_level_sort a' ->
    Dom m ≈ m' ∈ per_bot_at ak_level ->
    Dom ⇑ a m ≈ ⇑ a' m' ∈ per_lvl.
Proof.
  intros * Ha [H Hpf] s.
  destruct (H s) as [M M' Hl Hr HE].
  pose proof (proj1 (Hpf eq_refl) _ _ Hl) as Hp.
  pose proof (ne_proof_free_eq _ _ Hp HE) as <-.
  exists (ordinal_zero, cons (mk_level_atom 0 (domain_level_sort a) M) nil);
    [ econstructor; eassumption | rewrite Ha; econstructor; eassumption | cbn; split; [ exact Hp | exact I ] ].
Qed.

Hint Resolve per_bot_then_per_lvl : mctt.

Add Parametric Morphism i : (per_univ_elem i)
    with signature (@relation_equivalence domain) ==> eq ==> eq ==> iff as per_univ_elem_morphism_iff.
Proof.
  simpl.
  intros R R' HRR'.
  split; intros Horig; [gen R' | gen R];
    per_univ_elem_induction Horig.
  all: try solve [ basic_per_univ_elem_econstructor; eauto;
    try (etransitivity; [symmetry + idtac|]; eassumption);
    intros;
    destruct_rel_mod_eval;
    econstructor; mautosolve ].
An inductive type, a record type: their relations are untouched.
  all: intros R0 HR0; basic_per_univ_elem_econstructor; try eassumption;
    unfold nparams_evals, args_evals, doms_evals, fields_evals in *;
    try (intros; eapply rel_mod_eval_proj1; match goal with H : _ |- _ => eapply H; eassumption end);
    try (etransitivity; [ symmetry + idtac | ]; eassumption).
Qed.

The morphism in forward form. apply -> per_univ_elem_morphism_iff needs the level to be known, which is not the case when building a context PER: there the level of the head relation is fixed only by the witness supplied for it. Taking the witness first leaves <~> as the only goal, and leaves the target relation implicit, so the caller never spells out the impredicative head relation.
Lemma per_univ_elem_resp_iff : forall {i R R' a a'},
    DF a ≈ a' ∈ per_univ_elem i ↘ R ->
    (R <~> R') ->
    DF a ≈ a' ∈ per_univ_elem i ↘ R'.
Proof.
  intros * H HR.
  apply -> per_univ_elem_morphism_iff; [ eassumption | reflexivity | reflexivity | eassumption ].
Qed.

Lemma domain_app_per : forall f f' a a',
  Dom f ≈ f' ∈ per_bot ->
  Dom a ≈ a' ∈ per_top ->
  Dom f $ᵈ a ≈ f' $ᵈ a' ∈ per_bot.
Proof.
  intros * H H0 s.
  destruct (H s) as [L L' HL HL' HE].
  destruct (H0 s) as [N N' HN HN' HE'].
  exists (ne_app L N) (ne_app L' N'); [ econstructor; eassumption | econstructor; eassumption |].
  unfold ne_eq_upto_proofs, nf_eq_upto_proofs, ne_eq_upto_proofs in *; cbn; rewrite HE, HE'; reflexivity.
Qed.

Ltac rewrite_relation_equivalence_left :=
  repeat match goal with
    | H : ?R1 <~> ?R2 |- _ =>
        try setoid_rewrite H;
        (on_all_hyp: fun H' => assert_fails (unify H H'); unmark H; setoid_rewrite H in H');
        let T := type of H in
        fold (id T) in H
    end; unfold id in *.

Ltac rewrite_relation_equivalence_right :=
  repeat match goal with
    | H : ?R1 <~> ?R2 |- _ =>
        try setoid_rewrite <- H;
        (on_all_hyp: fun H' => assert_fails (unify H H'); unmark H; setoid_rewrite <- H in H');
        let T := type of H in
        fold (id T) in H
    end; unfold id in *.

Ltac clear_relation_equivalence :=
  repeat match goal with
    | H : ?R1 <~> ?R2 |- _ =>
        (unify R1 R2; clear H) + (is_var R1; clear R1 H) + (is_var R2; clear R2 H)
    end.

Ltac apply_relation_equivalence :=
  clear_relation_equivalence;
  rewrite_relation_equivalence_right;
  clear_relation_equivalence;
  rewrite_relation_equivalence_left;
  clear_relation_equivalence.

Closes R1 x y or R2 x y from R1 <~> R2 directly. apply_relation_equivalence only rewrites, and setoid_rewrite leaves the conclusion untouched when both sides of <~> are applications, as the head relations head_rel _ _ D of a context PER are for two witnesses D.
Ltac use_relation_equivalence :=
  match goal with
  | H : ?R1 <~> ?R2 |- ?R1 _ _ => apply H
  | H : ?R1 <~> ?R2 |- ?R2 _ _ => apply H
  end.
