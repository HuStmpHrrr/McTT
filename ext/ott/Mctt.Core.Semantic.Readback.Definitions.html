Generalizable All Variables.

Fresh Variables of the Telescopes of an Inductive Type

The readback of a stuck eliminator reads its motive and its branches under fresh variables, of the types the declaration gives: the non-uniform parameters, the arguments of a constructor, and the recursive results. Each type is evaluated in the environment of the variables before it, which holds each variable at its type; nothing is built. A variable of a propositional type is a neutral proof.
A telescope, outermost first: fresh_tele ρ T s vs gives the variables from s on, the type of each evaluated in ρ extended by those before it.
Inductive fresh_tele (Θ : gdeps) (Ξ : gstack) : env -> list centry -> nat -> list domain -> Prop :=
No entry
| fresh_tele_nil :
  `( Ftele nil in Θ ⍮ Ξ ⍮ ρ ⍮ s ↘ nil )
The first entry's variable at its type, then the rest with it in the environment
| fresh_tele_cons :
  `( ⟦ A ⟧ Θ ⍮ Ξ ⍮ ρ ↘ a ->
     Ftele T in Θ ⍮ Ξ ⍮ ρ ↦ ⇑! a s ⦂ entry_type_closure A ρ ⍮ S s ↘ vs ->
     Ftele ce_ass κ A :: T in Θ ⍮ Ξ ⍮ ρ ⍮ s ↘ ⇑! a s :: vs )
where "'Ftele' T 'in' Θ '⍮' Ξ '⍮' ρ '⍮' s ↘ vs" := (fresh_tele Θ Ξ ρ T s vs) : type_scope.

The arguments of a constructor of p at the uniform parameters ups: a non-recursive one of the type its declaration gives, in the environment of the parameters and the non-recursive arguments before it; a recursive one of the type of its shape there.
Inductive fresh_cargs (Θ : gdeps) (Ξ : gstack) (p : qname) (ups : list domain) :
  env -> list carg -> nat -> list domain -> Prop :=
No argument
| fresh_cargs_nil :
  `( Fcargs nil of p ups in Θ ⍮ Ξ ⍮ ρ ⍮ s ↘ nil )
A non-recursive argument: its variable at its declared type
| fresh_cargs_arg :
  `( ⟦ A ⟧ Θ ⍮ Ξ ⍮ ρ ↘ a ->
     Fcargs gs of p ups in Θ ⍮ Ξ ⍮ ρ ↦ ⇑! a s ⦂ entry_type_closure A ρ ⍮ S s ↘ vs ->
     Fcargs ca_arg r A :: gs of p ups in Θ ⍮ Ξ ⍮ ρ ⍮ s ↘ ⇑! a s :: vs )
A recursive argument: its variable at its shape's type, which is relevant
| fresh_cargs_rec :
  `( ⟦shty t of p ups ⟧ Θ ⍮ Ξ ⍮ ρ ↘ a ->
     Fcargs gs of p ups in Θ ⍮ Ξ ⍮ ρ ⍮ S s ↘ vs ->
     Fcargs ca_rec t :: gs of p ups in Θ ⍮ Ξ ⍮ ρ ⍮ s ↘ ⇑! a s :: vs )
where "'Fcargs' gs 'of' p ups 'in' Θ '⍮' Ξ '⍮' ρ '⍮' s ↘ vs" := (fresh_cargs Θ Ξ p ups ρ gs s vs) : type_scope.

The fresh variables of the recursive results along the leaf paths of an argument: one at each type as lists whose flag is true (a path of the container's, E1′), from s on; none where it is false.
Inductive fresh_leaf_vars : list bool -> list domain -> nat -> list domain -> Prop :=
No path left
| fresh_leaf_vars_nil : forall s, fresh_leaf_vars nil nil s nil
A path of the container's: a fresh variable at its type
| fresh_leaf_vars_fresh : forall bs a as' s vs,
    fresh_leaf_vars bs as' (S s) vs -> fresh_leaf_vars (true :: bs) (a :: as') s (⇑! a s :: vs)
A path nested through: none
| fresh_leaf_vars_skip : forall bs a as' s vs,
    fresh_leaf_vars bs as' s vs -> fresh_leaf_vars (false :: bs) (a :: as') s vs.

The recursive results of the arguments vs of kinds gs: one per leaf path of each argument recursive also in gs' (the kinds the eliminator read has them in, E1′, of the group Dc) that is a path of Dc's (leaf_in), of the type of its recursive result, the motives As in ρ, the shape's components in the environment ρa of the parameters and the non-recursive arguments before it, as gs has them, of the group at p at ups. A path nested through (of an argument recursive in gs only, or through a field the container's record view has as non-recursive) has no variable; its result is the eliminator's (wrap_ihs_eval).
Inductive fresh_ihs (Θ : gdeps) (Ξ : gstack) (ρ : env) (As : list exp) (p : qname) (ups : list domain) (Dc : ind_decl) :
  env -> list carg -> list carg -> list domain -> nat -> list domain -> Prop :=
No argument, no result
| fresh_ihs_nil :
  `( Fihs nil at nil nil of Dc under ρ As at p ups in Θ ⍮ Ξ ⍮ ρa ⍮ s ↘ nil )
A non-recursive argument: none, the argument entering ρa
| fresh_ihs_arg :
  `( Fihs vs at gs' gs of Dc under ρ As at p ups in Θ ⍮ Ξ ⍮ ρa ↦ v ⦂ entry_type_closure T ρa ⍮ s ↘ ihs ->
     Fihs v :: vs at (ca_arg ra' T' :: gs') (ca_arg ra T :: gs) of Dc under ρ As at p ups in Θ ⍮ Ξ ⍮ ρa ⍮ s ↘ ihs )
An argument recursive in both: a fresh variable at each recursive result's type, along the paths of the container's
| fresh_ihs_rec :
  `( ind_lookup Θ Ξ p = Some D ->
     ⟦ihty v of t at p ups under ρ As ⟧ Θ ⍮ Ξ ⍮ ρa ↘ as' ->
     fresh_leaf_vars (List.map (leaf_in Dc t') (shape_leaves (rview_leaves D) 0 t)) as' s ihs1 ->
     Fihs vs at gs' gs of Dc under ρ As at p ups in Θ ⍮ Ξ ⍮ ρa ⍮ (List.length ihs1 + s) ↘ ihs ->
     Fihs v :: vs at (ca_rec t' :: gs') (ca_rec t :: gs) of Dc under ρ As at p ups in Θ ⍮ Ξ ⍮ ρa ⍮ s ↘ ihs1 ++ ihs )
An argument recursive in gs only (nested through): no variable
| fresh_ihs_nest :
  `( Fihs vs at gs' gs of Dc under ρ As at p ups in Θ ⍮ Ξ ⍮ ρa ⍮ s ↘ ihs ->
     Fihs v :: vs at (ca_arg ra' T' :: gs') (ca_rec t :: gs) of Dc under ρ As at p ups in Θ ⍮ Ξ ⍮ ρa ⍮ s ↘ ihs )
where "'Fihs' vs 'at' gs' gs 'of' Dc 'under' ρm As 'at' p ups 'in' Θ '⍮' Ξ '⍮' ρ '⍮' s ↘ ihs" :=
  (fresh_ihs Θ Ξ ρm As p ups Dc ρ gs' gs vs s ihs) : type_scope.

The recursive results along the leaf paths of an argument, its group's rs and the container's variables ihs: the next variable at a path of the container's, the group's result at a path nested through; ihs' are the variables left.
Inductive wrap_leaf_vals : list bool -> list domain -> list domain -> list domain -> list domain -> Prop :=
No path left
| wrap_leaf_vals_nil : forall ihs, wrap_leaf_vals nil nil ihs ihs nil
A path of the container's: its variable
| wrap_leaf_vals_fresh : forall bs r rs ih ihs ihs' out,
    wrap_leaf_vals bs rs ihs ihs' out -> wrap_leaf_vals (true :: bs) (r :: rs) (ih :: ihs) ihs' (ih :: out)
A path nested through: the group's result
| wrap_leaf_vals_nest : forall bs r rs ihs ihs' out,
    wrap_leaf_vals bs rs ihs ihs' out -> wrap_leaf_vals (false :: bs) (r :: rs) ihs ihs' (r :: out).

The recursive results a branch of a block is read under, when the branch is read as one of the eliminator of the group the eliminated member is at (E1′): the arguments vs of the constructor are those of that group's Dc, of kinds gs'; the branch's group classifies them as gs. Along a path of Dc's, the recursive result ihs gives (a fresh variable); along one nested through, the eliminator of the branch's group. For an eliminator read as its own group's, Dc is the group, gs' is gs and the results are ihs.
Inductive wrap_ihs_eval (Θ : gdeps) (Ξ : gstack) (ρ : env) (p : qname) (ups : list domain) (Bks : list eblock) (Dc : ind_decl) :
  list carg -> list carg -> list domain -> list domain -> list domain -> Prop :=
No argument, no result
| wrap_ihs_eval_nil :
  `( ⟦wihs nil of nil nil of Dc with nil under p ups Bks ⟧ Θ ⍮ Ξ ⍮ ρ ↘ nil )
Recursive in both: along each path, the next of ihs at a path of the container's, the eliminator at one nested through
| wrap_ihs_eval_rec :
  `( ind_lookup Θ Ξ p = Some D ->
     ⟦ih v of t under p ups Bks ⟧ Θ ⍮ Ξ ⍮ ρ ↘ rs ->
     wrap_leaf_vals (List.map (leaf_in Dc t') (shape_leaves (rview_leaves D) 0 t)) rs ihs ihs' r1 ->
     ⟦wihs vs of gs' gs of Dc with ihs' under p ups Bks ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r ->
     ⟦wihs v :: vs of (ca_rec t' :: gs') (ca_rec t :: gs) of Dc with ihs under p ups Bks ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r1 ++ r )
Recursive for the branch's group only: the eliminator at the argument, along each path
| wrap_ihs_eval_nest :
  `( ⟦ih v of t under p ups Bks ⟧ Θ ⍮ Ξ ⍮ ρ ↘ rs ->
     ⟦wihs vs of gs' gs of Dc with ihs under p ups Bks ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r ->
     ⟦wihs v :: vs of (ca_arg ra' T' :: gs') (ca_rec t :: gs) of Dc with ihs under p ups Bks ⟧ Θ ⍮ Ξ ⍮ ρ ↘ rs ++ r )
Non-recursive: no result
| wrap_ihs_eval_arg :
  `( ⟦wihs vs of gs' gs of Dc with ihs under p ups Bks ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r ->
     ⟦wihs v :: vs of (ca_arg ra' T' :: gs') (ca_arg ra T :: gs) of Dc with ihs under p ups Bks ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r )
where "'⟦wihs' vs 'of' gs' gs 'of' Dc 'with' ihs 'under' p ups Bks '⟧' Θ '⍮' Ξ '⍮' ρ '↘' r" :=
  (wrap_ihs_eval Θ Ξ ρ p ups Bks Dc gs' gs vs ihs r) : type_scope.

How far past an entry the definition binding it reaches: a module entry is bound by its stored unit (read_entry_mod), written over the entry's tail, so it reaches the free variables of the unit; a term entry is bound by the readback of its value, which names no position of the environment. A definition with a module part is bound by its term part and its stored unit (read_entry_dm), so it reaches the free variables of the unit as a module entry does.
Definition entry_unit_bound (e : dentry) : nat :=
  match e with
  | de_mod _ U => gunit_free_bound U
  | de_dm _ _ _ U => gunit_free_bound U
  | _ => 0
  end.

proof_scope_from ρ j n: the least scope at least n that is closed under the stored units of the entries from j on, ρ the environment from j on: the entry at j, if inside the scope, widens it to the positions its unit reaches past it. A unit reaches only into its own tail, so one walk outwards from the innermost entry reaches the closure; the recursion is on ρ.
Fixpoint proof_scope_from (ρ : env) (j n : nat) : nat :=
  match ρ with
  | nil => n
  | e :: ρ' => if Nat.ltb j n then proof_scope_from ρ' (S j) (Nat.max n (S j + entry_unit_bound e)) else n
  end.

The environment positions the readback of a kept proof ⋆ᵈ⟨M, ρ⟩ binds: those up to the largest free index of M, so that M is copied as written, closed under the stored units of the module entries among them, which are copied too and may reach further into ρ. For example:
  • a proof #0.h selected from a global module p at the argument 3 is kept over ρ = (3 at its parameter's type) ↦ᵐ (p 3) ⦂ p #0 (eval_sel_global_proof): the scope is 1 by #0.h, widened to 2 by the unit p #0, and the proof reads back as let n : ℕ ≔ 3 in let module y ≔ p #0 in y.h;
  • under λ x, a proof #0.h in ℓₘ (F #0) in … is kept over ρ ↦ x ⦂ … ↦ᵐ h ⦂ F #0: the scope is widened from 1 to 2, so that x is bound too.
Definition proof_scope (M : exp) (ρ : env) : nat := proof_scope_from ρ 0 (exp_free_bound M).

Readback of values into normal and neutral forms in a context with s variables. The global context is needed to evaluate closures.
Inductive read_nf (Θ : gdeps) (Ξ : gstack) : nat -> domain_nf -> nf -> Prop :=
| read_nf_type :
  `( Rtyp a in Θ ⍮ Ξ ⍮ s ↘ A ->
     Rnf ⇓ 𝕌ω@i a in Θ ⍮ Ξ ⍮ s ↘ A )
| read_nf_stype :
  `( Rtyp a in Θ ⍮ Ξ ⍮ s ↘ A ->
     Rnf ⇓ 𝕌@n a in Θ ⍮ Ξ ⍮ s ↘ A )
A level reads back canonically: its atoms are read, then sorted and merged, and a dominated constant is dropped (lvl_canon). Evaluation flattens only, so this is where levels equal by the level equations become the same normal form. A neutral level is the single atom at offset 0, of the sort of its type (domain_level_sort), which is already canonical: the sort is read off the neutral's type, not off the type it is read back at. Its atom is stored as read, as lvl_canon stores atoms.
| read_nf_lvl :
  `( Rla xs in Θ ⍮ Ξ ⍮ s ↘ ys ->
     Rnf ⇓ (Levelᵈ@n) (lvᵈ c xs) in Θ ⍮ Ξ ⍮ s ↘ nf_lvl_of (lvl_canon (c, ys)) )
| read_nf_lvl_neut :
  `( Rne m in Θ ⍮ Ξ ⍮ s ↘ M ->
     Rnf ⇓ (Levelᵈ@n) (⇑ a m) in Θ ⍮ Ξ ⍮ s ↘ lvⁿ ordinal_zero (mk_level_atom 0 (domain_level_sort a) M :: nil) )
A value of a proposition reads back as a proof term (read_proof), with the proposition read back as a type. This is the only rule at a propositional type.
| read_nf_proof :
  `( domain_kind a = ak_propositional ->
     Rtyp a in Θ ⍮ Ξ ⍮ s ↘ P ->
     Rprf m in Θ ⍮ Ξ ⍮ s ↘ M ->
     Rnf ⇓ a m in Θ ⍮ Ξ ⍮ s ↘ nf_proof P M )
A proposition, as an element of Prop, reads back as a type.
| read_nf_prop :
  `( Rtyp a in Θ ⍮ Ξ ⍮ s ↘ A ->
     Rnf ⇓ Propᵈ a in Θ ⍮ Ξ ⍮ s ↘ A )
So does a type of levels, as an element of LevelSort.

A function, η-long: its body applied to a fresh variable of its domain. Its codomain is not a proposition (a function into propositions is a proof, read_nf_proof).
| read_nf_fn :

     evaluated_kind κc ->

A constructor at all its parameters and arguments: the parameters are read off the type, at the types the declaration gives them, and the arguments at theirs.
