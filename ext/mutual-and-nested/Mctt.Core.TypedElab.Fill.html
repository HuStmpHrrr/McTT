The Typed Fill

The elaborator is untyped, and leaves three things to the command judgment, which fills them in one depth-first pass over each command before the command runs, each part read in the context algorithmic typing (alg_type_infer) reads it in:
  • Literals: where the natural numbers are bound (Builtin), a numeral (a_nlit) stands for the chain of the bound type's constructors and the token ℕ (a_ntok) for its type former. Without a binding a literal has no fill.
  • Eliminators: an eliminator as written carries no group and no uniform parameters (a_elim None nil m Bks M). They are read off its scrutinee's inferred type (elim_target): the eliminator is filled when exactly one reading of it fits its blocks.
  • Accesses: for e.f the elaborator emits the member f of the module expression e stands for, and when e is a term (a term binder, a term member of a module, a term applied) that module expression has a term at its head, which no typing rule accepts. A term M whose type infers to the record type p at the parameters Rs stands, in module position, for the record's module at Rs, then M (record_value_module): 
        (λ (q : Pair ℕ ℕ) → q.fst)   is filled to   (λ (q : Pair ℕ ℕ) → (Pair ℕ ℕ q).fst)
    A member selected from the module of a record value must be accessible (sel_ok): privacy is checked on the command as written, where the selection is from a term, so it is checked here once the record is known.
Every command and every unit's parameter telescope is filled; a term with nothing to fill is filled to itself. The filled command is ordinary core and runs as any command does. The fill reads algorithmic inference (⊢a), which gives one type (functional_alg_type_infer), so the fill, and the run, are functional.

A member y selected from the module of a record value, the record p when it is one (Some p), is accessible, as glob_ok says of any member of a module named by its path. A selection from any other module is checked as written.
  Definition sel_ok (op : option qname) (y : string) : Prop :=
    match op with
    | None => True
    | Some p => glob_ok Θ Ξ (qname_mod p) y
    end.

A term with no subterm and nothing to fill: filled to itself. The literals are filled by their own rules.
  Definition exp_leaf (M : exp) : bool :=
    match M with
    | a_typ _ | a_level _ | a_llit _ | a_True | a_true | a_False
    | a_ind _ _ | a_con _ _ _ | a_var _ | a_record _ => true
    | _ => false
    end.

The binder k of Γ holds a term only, an assumption or a definition, and so reads as a term in module position.
  Definition term_binder (Γ : ctx) (k : nat) : Prop :=
    match List.nth_error Γ k with
    | Some (ce_ass _) | Some (ce_def _ _) => True
    | _ => False
    end.

The Fill of Terms

fill_exp Γ M M': the term M, read in Γ, filled, is M'. The contexts are those of algorithmic typing: a binder's type is its filled type; an unannotated let binds its definition at the type it infers; an eliminator's annotations, motives and branches are read in the contexts alg_type_infer_elim reads them in, at its group and its uniform parameters and filled motives; a local body's entries in the context of the expansion of the filled entries before them (body_xp).

A term with no subterm and nothing to fill
  | fill_exp_leaf : forall Γ M, exp_leaf M = true -> fill_exp Γ M M
  
A numeral: the chain of the bound type's constructors
  | fill_exp_nlit : forall Γ n p z s,
      nat_view Θ Ξ B = Some (p, z, s) -> fill_exp Γ (a_nlit n) (nat_chain p z s n)
  
The token ℕ: the bound type's type former
  | fill_exp_ntok : forall Γ p z s,
      nat_view Θ Ξ B = Some (p, z, s) -> fill_exp Γ a_ntok (a_ind p 0)
  
A universe at a level
  | fill_exp_univ : forall Γ M M', fill_exp Γ M M' -> fill_exp Γ (a_univ M) (a_univ M')
  
A level's successor
  | fill_exp_succl : forall Γ M M', fill_exp Γ M M' -> fill_exp Γ (a_succl M) (a_succl M')
  
A join of levels
  | fill_exp_maxl : forall Γ M M' N N', fill_exp Γ M M' -> fill_exp Γ N N' -> fill_exp Γ (a_maxl M N) (a_maxl M' N')

A λ: the body under the filled domain

An application

      fill_exp Γ (a_let (b_def None M) B) (a_let (b_def None M') B')
  
A local module: the rest under the filled unit
  | fill_exp_let_mod : forall Γ U U' B B',
      fill_unit Γ U U' -> fill_exp (Γ ▹ₘ U') B B' -> fill_exp Γ (a_let (b_mod U) B) (a_let (b_mod U') B')
  
A member: its module filled; a member of a record value's module accessible
  | fill_exp_mem : forall Γ H H' op x,

A record value: its type and its fields
  | fill_exp_tuple : forall Γ T T' fs fs',

A projection
  | fill_exp_proj : forall Γ f M M', fill_exp Γ M M' -> fill_exp Γ (a_proj f M) (a_proj f M')
  
An eliminator as written: its scrutinee filled; its group p and uniform parameters Us the one reading of it that fits its blocks, read off the scrutinee's inferred type (elim_target); its blocks at them and at the filled motives
  | fill_exp_elim : forall Γ m Bks Bks' M M' pc k Rs p D Us,

The blocks of an eliminator of the group p, D, from the member j on, at the uniform parameters Us and the motives As: each its annotation over its member's non-uniform parameters, its motive over them and the scrutinee, and its branches, with as many binders as alg_type_infer_elim asks
  with fill_blocks : ctx -> qname -> ind_decl -> list exp -> list exp -> nat -> list eblock -> list eblock -> Prop :=
  
No block
  | fill_blocks_nil : forall Γ p D Us As j, fill_blocks Γ p D Us As j nil nil
  
The block of the member j, then the rest
  | fill_blocks_cons : forall Γ p D Us As j Mj nm oZ oZ' A A' Bs Bs' Bks Bks',
      ind_member D j = Some Mj ->
      nm = S (im_nn Mj) ->

      fill_exp (elim_mctx p D j Mj Us ++ Γ) A A' ->
      fill_brs Γ p D Mj Us As Bs Bs' ->
      fill_blocks Γ p D Us As (S j) Bks Bks' ->
      fill_blocks Γ p D Us As j (eb_mk nm oZ A Bs :: Bks) (eb_mk nm oZ' A' Bs' :: Bks')

  
The branches of a block of the member Mj, each in its constructor's branch context
  with fill_brs : ctx -> qname -> ind_decl -> imember -> list exp -> list exp ->
                  list (string * nat * exp) -> list (string * nat * exp) -> Prop :=

  | fill_brs_nil : forall Γ p D Mj Us As, fill_brs Γ p D Mj Us As nil nil

The Fill of Commands

Each part of a command is filled in the context its run reads it in. A mutual definition's functions are filled in two steps: their parameters and scrutinees, from which the group is read (mdef_group), then their results and clauses, in the contexts the eliminator its translation files (mdef_defs) reads them in, at the motives of the translation's own blocks (mdef_blocks).
A function of a mutual definition over Γ, its parameters and scrutinee filled, as run_cmd_mdef reads them, to f'.
  Record fill_raw_fun_head (Γ : ctx) (f f' : raw_fun) : Prop := mk_fill_raw_fun_head
    {
The name is kept
      fill_raw_fun_head_name : raw_fun_name f' = raw_fun_name f
      
The parameters, over Γ, are filled
    ; fill_raw_fun_head_nparams : fill_tele Γ (raw_fun_nparams f) (raw_fun_nparams f')
      
The scrutinee's type, over the filled parameters, is filled
    ; fill_raw_fun_head_scrut : fill_exp (raw_fun_nparams f' ++ Γ) (raw_fun_scrut f) (raw_fun_scrut f')
      
The result type is kept, filled with the clauses
    ; fill_raw_fun_head_res : raw_fun_res f' = raw_fun_res f
      
The clauses are kept, filled with the result type
    ; fill_raw_fun_head_clauses : raw_fun_clauses f' = raw_fun_clauses f }.

A function f of the member m of the group D at pq, at the uniform parameters Us and the motives As, over Γ, its result and clauses filled to f': the result in the motive's context, the clauses in their branches', as alg_type_infer_elim reads them.
  Record fill_raw_fun_body (pq : qname) (D : ind_decl) (Us : list exp) (Γ : ctx) (As : list exp)
      (f : raw_fun) (m : nat) (f' : raw_fun) : Prop := mk_fill_raw_fun_body
    {
The name is kept
      fill_raw_fun_body_name : raw_fun_name f' = raw_fun_name f
      
The parameters are kept, filled already
    ; fill_raw_fun_body_nparams : raw_fun_nparams f' = raw_fun_nparams f
      
The scrutinee's type is kept, filled already
    ; fill_raw_fun_body_scrut : raw_fun_scrut f' = raw_fun_scrut f
      
The member is one of the group
    ; fill_raw_fun_body_member : ind_member D m <> None
      
The result type, over the member's parameters and the scrutinee, is filled
    ; fill_raw_fun_body_res : forall Mm, ind_member D m = Some Mm ->
        fill_exp (elim_mctx pq D m Mm Us ++ Γ) (raw_fun_res f) (raw_fun_res f')
      
The clauses, each in its constructor's branch context, are filled
    ; fill_raw_fun_body_clauses : forall Mm, ind_member D m = Some Mm ->
        fill_brs Γ pq D Mm Us As (raw_fun_clauses f) (raw_fun_clauses f') }.
