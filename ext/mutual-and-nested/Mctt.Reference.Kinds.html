The Reference Kinds of Members

The kinds of Extraction.Kinds computed with the Core lookups of Θ ⍮ Ξ, for the reference evaluator (Reference.Evaluation), which is stated at any global context. It is not extracted; Extraction.Kinds computes the same kinds through the fast context.
