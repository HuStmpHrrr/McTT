Inverting the Typing Rules

Every term former is introduced by exactly one rule, so a typing derivation for a term whose head is known says exactly what that rule says — except that wf_exp_subtyp may have been applied any number of times afterwards, which replaces "the type is A" by "the type refines to A". Each lemma below is that observation for one former, proved by induction on the derivation with only two cases: the introduction rule, where refinement is reflexivity, and wf_exp_subtyp, where it is transitivity.
Substitutions need no inversion lemmas:
  • M[σ] is not a term former, so there is nothing to invert;
  • wf_sub is a record, not an inductive family, so a derivation of Θ ⍮ Ξ ⍮ Γ ⊢ˢ σ : Δ carries no information beyond its two fields; in particular Θ ⍮ Ξ ⍮ Γ ⊢ˢ Id : Δ is itself a context refinement.

A Π is in a large universe, or in a small one at a level.
Lemma wf_pi_inversion : forall {Θ Ξ Γ A B C},
    Θ ⍮ Ξ ⍮ Γ ⊢ Π A B : C ->
    (exists i, Θ ⍮ Ξ ⍮ Γ ⊢ A : Typeω@i /\ Θ ⍮ Ξ ⍮ Γ ▹ A ⊢ B : Typeω@i /\ Θ ⍮ Ξ ⍮ Γ ⊢ Typeω@i ⊆ C) \/
    (exists L n, Θ ⍮ Ξ ⍮ Γ ⊢ L : Level@n /\ Θ ⍮ Ξ ⍮ Γ ⊢ A : Type⟨L⟩ /\ Θ ⍮ Ξ ⍮ Γ ▹ A ⊢ B : Type⟨L[↑]ʷ⟩ /\
               Θ ⍮ Ξ ⍮ Γ ⊢ Type⟨L⟩ ⊆ C).
Proof.
  intros * H.
  dependent induction H;
    try specialize (IHwf_exp1 _ _ eq_refl);
    try destruct IHwf_exp1 as [(j & ? & ? & ?) | (L' & n' & ? & ? & ? & ?)];
    repeat match goal with Hu : wf_is_univ _ _ _ _ |- _ => inversion Hu; subst; clear Hu end;
    cbn [exp_wk] in *; gen_core_presups.
  - left; eexists; mautosolve 4.
  - right; do 2 eexists; repeat split; try eassumption; mautosolve 4.
  - left; exists j; repeat split; try assumption; mautosolve 4.
  - right; exists L', n'; repeat split; try assumption; mautosolve 4.
Qed.

The level the domain and the codomain are checked at can always be taken to be the level of the Π-type itself. Moving the refinement Typeω@j ⊆ Typeω@i from Γ into Γ ▹ A is a weakening, and it is the only step that needs any work: both sides are unchanged by it (Typeω@j[↑]ʷ is Typeω@j), but only by computation, so the step is taken by hand.
Corollary wf_pi_inversion' : forall {Θ Ξ Γ A B i},
    Θ ⍮ Ξ ⍮ Γ ⊢ Π A B : Typeω@i ->
    Θ ⍮ Ξ ⍮ Γ ⊢ A : Typeω@i /\ Θ ⍮ Ξ ⍮ Γ ▹ A ⊢ B : Typeω@i.
Proof.
  intros * [[j [? []]] | [L [n [? [? []]]]]]%wf_pi_inversion.
  2:{ assert (⊢ Θ ⍮ Ξ ⍮ Γ ▹ A) by mauto 3.
      assert (Θ ⍮ Ξ ⍮ Γ ▹ A ⊢ʷ ↑ : Γ) by mauto 2.
      assert (Θ ⍮ Ξ ⍮ Γ ▹ A ⊢ L[↑]ʷ : Level@n) by (eapply (wk_preserves_exp _ _ _ _ (Level@n)); eassumption).
      split; eapply wf_exp_suniv_large; eassumption. }
  assert (⊢ Θ ⍮ Ξ ⍮ Γ ▹ A) by mauto 3.
  assert (Θ ⍮ Ξ ⍮ Γ ▹ A ⊢ʷ ↑ : Γ) by mauto 2.
  assert (Θ ⍮ Ξ ⍮ Γ ▹ A ⊢ exp_wk Typeω@j ↑ ⊆ exp_wk Typeω@i ↑) as H'
      by (eapply wk_preserves_subtyp; eassumption).
  assert (Θ ⍮ Ξ ⍮ Γ ▹ A ⊢ Typeω@j ⊆ Typeω@i) by exact H'.
  split; mauto 3.
Qed.

Inductive Types

The type former, a constructor and the eliminator are each introduced by one rule; the inversion of an application of a head is wf_apps_head.

Lemma wf_apps_head : forall {Θ Ξ Γ} Ns M T, Θ ⍮ Ξ ⍮ Γ ⊢ apps_exp M Ns : T -> exists T', Θ ⍮ Ξ ⍮ Γ ⊢ M : T'.
Proof.
  intros Θ Ξ Γ Ns; induction Ns as [| N Ns IH]; intros * H; cbn in H; [ eauto |].
  destruct (IH _ _ H) as (T' & HT'); destruct (wf_app_inversion HT') as (X & Y & HM & _); eauto.
Qed.

Lemma wf_subtyp_of_typed : forall {Θ Ξ Γ M A}, Θ ⍮ Ξ ⍮ Γ ⊢ M : A -> Θ ⍮ Ξ ⍮ Γ ⊢ A ⊆ A.
Proof.
  intros * H; destruct (presup_exp_typ H) as [i Hi].
  eapply wf_subtyp_refl; [ exact Hi | apply wf_exp_eq_refl; exact Hi ].
Qed.

What the eliminator a_elim oq Us m Bks M is typed by: the premises of wf_elim, and the type it gives below T. The stored uniform parameters are exactly those of the derivation (elim_inv_ups): convertible ones are reached only through the congruence rule.

Record elim_inv (Θ : gdeps) (Ξ : gstack) (Γ : ctx) (oq : option qname) (Us : list exp) (m : nat)
    (Bks : list eblock) (M T : typ) : Prop := mk_elim_inv
  {
The group's path
    elim_inv_grp : qname
    
The group
  ; elim_inv_decl : ind_decl
    
The scrutinee's member
  ; elim_inv_mem : imember
    
That member's block
  ; elim_inv_block : eblock
    
The scrutinee type's parameters, uniform then non-uniform
  ; elim_inv_params : list exp
    
The motives' level
  ; elim_inv_lvl : nat
    
The group is found at its path
  ; elim_inv_lookup : ind_lookup Θ Ξ elim_inv_grp = Some elim_inv_decl
    
The eliminator's group annotation names it
  ; elim_inv_elim_grp : elim_grp elim_inv_decl oq elim_inv_grp m
    
The member is the group's m-th
  ; elim_inv_member : ind_member elim_inv_decl m = Some elim_inv_mem
    
Its block is the m-th
  ; elim_inv_nth : List.nth_error Bks m = Some elim_inv_block
    
There are as many parameters as the member has
  ; elim_inv_plen : List.length elim_inv_params = im_np elim_inv_decl elim_inv_mem
    
Each parameter is typed at the member's telescope
  ; elim_inv_ps : forall k P T, List.nth_error elim_inv_params k = Some P ->
      List.nth_error (tele_insts (im_params elim_inv_decl elim_inv_mem) Id elim_inv_params) k = Some T -> Θ ⍮ Ξ ⍮ Γ ⊢ P : T
    
The scrutinee is of the member's type at the parameters
  ; elim_inv_scrut : Θ ⍮ Ξ ⍮ Γ ⊢ M : ind_mty elim_inv_grp elim_inv_decl m (List.firstn (ind_nu elim_inv_decl) elim_inv_params)
                                 (List.skipn (ind_nu elim_inv_decl) elim_inv_params)
    
The stored uniform parameters are the derivation's
  ; elim_inv_ups : Us = List.firstn (ind_nu elim_inv_decl) elim_inv_params
    
The blocks are typed
  ; elim_inv_blocks : blocks_typed Θ Ξ Γ elim_inv_grp elim_inv_decl (List.firstn (ind_nu elim_inv_decl) elim_inv_params) Bks elim_inv_lvl
    
The block's motive at the non-uniform parameters and the scrutinee is below T
  ; elim_inv_sub : Θ ⍮ Ξ ⍮ Γ ⊢ (eb_motive elim_inv_block)[sb_of_list Id (List.skipn (ind_nu elim_inv_decl) elim_inv_params ++ M :: nil)] ⊆ T }.

Lemma wf_elim_inversion : forall {Θ Ξ Γ oq Us m Bks M T}, Θ ⍮ Ξ ⍮ Γ ⊢ a_elim oq Us m Bks M : T ->
    elim_inv Θ Ξ Γ oq Us m Bks M T.
Proof.
  intros * H; dependent induction H.
  - econstructor; try eassumption; try reflexivity; [ constructor; eassumption |].
    eapply wf_subtyp_of_typed; eapply wf_elim; try eassumption; reflexivity.
  - destruct (IHwf_exp1 _ _ _ _ _ eq_refl) as [p D Mm bm Ps i0 Hl Hg Hm Hb HPl HPs HM HUs HBt Hs].
    econstructor; try eassumption; eapply wf_subtyp_trans; eassumption.
Qed.
