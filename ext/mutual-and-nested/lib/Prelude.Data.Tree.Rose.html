Prelude›Data›Tree›Rose

Rose trees, a nested inductive type: a tree node x ts has a label x : A and a list ts : List u (Rose u A) of children, the lists of Prelude›Data›List. The occurrence of Rose u A inside List makes List u (Rose u A), the forests, a view of Rose: its eliminator has a block for Rose u A and one for the view, and a mutual definition a function for each.

The operations over a fixed A are in the module Ops u A, each a pair of functions, one on trees and one on forests: the number of nodes size and sizeForest, the depth depth and depthForest, map and mapForest, the preorder lists of labels flatten and flattenForest, and the folds fold and foldForest. The laws are in Prelude›Data›Tree›Rose›Properties.

module Prelude›Data›Tree›Rose where

import Prelude›Builtin›Nat use (succ)
import Prelude›Arith›Plus use (plus)
import Prelude›Arith›MinMax use (max)
import Prelude›Data›List use (List)
open Prelude›Data›List.Ops as LO

The children are a List of trees, at the same uniform parameters.

inductive Rose (u : Level) (A : Type@{u}) : Type@{u} where
| node (x : A) (ts : List u (Rose u A))
end

module Ops (u : Level) (A : Type@{u}) where

private inductive T ≔ Rose u A

private inductive F ≔ List u T

A tree without children.

def leaf (x : A) : T ≔ T.node x F.nil end

The number of nodes. The function on forests is at the view List u T; h is sizeForest ts, and ht and hts are the sizes of the first tree and of the rest.

mutual def
  size (t : T) : ℕ ≔
  | node x ts, h ⇒ succ h
  with sizeForest (ts : F) : ℕ ≔
  | nil ⇒ 0
  | cons t ts, ht hts ⇒ plus ht hts
end

The depth: the number of nodes on a longest path from the root, so a leaf has depth 1 and the empty forest depth 0.

mutual def
  depth (t : T) : ℕ ≔
  | node x ts, h ⇒ succ h
  with depthForest (ts : F) : ℕ ≔
  | nil ⇒ 0
  | cons t ts, ht hts ⇒ max ht hts
end

The labels changed by f, the shape kept. The parameters B and f are shared by both functions; the forest of the result is at the view List u (Rose u B).

mutual def (B : Type@{u}) (f : ∀ (x : A) → B)
  map (t : T) : Rose u B ≔
  | node x ts, h ⇒ Rose.node u B (f x) h
  with mapForest (ts : F) : List u (Rose u B) ≔
  | nil ⇒ List.nil u (Rose u B)
  | cons t ts, ht hts ⇒ List.cons u (Rose u B) ht hts
end

The labels in preorder: a node's label, then those of its children, left to right.

mutual def
  flatten (t : T) : List u A ≔
  | node x ts, h ⇒ List.cons u A x h
  with flattenForest (ts : F) : List u A ≔
  | nil ⇒ List.nil u A
  | cons t ts, ht hts ⇒ LO.append u A ht hts
end

The fold, into R at trees and S at forests: node combines a label with the result of its children, cons the results of a tree and of the forest after it. It is the eliminator with both blocks at constant motives, the tree's block marked at in fold and the forest's in foldForest. When single types have a recursor module, these move to Rose.Rec.

def fold (R : Type@{u}) (S : Type@{u}) (node : ∀ (x : A) (s : S) → R)
    (nil : S) (cons : ∀ (r : R) (s : S) → S) (t : T) : R ≔
  elim t at (z : T) -> R
  | node x ts, h ⇒ node x h
  with (z : F) -> S
  | nil ⇒ nil
  | cons s ts, hs hts ⇒ cons hs hts
  end
end

def foldForest (R : Type@{u}) (S : Type@{u}) (node : ∀ (x : A) (s : S) → R)
    (nil : S) (cons : ∀ (r : R) (s : S) → S) (ts : F) : S ≔
  elim ts with (z : T) -> R
  | node x us, h ⇒ node x h
  at (z : F) -> S
  | nil ⇒ nil
  | cons s us, hs hus ⇒ cons hs hus
  end
end

end
