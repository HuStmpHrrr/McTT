Prelude›Data›Ordering

The result of a comparison: less, equal or greater. The type carries no evidence; the proposition Spec m n o states what an outcome o of comparing m and n means.

compare m n compares two numbers, flip exchanges less and greater, and thenCmp o p is the lexicographic combination: o, unless it is equal, then p. The laws, among them that compare meets Spec, are in Prelude›Data›Ordering›Properties.

module Prelude›Data›Ordering where

import Prelude›Builtin›Nat use (succ)
import Prelude›Arith›Equality use (Eq)
import Prelude›Arith›Order use (Lt)

inductive Ordering : Type@0 where
| less
| equal
| greater
end

open Ordering use (less; equal; greater)

def flip (o : Ordering) : Ordering ≔
  elim o at z -> Ordering
  | less ⇒ greater
  | equal ⇒ equal
  | greater ⇒ less
  end
end

By recursion on m, then cases on n: two successors compare as their predecessors.

def compare (m : ℕ) : ∀ (n : ℕ) → Ordering ≔
  elim m at x -> (∀ (n : ℕ) → Ordering)
  | zero ⇒ λ (n : ℕ) →
      elim n at y -> Ordering | zero ⇒ equal | succ q, s ⇒ less end
  | succ p, r ⇒ λ (n : ℕ) →
      elim n at y -> Ordering | zero ⇒ greater | succ q, s ⇒ r q end
  end
end

What an outcome of comparing m and n means: Lt m n for less, Eq m n for equal and Lt n m for greater.

def Spec (m : ℕ) (n : ℕ) (o : Ordering) : Type@0 ≔
  elim o at z -> Type@0
  | less ⇒ Lt m n
  | equal ⇒ Eq m n
  | greater ⇒ Lt n m
  end
end

def thenCmp (o : Ordering) (p : Ordering) : Ordering ≔
  elim o at z -> Ordering
  | less ⇒ less
  | equal ⇒ p
  | greater ⇒ greater
  end
end

end
