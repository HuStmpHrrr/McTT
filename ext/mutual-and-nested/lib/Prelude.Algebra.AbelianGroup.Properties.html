Prelude›Algebra›AbelianGroup›Properties

Laws of an abelian group A, up to A.eq: the inverse of a product is the product of the inverses, in either order, and the inverse is a homomorphism from A to itself. The laws of every group are Prelude›Algebra›Group›Properties at A.group.

import Prelude›Algebra›AbelianGroup
module Prelude›Algebra›AbelianGroup›Properties (c : Level) (r : Level)
    (A : Prelude›Algebra›AbelianGroup.AbelianGroup c r) where

import Prelude›Algebra›Group›Properties c r A.group as GP
import Prelude›Algebra›Group›Hom c r use (Hom)

open A use (carrier as C)

inv (a b) = inv b inv a = inv a inv b.

theorem invOp : ∀ (a : C) (b : C) →
    A.eq (A.inv (A.op a b)) (A.op (A.inv a) (A.inv b)) ≔
  λ (a : C) (b : C) →
    A.trans (A.inv (A.op a b)) (A.op (A.inv b) (A.inv a))
      (A.op (A.inv a) (A.inv b))
      (GP.Laws.invOp a b) (A.comm (A.inv b) (A.inv a))
end

The inverse, as a homomorphism from A to itself.

def invHom : Hom A.group A.group ≔
  record Hom A.group A.group where
    map ≔ A.inv; mapCong ≔ A.invCong; mapOp ≔ invOp
  end
end
