Prelude›Data›Sigma

Dependent pairs: Sigma is the record of a first component fst : A and a second snd : B fst, whose type depends on the first; pair a b builds one, for a : A and b : B a.

The unit takes the level u, the type A of first components and the family B of second components as parameters: Prelude›Data›Sigma 0l ℕ (λ (n : ℕ) → NV.Vec n), with NV the vectors of numbers, holds the vectors of every length. The fields are also the projections as functions, fst p and snd p : B (fst p), exported from the record's module. A record has eta, so every p : Sigma is pair p.fst p.snd by conversion. Its laws are in Prelude›Data›Sigma›Properties.

module Prelude›Data›Sigma (u : Level) (A : Type@{u})
    (B : ∀ (a : A) → Type@{u}) where

record Sigma : Type@{u} where
  fst : A;
  snd : B fst
end

open Sigma export (fst; snd)

def pair (a : A) (b : B a) : Sigma ≔ record Sigma where fst ≔ a; snd ≔ b end end

end
