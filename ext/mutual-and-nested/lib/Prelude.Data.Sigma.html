Prelude›Data›Sigma

Dependent pairs: Sigma u A B has the one constructor pair a b, for a : A and b : B a, at every level u. The type of the second component depends on the first, so snd p has the type B (fst p).

The unit takes the level u, the type A of first components and the family B of second components as parameters: Prelude›Data›Sigma 0l ℕ (λ (n : ℕ) → Vec n) holds the vectors of every length. Its laws are in Prelude›Data›Sigma›Properties.

module Prelude›Data›Sigma (u : Level) (A : Type@{u})
    (B : ∀ (a : A) → Type@{u}) where

inductive Sigma : Type@{u} where
| pair (a : A) (b : B a)
end

open Sigma use (pair)

def fst (p : Sigma) : A ≔
  elim p at (z : Sigma) -> A | pair a b ⇒ a end
end

The second component; the branch's type, B (fst (pair a b)), computes to B a.

def snd (p : Sigma) : B (fst p) ≔
  elim p at (z : Sigma) -> B (fst z) | pair a b ⇒ b end
end

end
