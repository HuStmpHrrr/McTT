Prelude›Algebra›Instances›Nat

The numbers as instances of the structures of Prelude›Algebra, up to the equality of numbers Eq of Prelude›Arith›Equality, which computes, so a closed law between numbers normalizes to ⋆: commutative monoids under addition (additive), multiplication (multiplicative) and maximum (maximum), the semiring of addition and multiplication (semiring), and the lattice of min and max (minMax). Eq is a relation into Type@0, so the level is 0l.

Every operation on numbers respects Eq (congBoth), so each magma predicate comes from magmaOf; the predicates of addition and multiplication are named, so that the semiring reuses them.

Every binary operation on numbers respects equality on both sides.

theorem congBoth : ∀ (f : ∀ (x : ℕ) (y : ℕ) → ℕ)
    (a : ℕ) (b : ℕ) (c : ℕ) (d : ℕ) (hac : Eq a c) (hbd : Eq b d) →
    Eq (f a b) (f c d) ≔
  λ (f : ∀ (x : ℕ) (y : ℕ) → ℕ) (a : ℕ) (b : ℕ) (c : ℕ) (d : ℕ)
    (hac : Eq a c) (hbd : Eq b d) →
    trans (f a b) (f c b) (f c d)
      (cong (λ (y : ℕ) → f y b) a c hac)
      (cong (λ (y : ℕ) → f c y) b d hbd)
end

def eqIsEquivalence : IsEquivalence ℕ Eq ≔
  record IsEquivalence ℕ Eq where refl ≔ refl; sym ≔ sym; trans ≔ trans end
end

private def magmaOf (op : ∀ (a : ℕ) (b : ℕ) → ℕ) : IsMagma ℕ Eq op ≔
  record IsMagma ℕ Eq op where
    isEquivalence ≔ eqIsEquivalence; opCong ≔ congBoth op
  end
end

An associative operation on numbers.

private def semigroupOf (op : ∀ (a : ℕ) (b : ℕ) → ℕ)
    (assoc : ∀ (a : ℕ) (b : ℕ) (c : ℕ) → Eq (op (op a b) c) (op a (op b c))) :
    IsSemigroup ℕ Eq op ≔
  record IsSemigroup ℕ Eq op where isMagma ≔ magmaOf op; assoc ≔ assoc end
end

Addition, with 0; plus 0 n is n by computation.

def plusIsCommutativeMonoid : IsCommutativeMonoid ℕ Eq plus 0 ≔
  record IsCommutativeMonoid ℕ Eq plus 0 where
    isMonoid ≔
      record IsMonoid ℕ Eq plus 0 where
        isSemigroup ≔ semigroupOf plus plusAssoc;
        leftId ≔ refl;
        rightId ≔ plusIdentityRight
      end;
    comm ≔ plusComm
  end
end

def additive : CommutativeMonoid ≔

  end

The semiring of addition and multiplication, on the predicates above; mult 0 n is 0 by computation.

def semiring : Semiring ≔
  record Semiring where
    carrier ≔ ℕ; eq ≔ Eq; plus ≔ plus; mul ≔ mult; zero ≔ 0; one ≔ 1;
    isSemiring ≔
      record IsSemiring ℕ Eq plus mult 0 1 where
        plusIsCommutativeMonoid ≔ plusIsCommutativeMonoid;
        mulIsMonoid ≔ multIsCommutativeMonoid.isMonoid;
        distribLeft ≔ multDistribLeft;
        distribRight ≔ multDistribRight;
        zeroLeft ≔ λ (a : ℕ) → ⋆;
        zeroRight ≔ multZeroRight
      end
  end
end

The lattice of min and max: its order is the order of numbers.

def minMax : Lattice ≔
  record Lattice where
    carrier ≔ ℕ; eq ≔ Eq; meet ≔ min; join ≔ max;
    isLattice ≔
      record IsLattice ℕ Eq min max where
        meetIsSemilattice ≔
          record IsSemilattice ℕ Eq min where
            isSemigroup ≔ semigroupOf min minAssoc; comm ≔ minComm; idem ≔ minIdem
          end;
        joinIsSemilattice ≔
          record IsSemilattice ℕ Eq max where
            isSemigroup ≔ semigroupOf max maxAssoc; comm ≔ maxComm; idem ≔ maxIdem
          end;
        absorbMeet ≔ minMaxAbsorb;
        absorbJoin ≔ maxMinAbsorb
      end
  end
end
