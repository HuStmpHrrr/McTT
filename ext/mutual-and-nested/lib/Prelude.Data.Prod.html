Prelude›Data›Prod

Pairs: Prod u A B is the record of a first component fst : A and a second snd : B, at every level u; pair u A B a b builds one. The dependent pairs, whose second component has a type depending on the first, are Prelude›Data›Sigma.

A record has eta: every p : Prod u A B is pair u A B p.fst p.snd by conversion, so the laws of Prelude›Data›Prod›Properties hold by reflexivity. The record's own member swap exchanges the components: p.swap is pair u B A p.snd p.fst.

The operations as functions over fixed A and B are in the module Ops u A B: the projections and swap, exported from the record's module at u A B, the reassociations assoc and unassoc, map on both components, and currying.

module Prelude›Data›Prod where

record Prod (u : Level) (A : Type@{u}) (B : Type@{u}) : Type@{u} where
  fst : A;
  snd : B
with
  (* The pair with its components exchanged. *)
  def swap : Prod u B A ≔ record Prod u B A where fst ≔ snd; snd ≔ fst end end
end

def pair (u : Level) (A : Type@{u}) (B : Type@{u}) (a : A) (b : B) :
    Prod u A B ≔
  record Prod u A B where fst ≔ a; snd ≔ b end
end

module Ops (u : Level) (A : Type@{u}) (B : Type@{u}) where

fst p, snd p and swap p, the record's members at u A B.

open Prod u A B export (fst; snd; swap)

From ((a, b), c) to (a, (b, c)).

def assoc (C : Type@{u}) (p : Prod u (Prod u A B) C) :
    Prod u A (Prod u B C) ≔
  pair u A (Prod u B C) p.fst.fst (pair u B C p.fst.snd p.snd)
end

From (a, (b, c)) to ((a, b), c).

def unassoc (C : Type@{u}) (p : Prod u A (Prod u B C)) :
    Prod u (Prod u A B) C ≔
  pair u (Prod u A B) C (pair u A B p.fst p.snd.fst) p.snd.snd
end

Applies f to the first component and g to the second.

def map (C : Type@{u}) (D : Type@{u}) (f : ∀ (a : A) → C)
    (g : ∀ (b : B) → D) (p : Prod u A B) : Prod u C D ≔
  pair u C D (f p.fst) (g p.snd)
end

def curry (C : Type@{u}) (f : ∀ (p : Prod u A B) → C) (a : A) (b : B) : C ≔
  f (pair u A B a b)
end

def uncurry (C : Type@{u}) (f : ∀ (a : A) (b : B) → C) (p : Prod u A B) :
    C ≔
  f p.fst p.snd
end

end
