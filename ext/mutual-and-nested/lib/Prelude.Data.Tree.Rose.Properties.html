Prelude›Data›Tree›Rose›Properties

Laws of Prelude›Data›Tree›Rose over labels A of Type@{u}: map keeps the size, is a functor, and is List's map on forests; the preorder list of labels has the size as its length and commutes with map.

Each law about trees and forests is a mutual definition, one theorem on trees and one at the view List u (Rose u A), proved together: the hypothesis of a node's branch is the law at its children, and those of a forest's cons branch the laws at its first tree and at the rest. Equalities of trees and lists are the Leibniz equality of Prelude›Logic›Leibniz, equalities of numbers Prelude›Arith›Equality.

module Maps where

On forests, mapForest is the map of Prelude›Data›List by map, by reflexivity, on any forest ts, a variable here: an eliminator at the view List (Rose A) IS the eliminator of List, each element's induction hypothesis the eliminator of Rose applied to it. So the equation holds definitionally, and no induction is needed.

theorem mapForestList : ∀ (B : Type@{u}) (f : ∀ (x : A) → B) (ts : F) →
    Id (Forest B) (Op.mapForest B f ts)
      (LO.map u T (Rose u B) (Op.map B f) ts) ≔
  λ (B : Type@{u}) (f : ∀ (x : A) → B) (ts : F) → idRefl (Forest B) (Op.mapForest B f ts)
end

abstract mutual def (B : Type@{u}) (f : ∀ (x : A) → B)
  sizeMap (t : T) :
      Eq (RO.size u B (Op.map B f t)) (Op.size t) ≔
  | node x ts, h ⇒ h
  with sizeMapForest (ts : F) :
      Eq (RO.sizeForest u B (Op.mapForest B f ts)) (Op.sizeForest ts) ≔
  | nil ⇒ ⋆
  | cons t ts, ht hts ⇒
      plusCongBoth (RO.size u B (Op.map B f t))
        (RO.sizeForest u B (Op.mapForest B f ts))
        (Op.size t) (Op.sizeForest ts) ht hts
end

Mapping the identity changes nothing: by congruence through node x and cons.

abstract mutual def
  mapId (t : T) : Id T (Op.map A (λ (x : A) → x) t) t ≔
  | node x ts, h ⇒
      idCong F T (T.node x) (Op.mapForest A (λ (y : A) → y) ts) ts h
  with mapIdForest (ts : F) : Id F (Op.mapForest A (λ (x : A) → x) ts) ts ≔
  | nil ⇒ idRefl F F.nil
  | cons t ts, ht hts ⇒
      idCongTwo T F F F.cons
        (Op.map A (λ (x : A) → x) t) t
        (Op.mapForest A (λ (x : A) → x) ts) ts ht hts
end

Mapping twice is mapping the composite.

abstract mutual def (B : Type@{u}) (C : Type@{u}) (f : ∀ (x : A) → B)
    (g : ∀ (y : B) → C)
  mapComp (t : T) :
      Id (Rose u C) (RO.map u B C g (Op.map B f t))
        (Op.map C (λ (x : A) → g (f x)) t) ≔
  | node x ts, h ⇒
      idCong (Forest C) (Rose u C) (Rose.node u C (g (f x)))
        (RO.mapForest u B C g (Op.mapForest B f ts))
        (Op.mapForest C (λ (y : A) → g (f y)) ts) h
  with mapCompForest (ts : F) :
      Id (Forest C) (RO.mapForest u B C g (Op.mapForest B f ts))
        (Op.mapForest C (λ (x : A) → g (f x)) ts) ≔
  | nil ⇒ idRefl (Forest C) (List.nil u (Rose u C))
  | cons t ts, ht hts ⇒
      idCongTwo (Rose u C) (Forest C) (Forest C) (List.cons u (Rose u C))
        (RO.map u B C g (Op.map B f t))
        (Op.map C (λ (x : A) → g (f x)) t)
        (RO.mapForest u B C g (Op.mapForest B f ts))
        (Op.mapForest C (λ (x : A) → g (f x)) ts) ht hts
end

The preorder list of labels.

module Flatten where

The list has one label per node. A node's list is a cons, whose length is succ of the rest's by conversion; a forest's is an append, whose length is the sum by lengthAppend.

abstract mutual def
  lengthFlatten (t : T) :
      Eq (LO.length u A (Op.flatten t)) (Op.size t) ≔
  | node x ts, h ⇒ h
  with lengthFlattenForest (ts : F) :
      Eq (LO.length u A (Op.flattenForest ts)) (Op.sizeForest ts) ≔
  | nil ⇒ ⋆
  | cons t ts, ht hts ⇒
      trans (LO.length u A (LO.append u A (Op.flatten t)
                              (Op.flattenForest ts)))
        (plus (LO.length u A (Op.flatten t))
           (LO.length u A (Op.flattenForest ts)))
        (plus (Op.size t) (Op.sizeForest ts))
        (lengthAppend (Op.flatten t) (Op.flattenForest ts))
        (plusCongBoth (LO.length u A (Op.flatten t))
           (LO.length u A (Op.flattenForest ts))
           (Op.size t) (Op.sizeForest ts) ht hts)
end

Flattening commutes with map: in a forest's step, the appended lists are rewritten by the hypotheses, then map is pulled out of the append by mapAppend.

abstract mutual def (B : Type@{u}) (f : ∀ (x : A) → B)
  flattenMap (t : T) :
      Id (List u B) (RO.flatten u B (Op.map B f t))
        (LO.map u A B f (Op.flatten t)) ≔
  | node x ts, h ⇒
      idCong (List u B) (List u B) (List.cons u B (f x))
        (RO.flattenForest u B (Op.mapForest B f ts))
        (LO.map u A B f (Op.flattenForest ts)) h
  with flattenMapForest (ts : F) :
      Id (List u B) (RO.flattenForest u B (Op.mapForest B f ts))
        (LO.map u A B f (Op.flattenForest ts)) ≔
  | nil ⇒ idRefl (List u B) (List.nil u B)
  | cons t ts, ht hts ⇒
      idTrans (List u B)
        (LO.append u B (RO.flatten u B (Op.map B f t))
           (RO.flattenForest u B (Op.mapForest B f ts)))
        (LO.append u B (LO.map u A B f (Op.flatten t))
           (LO.map u A B f (Op.flattenForest ts)))
        (LO.map u A B f (LO.append u A (Op.flatten t)
                           (Op.flattenForest ts)))
        (idCongTwo (List u B) (List u B) (List u B) (LO.append u B)
           (RO.flatten u B (Op.map B f t))
           (LO.map u A B f (Op.flatten t))
           (RO.flattenForest u B (Op.mapForest B f ts))
           (LO.map u A B f (Op.flattenForest ts)) ht hts)
        (idSym (List u B)
           (LO.map u A B f (LO.append u A (Op.flatten t)
                              (Op.flattenForest ts)))
           (LO.append u B (LO.map u A B f (Op.flatten t))
              (LO.map u A B f (Op.flattenForest ts)))
           (mapAppend B f (Op.flatten t) (Op.flattenForest ts)))
end

end
