Prelude›Algebra›Monoid

Monoids: a semigroup with a neutral element e on both sides. The record's members carrier, op and assoc are those of its semigroup. The laws derived from these, and the homomorphisms of monoids, are in Prelude›Algebra›Monoid›Properties; monoids over a setoid rather than up to Leibniz equality are Prelude›Algebra›Setoid›Monoid.

module Prelude›Algebra›Monoid (u : Level) where

import Prelude›Logic›Leibniz u use (Id)
import Prelude›Algebra›Semigroup u use (Semigroup)

record Monoid : Type@{succl u} where
  semigroup : Semigroup;
  e : semigroup.carrier;
  leftId : ∀ (x : semigroup.carrier) → Id semigroup.carrier (semigroup.op e x) x;
  rightId : ∀ (x : semigroup.carrier) → Id semigroup.carrier (semigroup.op x e) x
with
  def carrier : Type@{u} ≔ semigroup.carrier end
  def op (x : carrier) (y : carrier) : carrier ≔ semigroup.op x y end
  def assoc : ∀ (x : carrier) (y : carrier) (z : carrier) →
      Id carrier (op (op x y) z) (op x (op y z)) ≔
    semigroup.assoc
  end
end
end

end
