Prelude›Algebra›Instances›Bool

The booleans as instances of the structures of Prelude›Algebra, up to Leibniz equality, at the levels 0l and 1l: commutative monoids under and with tt (conjunction) and under or with ff (disjunction), the lattice of and and or (andOr), and the boolean ring of xor and and (ring), in which every element is its own negative. The laws are those of Prelude›Data›Bool›Properties; and tt b is b and or ff b is b by computation. Each magma predicate is idIsMagma Bool op, and the predicates of and, or and xor are named, so that the lattice and the ring reuse them.

An associative operation on booleans.

private def semigroupOf (op : ∀ (a : Bool) (b : Bool) → Bool)
    (assoc : ∀ (a : Bool) (b : Bool) (c : Bool) →
               Id Bool (op (op a b) c) (op a (op b c))) :
    IsSemigroup Bool (Id Bool) op ≔
  record IsSemigroup Bool (Id Bool) op where
    isMagma ≔ idIsMagma Bool op; assoc ≔ assoc
  end
end

def andIsCommutativeMonoid : IsCommutativeMonoid Bool (Id Bool) and tt ≔
  record IsCommutativeMonoid Bool (Id Bool) and tt where
    isMonoid ≔
      record IsMonoid Bool (Id Bool) and tt where
        isSemigroup ≔ semigroupOf and andAssoc;
        leftId ≔ idRefl Bool;
        rightId ≔ andIdentityRight
      end;
    comm ≔ andComm
  end
end

def orIsCommutativeMonoid : IsCommutativeMonoid Bool (Id Bool) or ff ≔
  record IsCommutativeMonoid Bool (Id Bool) or ff where
    isMonoid ≔
      record IsMonoid Bool (Id Bool) or ff where
        isSemigroup ≔ semigroupOf or orAssoc;
        leftId ≔ idRefl Bool;
        rightId ≔ orIdentityRight
      end;
    comm ≔ orComm
  end
end

def xorIsCommutativeMonoid : IsCommutativeMonoid Bool (Id Bool) xor ff ≔
  record IsCommutativeMonoid Bool (Id Bool) xor ff where
    isMonoid ≔
      record IsMonoid Bool (Id Bool) xor ff where
        isSemigroup ≔ semigroupOf xor xorAssoc;
        leftId ≔ idRefl Bool;
        rightId ≔ xorIdentityRight
      end;
    comm ≔ xorComm
  end
end

def conjunction : CommutativeMonoid ≔
  record CommutativeMonoid where
    carrier ≔ Bool; eq ≔ Id Bool; op ≔ and; e ≔ tt;
    isCommutativeMonoid ≔ andIsCommutativeMonoid
  end
end

def disjunction : CommutativeMonoid ≔
  record CommutativeMonoid where
    carrier ≔ Bool; eq ≔ Id Bool; op ≔ or; e ≔ ff;
    isCommutativeMonoid ≔ orIsCommutativeMonoid
  end
end

The lattice of and and or: Le a b, and a b = a, is implication.

def andOr : Lattice ≔
  record Lattice where
    carrier ≔ Bool; eq ≔ Id Bool; meet ≔ and; join ≔ or;
    isLattice ≔
      record IsLattice Bool (Id Bool) and or where
        meetIsSemilattice ≔
          record IsSemilattice Bool (Id Bool) and where
            isSemigroup ≔ semigroupOf and andAssoc; comm ≔ andComm; idem ≔ andIdem
          end;
        joinIsSemilattice ≔
          record IsSemilattice Bool (Id Bool) or where
            isSemigroup ≔ semigroupOf or orAssoc; comm ≔ orComm; idem ≔ orIdem
          end;
        absorbMeet ≔ andAbsorbsOr;
        absorbJoin ≔ orAbsorbsAnd
      end
  end
end

The boolean ring: xor is the addition, with ff as zero, and and the multiplication, with tt as one; every element is its own negative, and and ff b is ff by computation.

def ring : Ring ≔
  record Ring where
    carrier ≔ Bool; eq ≔ Id Bool; plus ≔ xor; mul ≔ and; zero ≔ ff; one ≔ tt;
    neg ≔ λ (b : Bool) → b;
    isRing ≔
      record IsRing Bool (Id Bool) xor and ff tt (λ (b : Bool) → b) where
        isSemiring ≔
          record IsSemiring Bool (Id Bool) xor and ff tt where
            plusIsCommutativeMonoid ≔ xorIsCommutativeMonoid;
            mulIsMonoid ≔ andIsCommutativeMonoid.isMonoid;
            distribLeft ≔ andXorDistribLeft;
            distribRight ≔ andXorDistribRight;
            zeroLeft ≔ λ (b : Bool) → idRefl Bool ff;
            zeroRight ≔ andZeroRight
          end;
        negCong ≔ λ (a : Bool) (b : Bool) (h : Id Bool a b) → h;
        negLeft ≔ xorSelf
      end
  end
end
