Prelude›Algebra›Instances›Bool

The booleans as instances of the bundled structures of Prelude›Algebra: commutative monoids under and with tt (conjunction) and under or with ff (disjunction), the lattice of and and or (andOr), and the boolean ring of xor and and (ring), in which every element is its own negative. The laws are those of Prelude›Data›Bool›Properties; and tt b is b and or ff b is b by computation.

The semigroup of an associative operation on booleans.

private def semigroupOf (op : ∀ (a : Bool) (b : Bool) → Bool)
    (assoc : ∀ (a : Bool) (b : Bool) (c : Bool) →
               Id Bool (op (op a b) c) (op a (op b c))) : Semigroup ≔
  record Semigroup where
    magma ≔ record Magma where carrier ≔ Bool; op ≔ op end;
    assoc ≔ assoc
  end
end

def conjunction : CommutativeMonoid ≔
  record CommutativeMonoid where
    monoid ≔
      record Monoid where
        semigroup ≔ semigroupOf and andAssoc;
        e ≔ tt;
        leftId ≔ λ (b : Bool) → idRefl Bool b;
        rightId ≔ andIdentityRight
      end;
    comm ≔ andComm
  end
end

def disjunction : CommutativeMonoid ≔
  record CommutativeMonoid where
    monoid ≔
      record Monoid where
        semigroup ≔ semigroupOf or orAssoc;
        e ≔ ff;
        leftId ≔ λ (b : Bool) → idRefl Bool b;
        rightId ≔ orIdentityRight
      end;
    comm ≔ orComm
  end
end

The lattice of and and or: Le a b, and a b = a, is implication.

def andOr : Lattice ≔
  record Lattice where
    meet ≔
      record Semilattice where
        semigroup ≔ semigroupOf and andAssoc;
        comm ≔ andComm;
        idem ≔ andIdem
      end;
    join ≔ or;
    joinAssoc ≔ orAssoc;
    joinComm ≔ orComm;
    absorbMeet ≔ andAbsorbsOr;
    absorbJoin ≔ orAbsorbsAnd
  end
end

The boolean ring: xor is the addition, with ff as zero, and and the multiplication, with tt as one; and ff b is ff by computation.

def ring : Ring ≔
  record Ring where
    semiring ≔
      record Semiring where
        additive ≔
          record CommutativeMonoid where
            monoid ≔
              record Monoid where
                semigroup ≔ semigroupOf xor xorAssoc;
                e ≔ ff;
                leftId ≔ λ (b : Bool) → idRefl Bool b;
                rightId ≔ xorIdentityRight
              end;
            comm ≔ xorComm
          end;
        mul ≔ and;
        one ≔ tt;
        mulAssoc ≔ andAssoc;
        mulLeftId ≔ λ (b : Bool) → idRefl Bool b;
        mulRightId ≔ andIdentityRight;
        distribLeft ≔ andXorDistribLeft;
        distribRight ≔ andXorDistribRight;
        zeroLeft ≔ λ (b : Bool) → idRefl Bool ff;
        zeroRight ≔ andZeroRight
      end;
    neg ≔ λ (b : Bool) → b;
    negLeft ≔ xorSelf
  end
end
