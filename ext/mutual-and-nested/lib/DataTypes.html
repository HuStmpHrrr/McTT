DataTypes

A client of the inductive types of Prelude›Data: comparisons, inclusive unions, non-empty lists, binary trees, signs and parities, integers, binary numbers and well-founded trees, computed on closed values, and closed instances of their laws.

Inclusive unions: the sum of what is there.

def total (t : These 0l ℕ ℕ) : ℕ ≔
  Th.fold 0l ℕ ℕ ℕ (λ (a : ℕ) → a) (λ (b : ℕ) → b) plus t
end

eval total (Th.swap 0l ℕ ℕ (These.these 0l ℕ ℕ 2 3))
output
Evaluate total (Th.swap 0l ℕ ℕ (These.these 0l ℕ ℕ 2 3)) --> 5 : ℕ
eval total (These.that 0l ℕ ℕ 4)
output
Evaluate total (These.that 0l ℕ ℕ 4) --> 4 : ℕ

Non-empty lists: the last element always exists.

inductive NatNE ≔ NonEmpty 0l ℕ

module N ≔ NE 0l ℕ

def oneToFour : NatNE ≔
  NatNE.cons 1 (List.cons 0l ℕ 2 (List.cons 0l ℕ 3 (List.cons 0l ℕ 4
    (List.nil 0l ℕ))))
end

Binary trees with numbers at the nodes and booleans at the leaves.

inductive NT ≔ Tree 0l ℕ Bool

def sample : NT ≔
  NT.node (NT.node (NT.leaf tt) 1 (NT.leaf ff)) 2 (NT.leaf tt)

W-types: the natural numbers as the W-type of two shapes, ff with no subtree and tt with one.

def Arity (b : Bool) : Type@0 ≔ Cond.if 1l Type@0 b ⊤ ⊥ end

inductive WNat ≔ W 0l Bool Arity

def wzero : WNat ≔ WNat.sup ff (λ (p : ⊥) → exfalso p return z . WNat) end

def wsucc (w : WNat) : WNat ≔ WNat.sup tt (λ (p : ⊤) → w) end

The number a tree stands for, by foldr: one more than its subtree at a tt node.

def wToNat (w : WNat) : ℕ ≔
  WO.foldr 0l Bool Arity ℕ
    (λ (b : Bool) →
       elim b at z -> (∀ (r : ∀ (p : Arity z) → ℕ) → ℕ)
       | tt ⇒ λ (r : ∀ (p : ⊤) → ℕ) → succ (r ⋆)
       | ff ⇒ λ (r : ∀ (p : ⊥) → ℕ) → 0
       end)
    w
end

eval wToNat (wsucc (wsucc (wsucc wzero)))
output
Evaluate wToNat (wsucc (wsucc (wsucc wzero))) --> 3 : ℕ
eval WO.head 0l Bool Arity (wsucc wzero)
output
Evaluate WO.head 0l Bool Arity (wsucc wzero) --> Prelude›Data›Bool.Bool.tt
  : Prelude›Data›Bool.Bool
