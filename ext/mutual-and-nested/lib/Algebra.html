Algebra

A client of Prelude›Algebra›Setoid›Monoid and its instances. The laws of powers are proved once, for every monoid; read in the additive, the multiplicative and the composition monoid, they become laws of multiplication, of exponentiation and of iteration.

module Algebra where

import Prelude›Builtin›Nat use (succ)
import Prelude›Arith›Equality use (Eq; refl; sym; trans)
import Prelude›Arith›Plus use (plus)
open Prelude›Arith›Plus.Basic use (plusIdentityRight)
open Prelude›Arith›Plus.Algebra use (plusAssoc; plusCongBoth)
import Prelude›Arith›Mult use (mult)
import Prelude›Arith›Pow use (pow)
import Prelude›Arith›MinMax use (max)
open Prelude›Arith›MinMax.Laws use (maxIdem; maxIdentityRight)
import Prelude›Algebra›Setoid›Monoid as Monoid
import Prelude›Algebra›Setoid›Instances
  use (Additive; AdditiveComm; Multiplicative; MultiplicativeComm; Maximum;
       Composition; Endo; Pointwise; compose)

The powers of the additive and multiplicative monoids are multiplication and exponentiation, by conversion.

module Unfold where

theorem additivePow : ∀ (x : ℕ) (n : ℕ) → Eq (Additive.pow x n) (mult n x) ≔
  λ (x : ℕ) (n : ℕ) → refl (mult n x)
end

theorem multiplicativePow : ∀ (x : ℕ) (n : ℕ) →
    Eq (Multiplicative.pow x n) (pow x n) ≔
  λ (x : ℕ) (n : ℕ) → refl (pow x n)
end

end

Laws of multiplication, as laws of powers in the additive monoid.

module Scaling where

Right distributivity is powPlus.

theorem multPlusRight : ∀ (m : ℕ) (n : ℕ) (x : ℕ) →
    Eq (mult (plus m n) x) (plus (mult m x) (mult n x)) ≔
  λ (m : ℕ) (n : ℕ) (x : ℕ) → Additive.Power.powPlus x m n
end

Associativity is powMult.

theorem multAssocPow : ∀ (m : ℕ) (n : ℕ) (x : ℕ) →
    Eq (mult (mult m n) x) (mult m (mult n x)) ≔
  λ (m : ℕ) (n : ℕ) (x : ℕ) → Additive.Power.powMult x m n
end

Left distributivity needs commutativity of addition: it is powOp in the commutative instance.

theorem multPlusLeft : ∀ (n : ℕ) (x : ℕ) (y : ℕ) →
    Eq (mult n (plus x y)) (plus (mult n x) (mult n y)) ≔
  λ (n : ℕ) (x : ℕ) (y : ℕ) → AdditiveComm.powOp x y n
end

end

Laws of exponents, as laws of powers in the multiplicative monoid. Each proof names the submodule of laws it uses with a local module.

module Exponents where

theorem powPlus : ∀ (x : ℕ) (m : ℕ) (n : ℕ) →
    Eq (pow x (plus m n)) (mult (pow x m) (pow x n)) ≔
  λ (x : ℕ) (m : ℕ) (n : ℕ) →
    let module P ≔ Multiplicative.Power in P.powPlus x m n end
end

theorem powMult : ∀ (x : ℕ) (m : ℕ) (n : ℕ) →
    Eq (pow x (mult m n)) (pow (pow x n) m) ≔
  λ (x : ℕ) (m : ℕ) (n : ℕ) →
    let module P ≔ Multiplicative.Power in P.powMult x m n end
end

theorem powOfProduct : ∀ (x : ℕ) (y : ℕ) (n : ℕ) →
    Eq (pow (mult x y) n) (mult (pow x n) (pow y n)) ≔
  λ (x : ℕ) (y : ℕ) (n : ℕ) → MultiplicativeComm.powOp x y n
end

x to the fourth is the square of its square: mult 2 2 computes to 4.

theorem fourthPower : ∀ (x : ℕ) → Eq (pow x 4) (pow (pow x 2) 2) ≔
  λ (x : ℕ) → let module P ≔ Multiplicative.Power in P.powMult x 2 2 end
end

end

Iteration, as powers in the composition monoid, compared pointwise.

module Iteration where

Iterating m + n times is iterating n times, then m times.

theorem iterPlus : ∀ (f : Endo) (m : ℕ) (n : ℕ) →
    Pointwise (Composition.pow f (plus m n))
      (compose (Composition.pow f m) (Composition.pow f n)) ≔
  λ (f : Endo) (m : ℕ) (n : ℕ) → Composition.Power.powPlus f m n
end

Iterating m * n times is iterating n times, m times over.

theorem iterMult : ∀ (f : Endo) (m : ℕ) (n : ℕ) →
    Pointwise (Composition.pow f (mult m n))
      (Composition.pow (Composition.pow f n) m) ≔
  λ (f : Endo) (m : ℕ) (n : ℕ) → Composition.Power.powMult f m n
end

end

A monoid built here, from a partial application of the unit: the setoid of numbers is fixed, and the operation and its laws come later. It is addition again, so its powers agree with Additive's.

module NatMonoid ≔ Monoid 0l ℕ Eq refl sym trans

module Sums ≔ NatMonoid plus plusCongBoth 0 plusAssoc refl plusIdentityRight

eval Sums.pow 6 3
output
Evaluate Sums.pow 6 3 --> 18 : ℕ

In the maximum monoid every positive power of x is x: the first is max x 0, and each further factor is absorbed by maxIdem. The step names its rewriting under max x in a local module, which opens the congruence laws of the instance.

theorem maxPowSucc : ∀ (x : ℕ) (n : ℕ) → Eq (Maximum.pow x (succ n)) x ≔
  λ (x : ℕ) (n : ℕ) →
    elim n at k -> Eq (Maximum.pow x (succ k)) x
    | zero ⇒ maxIdentityRight x
    | succ p, ih ⇒
        let power ≔ Maximum.pow x (succ p);
            module L where
              open Maximum.Cong use (congRight)
              (* One more factor [x] in front of a power that is already [x]. *)
              def front : Eq (max x power) (max x x) ≔
                congRight x power x ih
              end
            end
        in trans (max x power) (max x x) x L.front (maxIdem x)
        end
    end
end
