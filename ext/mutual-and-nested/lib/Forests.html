The number of leaves, by the group's eliminator, here at the tree's block: a node is a leaf when its forest is nil. The motive at forests says how many leaves a forest has, and whether it is empty.

def leaves (t : T) : ℕ ≔
  elim t at (z : T) -> ℕ
  | node x ts, h ⇒
      elim ts with (z : T) -> ℕ
      | node y us, k ⇒ 0
      at (z : F) -> ℕ
      | nil ⇒ 1
      | cons s us, ks kus ⇒ h
      end
  with (z : F) -> ℕ
  | nil ⇒ 0
  | cons s us, hs hus ⇒ plus hs hus
  end
end

eval leaves example
output
Evaluate leaves example --> 2 : ℕ

The largest label, by the recursor module of the group: one motive per member, then one case per constructor.

def largest (t : T) : ℕ ≔
  Rose.Rec.rec_Tree 0l ℕ 0l (λ (z : T) → ℕ) (λ (z : F) → ℕ)
    (λ (x : ℕ) (ts : F) (m : ℕ) → max x m)
    0
    (λ (s : T) (ts : F) (m : ℕ) (n : ℕ) → max m n)
    t
end

eval largest example
output
Evaluate largest example --> 4 : ℕ
