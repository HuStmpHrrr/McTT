NumberTheory

A client of Prelude›Arith›Gcd, its laws, and Prelude›Arith›Prime: greatest common divisors, the primes below 30, and closed instances of the theorems, which normalize to ⋆. The numbers in the proofs stay small, since they compute with remainders and equalities of numbers.

import Prelude›Arith›Sum use (sumTo)

Enumerating the primes. The search for the next prime is a private helper; only nthPrime is exported.

module Primes where

The least prime above n, searched among the numbers from n + 1 to 2 n + 2, which contain one by Bertrand's postulate.

let nextPrime (n : ℕ) : ℕ ≔
  (elim n at y -> (∀ (c : ℕ) → ℕ)
   | zero ⇒ λ (c : ℕ) → cond ℕ (isPrime c) (λ (u : ⊤) → c) (λ (u : ⊤) → succ c)
   | succ p, r ⇒ λ (c : ℕ) →
       cond ℕ (isPrime c) (λ (u : ⊤) → c) (λ (u : ⊤) → r (succ c))
   end) (succ n)
end

The k-th prime, counting from 0.

def nthPrime (k : ℕ) : ℕ ≔ Generic.iterate 0l ℕ nextPrime (succ k) 0 end

end

open Primes use (nthPrime)
