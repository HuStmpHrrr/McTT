Inference Is Functional

A term infers at most one type. The proof reads only the syntax: normalisation is functional, and so is what a module expression denotes; so it stands below the metatheory, where the static semantics of commands, whose access fill infers types, can use it.

A term infers one type. A member's is read off what its module denotes, which of a well-formed global context is one description (mdenote_functional_all).
Lemma functional_alg_type_infer : forall {Γ A A' M},
    ⊢ᵍ gc_deps ⍮ gc_stack ->
    Γ ⊢a M ⟹ A ->
    Γ ⊢a M ⟹ A' ->
    A = A'.
Proof.
  intros * Hg HM1 HM2. gen A'.
  induction HM1; intros;
    inversion_clear HM2;
