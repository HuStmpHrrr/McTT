Record Types: the Canonical Model and the Type Former

A record whose declaration is valid in the PER model (its parameters a context, its sort a universe over them, each field a type of the sort over the fields before it) is, at related parameters, a type of the universe its sort denotes, with the canonical relations of Core.Semantic.RecordPER (record_relate). Its type former is then an element of its Π-type (valid_exp_under_ctx_record).
The validity of the declaration is the hypotheses of RecordModel; a valid global context provides them for every record it files. The first section states, for any closed telescope and any sort over it, what Inductives/Model.v states for the uniform parameters and the sort of a group.

Lemma tele_rel_build : forall {X} tr (T : list X) A B,
    List.length A = List.length T -> List.length B = List.length T ->
    (forall k x y, List.nth_error A k = Some x -> List.nth_error B k = Some y ->
       tele_prefix_rel tr k (List.firstn k A) (List.firstn k B) -> tr k (List.firstn k A) x y) ->

A Valid Record

The hypotheses are the judgments of the record's declaration, read in the PER model: the fields over the parameters are a context, the sort is a universe over the parameters, and each field is a type of the sort over the fields before it.

  Variables (p : qname) (R : record_decl).

      by (apply (gargs_env_rel _ _ _ _ _ _ HRU record_params_sem); [ exact Hlen | exact Hgd ]).
