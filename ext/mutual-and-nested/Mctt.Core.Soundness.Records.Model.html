Record Types in the Gluing Model

A record found in a well-formed global context is typed there, so valid in the PER model (record_model_at); Core/Completeness/Records/Model.v then gives the values of its type former, its fields' types and its projections. On top of them: a projection of a glued element is glued at its field's type (glu_rel_exp_proj), a tuple of glued fields is glued at its record type (glu_rel_exp_tuple), and the type former, at a declaration whose judgments are glued (glu_record_decl), is glued at its type (glu_rel_exp_record0).

A Record of a Well-Formed Global Context

A record found in a well-formed global context is valid there in the PER model: it is typed where it is found, and the identity embedding is sound.
Lemma record_model_at : forall p R, ⊢ᵍ gc_deps ⍮ gc_stack -> record_lookup gc_deps gc_stack p = Some R ->
    record_model p R.
Proof.
  intros * Hg Hl.
  pose proof (record_model_of_emb _ _ _ _ _ _ (valid_emb_refl _ _ Hg) Hl) as H.
  destruct GC; exact H.
Qed.

Projections

The projection of an element glued at the record type at parameters is glued at its field's type: it is the projection the element's gluing glues, at the parameters, which are the element's type's.

         Γ ⊢ N : A) ->
      (forall j N A, List.nth_error Ns j = Some N -> List.nth_error (tele_insts (record_params R) Id Ns) j = Some A ->

Tuples

A tuple of glued fields at a glued record type at glued parameters is glued at that type: the type is the record type at the parameters, and each field's projection is the field (field-β), glued at its type, by induction on the position, since the field's type is glued after the fields before it are.
  Lemma glu_rel_exp_tuple : forall Γ T Ns (fs : list (String.string * exp)) (i : nat),
      Γ ⊩ T : Typeω@i ->
      Γ ⊢ T ≈ apps_exp (a_record p) Ns : Typeω@i ->
      Γ ⊢ a_record p : record_ty R ->
      List.length Ns = List.length (record_params R) ->
      (forall j N A, List.nth_error Ns j = Some N -> List.nth_error (tele_insts (record_params R) Id Ns) j = Some A ->
         Γ ⊢ N : A) ->
      (forall j N A, List.nth_error Ns j = Some N -> List.nth_error (tele_insts (record_params R) Id Ns) j = Some A ->
         Γ ⊩ N : A) ->
      List.map fst fs = List.map fst (record_fields R) ->
      (forall k f M U, List.nth_error fs k = Some (f, M) -> List.nth_error (record_fields R) k = Some (f, U) ->
         Γ ⊢ M : U[sb_of_list Id (Ns ++ List.firstn k (List.map snd fs))]) ->
      (forall k f M U, List.nth_error fs k = Some (f, M) -> List.nth_error (record_fields R) k = Some (f, U) ->
         Γ ⊩ M : U[sb_of_list Id (Ns ++ List.firstn k (List.map snd fs))]) ->
      Γ ⊩ a_tuple T fs : T.

      by (eapply wf_tuple; [ exact (glu_rel_exp_to_wf_exp HT) | exact HTeq | exact Hrt | exact Hl | exact Hn | exact HNt
