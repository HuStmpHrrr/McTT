The Semantic Judgments

All the definitions of the PER model's judgments, in four parts.
1. The relations at one global context GC, the building blocks: weakenings, substitutions, terms, subtyping and module expressions; semantically well-formed contexts and the parts of units (rel_ctx_wf, rel_unit_wf), and the relations of units and extensions. 2. Valid units and module expressions valid in what they denote (valid_unit, valid_modexp), with lookups read at a global context Θm ⍮ Ξm that GC extends and values at GC; and the contexts whose slots hold valid units (valid_ctx). 3. What a global context Θm ⍮ Ξm files and has open is worth at GC (valid_filed_mod, valid_filed_mods), and a declaration (valid_ind_decl, valid_record_decl); a sound embedding of Θ1 ⍮ Ξ1 into Θ2 ⍮ Ξ2 (valid_emb). 4. The semantic judgments: a judgment of Θ ⍮ Ξ is the relation of the first two parts at every global context Θ ⍮ Ξ embeds into soundly.
The substitution and term layers state their conclusion as a four-value pattern (see Core/Semantic/PER/Chain.v): 
{⟦M[σ]⟧(ρ), ⟦M⟧(⟦σ⟧(ρ)), ⟦M'⟧(⟦σ'⟧(ρ')), ⟦M'[σ']⟧(ρ')} ⊆ R
Its three consecutive links are the commutation obligation on the left, the relatedness obligation in the middle, and the commutation obligation on the right. Substitution is an operation, so ⟦M[σ]⟧(ρ) and ⟦M⟧(⟦σ⟧(ρ)) are in general not equal, and every case of the fundamental theorem must discharge both commutations.

Semantic Weakening

A weakening is an operation, so related environments need not stay related after it is applied; the semantic judgment for weakenings requires that they do. Without its two context witnesses it is Proper (R ==> R') (eval_wk φ), for a weakening that moves no variable down: environments are lists, which is what makes weakenings compose on them (eval_wk_compose). Every weakening the proofs use is built from ↑ and wk_q, hence is of this kind.

Record rel_wk (φ : wk) (R R' : relation env) : Prop := mk_rel_wk
  { rel_wk_mono : WkMono φ
  ; rel_wk_app :> forall ρ ρ',
      Dom ρ ≈ ρ' ∈ R ->
      Dom ⟪φ⟫ ρ ≈ ⟪φ⟫ ρ' ∈ R' }.

  ; rel_wk_under_ctx_per : EF Γ ≈ Γ ∈ per_ctx_env ↘ rel_wk_under_ctx_rel
  ; rel_wk_under_ctx_rel' : relation env
  ; rel_wk_under_ctx_per' : EF Δ ≈ Δ ∈ per_ctx_env ↘ rel_wk_under_ctx_rel'
  ; rel_wk_under_ctx_wk : rel_wk φ rel_wk_under_ctx_rel rel_wk_under_ctx_rel' }.

Semantic Substitution Equality

σ and σ' must stay related after an arbitrary semantic weakening φ — the Kripke-like quantification that makes the judgment usable under context extension. The four environments are the two ways of evaluating each side: σ[φ] in ρ (the substitution sb_wk σ φ, which is σ postcomposed with φ) against σ in ⟪φ⟫ ρ.

#[warnings="-cannot-define-projection"]
Record rel_sub (σ : sub) (φ : wk) (ρ : env) (σ' : sub) (ρ' : env) (R : relation env) : Prop := mk_rel_sub
  { ρσφ : env
  ; ρσ : env
  ; ρ'σ' : env
  ; ρ'σ'φ : env
  ; rel_sub_eval_wk : ⟦ (sb_wk σ φ) ⟧s ρ ↘ ρσφ
  ; rel_sub_eval : ⟦ σ ⟧s ⟪φ⟫ ρ ↘ ρσ
  ; rel_sub_eval' : ⟦ σ' ⟧s ⟪φ⟫ ρ' ↘ ρ'σ'
  ; rel_sub_eval_wk' : ⟦ (sb_wk σ' φ) ⟧s ρ' ↘ ρ'σ'φ
  ; rel_sub_chain : rel_chain R ([ρσφ; ρσ; ρ'σ'; ρ'σ'φ]) }.

Terms

Terms are required to be stable under semantic substitutions rather than weakenings. rel_exp is the four-value pattern of one expression pair. The two environments ρσ and ρ'σ' are parameters rather than existentials, because the type chain and the term chain must be read in the same pair of environments: closures capture their environment, so replacing it by a pointwise-equal one changes the values.

#[warnings="-cannot-define-projection"]
Record rel_exp (M : exp) (σ : sub) (ρ ρσ : env) (M' : exp) (σ' : sub) (ρ' ρ'σ' : env) (R : relation domain) : Prop := mk_rel_exp
  { mσ : domain
  ; m : domain
  ; m' : domain
  ; m'σ' : domain
  ; rel_exp_eval_sub : ⟦ M[σ] ⟧ ρ ↘ mσ
  ; rel_exp_eval : ⟦ M ⟧ ρσ ↘ m
  ; rel_exp_eval' : ⟦ M' ⟧ ρ'σ' ↘ m'
  ; rel_exp_eval_sub' : ⟦ M'[σ'] ⟧ ρ' ↘ m'σ'
  ; rel_exp_chain : rel_chain R ([mσ; m; m'; m'σ']) }.
#[global] Arguments mk_rel_exp {_ _ _ _ _ _ _ _ _}.

The notation ⟦σ⟧(ρ) suggests that evaluation of σ is a function. It is a relation, and functional_eval_sub determines its result only up to env_eq. That does not allow substituting one witness for another, since evaluation does not respect env_eq (a closure captures its environment). So the two environments are quantified universally, over evaluation witnesses supplied by the caller, rather than existentially; any two proofs that σ evaluates at ρ are then interchangeable.
The relation does not itself claim that σ evaluates at ρ; that is part of rel_sub_under_ctx Γ' Γ σ σ', which every instantiation supplies. In return, each case of the fundamental theorem must produce its values at whatever environment the caller names. This is what makes the inductive cases fit: a premise's values arrive in the same environment as the conclusion's, so two instantiations of one relation share values rather than being pointwise equal, and rel_chain_merge applies.

Contexts

An inductive relation whose extension step carries both the context PER witness and the semantic well-formedness of the head (and, for a definition, of its body; for a module slot, of its unit; for a definition with a module part, of both), so rel_ctx_wf_per_ctx_env reads the PER off any derivation. The validity of a unit's parts (rel_unit_wf) is defined with it, since a body unit's parts form a context.

Inductive rel_ctx_wf : ctx -> Prop :=
| rel_ctx_wf_nil : ⊨ ⋅
| rel_ctx_wf_cons : forall Γ A i env_rel,
    ⊨ Γ ->
    EF Γ ▹ A ≈ Γ ▹ A ∈ per_ctx_env ↘ env_rel ->
    Γ ⊨ A ≈ A : Typeω@i ->
    ⊨ Γ ▹ A
| rel_ctx_wf_cons_def : forall Γ A M i env_rel,
    ⊨ Γ ->
    EF Γ ▸ A ≔ M ≈ Γ ▸ A ≔ M ∈ per_ctx_env ↘ env_rel ->
    Γ ⊨ A ≈ A : Typeω@i ->
    Γ ⊨ M ≈ M : A ->
    ⊨ Γ ▸ A ≔ M
| rel_ctx_wf_cons_mod : forall Γ U env_rel,
    ⊨ Γ ->

A unit is valid when its parts are (valid_unit): a filed module at arguments valid against its telescope (valid_args); a local body whose context, read as its expansion, is valid, whose submodules (the module parts of its entries, entry_unit) are valid units in the context the body before each makes, and whose opens' targets are valid; an alias whose target is. A module expression is valid in what it denotes (valid_modexp) when it is equal, in the PER model, to a valid unit denoting the same module part: the semantic counterpart of lookup soundness.

4. The Semantic Judgments

A semantic judgment is stated at a global context Θ ⍮ Ξ, as the syntactic one is, and holds at every global context Θ2 ⍮ Ξ2 that Θ ⍮ Ξ embeds into soundly: there it is the relation of the first two parts, read in the PER model of Θ2 ⍮ Ξ2, with lookups read at Θ ⍮ Ξ. Each judgment about the members of a context also states the context, with valid slots (valid_ctx). The units of ⊨ᵘ are moreover valid (valid_unit), the extended contexts of ⊨ˣ have valid slots, and the module expressions of ⊨ᵐ are valid in what they denote (valid_modexp).
