A tour of the McTT surface language, one feature at a time. Run it from lib/ with ../_build/default/driver/mctt.exe Tutorial.mctt.

A file is one unit: one module. Its imports go inside it (section 11).

module Tutorial where

import Prelude›Arith›Equality use (Eq; refl)
import Prelude›Function›Iter as Iter

1. Lexical matters. This text is a comment; comments do not nest. Identifiers are letters only, so names are camelCase. A numeral is unary: 3 is succ (succ (succ zero)).

Symbols have a Unicode and an ASCII spelling, and either may be used anywhere; this file uses the Unicode ones, which the checker also prints: → -> ⇒ => ≔ := › :: λ fun ∀ forall (or Π) ℕ Nat ⊤ True ⊥ False ⋆ true ω omega Identifiers are ASCII letters, so the symbols need no spaces around them: λ(x:ℕ)→x is fun (x : Nat) -> x.

eval succ (succ (succ zero))
output
Evaluate 3 --> 3 : ℕ

2. Evaluation. eval M normalizes M and infers its type; eval M : T checks M against T first.

eval 3 : ℕ
output
Evaluate 3 --> 3 : ℕ

3. Universes and types. Type@i is the universe of level i, with Type@i : Type@(i+1). ℕ is in Type@0, with zero and succ.

eval ℕ : Type@0
output
Evaluate ℕ --> ℕ : Type@0
eval Type@0 : Type@1
output
Evaluate Type@0 --> Type@0 : Type@1

A function is λ (x : A) → M; its type is ∀ (x : A) → B, where B may mention x. Application is juxtaposition. Several binders abbreviate nested ones.

eval (λ (A : Type@0) (x : A) → x) ℕ 4
output
Evaluate (λ (A1 : Type@0)
            (x1 : A1)
           → x1) ℕ 4 --> 4 : ℕ
eval λ (A : Type@0) (x : A) → x
output
Evaluate λ (A1 : Type@0)
           (x1 : A1)
           → x1 --> λ (A1 : Type@0)
                      (x1 : A1)
                      → x1 : ∀ (A1 : Type@0)
                               (x1 : A1)
                               → A1

4. Recursion. rec n return y . T | zero ⇒ z | succ p, r ⇒ s end is primitive recursion on n: T is the motive, p the predecessor and r the result for p.

eval rec 3 return y . ℕ | zero ⇒ 0 | succ p, r ⇒ succ (succ r) end
output
Evaluate rec 3 return x1 . ℕ | zero ⇒ 0 | succ x2, x3 ⇒ succ (succ x3) end
  --> 6 : ℕ

The motive may compute a type: here, the type of n-ary functions on ℕ.

eval rec 2 return y . Type@0
     | zero ⇒ ℕ
     | succ p, r ⇒ ∀ (x : ℕ) → r
     end
output
Evaluate rec 2 return x1 . Type@0
         | zero ⇒ ℕ
         | succ x2, A1 ⇒ ∀ (x3 : ℕ) → A1
         end --> ∀ (x1 : ℕ)
                   (x2 : ℕ)
                   → ℕ : Type@0

5. Unit and empty types. ⊤ has the one element ⋆; ⊥ has none. exfalso h return x . P eliminates h : ⊥ into any type P.

eval ⋆ : ⊤
output
Evaluate ⋆ --> ⋆ : ⊤
eval λ (h : ⊥) → exfalso h return x . ℕ
output
Evaluate λ (x1 : ⊥) → exfalso x1 return x2 . ℕ
  --> λ (x1 : ⊥) → exfalso x1 return x2 . ℕ : ∀ (x1 : ⊥) → ℕ

6. Local definitions. let x : A ≔ a; y ≔ b in M end binds each name in the later bindings and in M. A binding is transparent, so its value is known while checking the rest; an unannotated one has its type inferred. Eq n m, imported above, computes to ⊤ exactly when n and m are equal, so ⋆ proves Eq 3 3.

eval let n : ℕ ≔ 2;
         f ≔ λ (x : ℕ) → succ x;
         p : Eq (f n) 3 ≔ ⋆
     in f (f n)
     end
output
Evaluate let x1 : ℕ ≔ 2; x2 ≔ λ (x3 : ℕ) → succ x3; x4 : Eq (x2 x1) 3 ≔ ⋆
         in x2 (x2 x1)
         end --> 4 : ℕ

7. Definitions. def f (x : A) : T ≔ M end is def f : ∀ (x : A) → T ≔ λ (x : A) → M end. A definition is transparent: it unfolds wherever it is used.

def double (n : ℕ) : ℕ ≔
  rec n return y . ℕ | zero ⇒ 0 | succ p, r ⇒ succ (succ r) end
end

eval double 3
output
Evaluate double 3 --> 6 : ℕ

An abstract definition is opaque: it is checked, but never unfolds, so its uses are stuck.

abstract def four : ℕ ≔ 4 end

eval double four
output
Evaluate double four
  --> rec four return x1 . ℕ | zero ⇒ 0 | succ x2, x3 ⇒ succ (succ x3) end
  : ℕ

A private definition is usable only inside its module (section 10). Both modifiers combine, in either order.

private def helper : ℕ ≔ 1 end

private abstract def hiddenFive : ℕ ≔ 5 end

abstract private def hiddenSix : ℕ ≔ 6 end

eval succ helper
output
Evaluate succ helper --> 2 : ℕ

8. Definition keywords. Each is def with modifiers implied: theorem, lemma = abstract; fact, remark = abstract private; let, given = private. refl n proves Eq n n.

theorem doubleTwo : Eq (double 2) 4 ≔ refl 4 end

lemma twoDouble : Eq 4 (double 2) ≔ refl 4 end

fact factTrue : ⊤ ≔ ⋆ end

remark remarkTrue : ⊤ ≔ ⋆ end

let one : ℕ ≔ 1 end

given two : ℕ ≔ 2 end

eval double two
output
Evaluate double two --> 4 : ℕ

A keyword takes only the modifiers it does not imply: private theorem and abstract let are allowed; fact and remark take none.

private theorem privateThm : Eq 1 1 ≔ ⋆ end

abstract let opaqueLet : ℕ ≔ 3 end

Rejected: abstract theorem t : ℕ ≔ 1 end Error: theorem is already abstract private let l : ℕ ≔ 1 end Error: let is already private private fact f : ℕ ≔ 1 end Error: fact takes no modifiers

axiom x : T declares x with no body: it never normalizes. An axiom takes no modifiers (private axiom gives "axiom takes no modifiers").

axiom k : ℕ

eval double (succ k)
output
Evaluate double (succ k)
  --> succ
        (succ
          (rec k return x1 . ℕ | zero ⇒ 0 | succ x2, x3 ⇒ succ (succ x3) end))
  : ℕ

9. Modules. module X where … end groups members; X.f selects one, through any chain of nested modules.

module Outer where
  def base : ℕ ≔ 10 end
  module Inner where
    def next : ℕ ≔ succ base end
  end
end

eval Outer.Inner.next
output
Evaluate Outer.Inner.next --> 11 : ℕ

A module with parameters abstracts every member over them. Its arguments follow the selection, or apply the module in parentheses.

module Twice (A : Type@0) (f : ∀ (a : A) → A) where
  def twice (a : A) : A ≔ f (f a) end
end

eval Twice.twice ℕ double 1
output
Evaluate Twice.twice ℕ double 1 --> 4 : ℕ
eval (Twice ℕ double).twice 1
output
Evaluate (Twice ℕ double).twice 1 --> 4 : ℕ

module Y ≔ E declares an alias. Applying a module to some of its parameters is partial application.

module NatTwice ≔ Twice ℕ

module Quadruple ≔ NatTwice double

eval Quadruple.twice 1
output
Evaluate Quadruple.twice 1 --> 4 : ℕ

module A.B where … end declares B inside A.

module Shapes.Square where
  def side : ℕ ≔ 2 end
end

eval Shapes.Square.side
output
Evaluate Shapes.Square.side --> 2 : ℕ

10. Privacy. A private member is usable inside the module that declares it, including its nested modules, and nowhere else.

module Vault where
  private def secret : ℕ ≔ 7 end
  def reveal : ℕ ≔ succ secret end
  module Inside where
    def peek : ℕ ≔ secret end
  end
end

eval Vault.reveal
output
Evaluate Vault.reveal --> 8 : ℕ
eval Vault.Inside.peek
output
Evaluate Vault.Inside.peek --> 7 : ℕ

Rejected: eval Vault.secret Error: Tutorial.Vault.secret is private

11. Imports and opens. import X›Y only loads the unit X›Y: its members are reached by their full name.

import Prelude›Arith›Plus

eval Prelude›Arith›Plus.plus 2 3
output
Evaluate Prelude›Arith›Plus.plus 2 3 --> 5 : ℕ

open E as Z use (a; c as d) export (e) declares, in this module, a private alias module Z ≔ E, private definitions a ≔ Z.a and d ≔ Z.c, and a public definition e ≔ Z.e. Items naming a submodule declare aliases instead.

module Adding where
  open Prelude›Arith›Plus as P use (plus as add) export (Algebra)
  def five : ℕ ≔ add 2 (P.plus 1 2) end
end

eval Adding.five
output
Evaluate Adding.five --> 5 : ℕ
eval Adding.Algebra.plusComm 1 2
output
Evaluate Adding.Algebra.plusComm 1 2 --> ⋆ : ⊤

Rejected: eval Adding.add Error: Tutorial.Adding.add is private

The long form import X›Y as Z use (…) is import X›Y then open X›Y as Z use (…). Prelude›Arith›Plus is loaded already, and a repeated import does nothing, so this one only opens it.

module Counting where
  import Prelude›Arith›Plus as Q use (plus)
  def seven : ℕ ≔ plus 3 (Q.plus 2 2) end
end

eval Counting.seven
output
Evaluate Counting.seven --> 7 : ℕ

Imports and opens may also precede the unit's header, but only for what the unit's parameter types need; everything else is imported inside the module, as at the top of this file. Leading ones may use and as but not export: import Prelude›Arith›Equality use (Eq) module Proofs (h : Eq 1 1) where … end

12. Local modules. let module X (ps) where … end in M end declares a module inside a term, and let module X ≔ E in M end an alias. The body may open modules and declare private members, which M cannot use.

eval let module Doubler (n : ℕ) where
         open Twice ℕ double use (twice)
         private def base : ℕ ≔ twice n end
         def sum : ℕ ≔ succ base end
       end;
       module DoublerOne ≔ Doubler 1
     in DoublerOne.sum
     end
output
Evaluate let module M1 (x1 : ℕ) where
               private def twice : ∀ (x2 : ℕ) → ℕ ≔
                 (Twice ℕ double).twice
               end
               private def base : ℕ ≔
                 twice x1
               end
               def sum : ℕ ≔
                 succ base
               end
             end;
             module M2 ≔ M1 1
         in M2.sum
         end --> 5 : ℕ

Rejected in a local module body: import X›Y Error: import is not allowed in a local module; use open eval M Error: eval is not allowed in a local module axiom x : T Error: axioms are not allowed in a local module An abstract member, or an abstract keyword, makes the whole let ill-typed: "Error: let module M1 where … end in 0 end has no inferable type". Using Doubler.base in the let's body gives "Error: base is private in a local module, but it is used outside it".

13. Putting it together: a parameterized module with a theorem proved by induction, opened in a local module and instantiated.

module Adder (m : ℕ) where
  def add (n : ℕ) : ℕ ≔
    rec n return y . ℕ | zero ⇒ m | succ p, r ⇒ succ r end
  end

  (* Adding n is iterating succ n times. *)
  theorem addIter (n : ℕ) :
      Eq (add n) (Iter.iter 0l ℕ (λ (x : ℕ) → succ x) n m) ≔
    rec n return y . Eq (add y) (Iter.iter 0l ℕ (λ (x : ℕ) → succ x) y m)
    | zero ⇒ refl m
    | succ p, ih ⇒ ih
    end
  end
end

eval let module Five where
         open Adder 5 use (add) export (addIter)
         def eight : ℕ ≔ add 3 end
       end
     in Five.addIter Five.eight
     end
output
Evaluate let module M1 where
               private def add : ∀ (x1 : ℕ) → ℕ ≔
                 (Adder 5).add
               end
               def addIter : ∀ (x2 : ℕ)
                               → Eq (Adder.add 5 x2)
                                   (Iter.iter 0l ℕ (λ (x3 : ℕ) → succ x3) x2
                                     5) ≔
                 (Adder 5).addIter
               end
               def eight : ℕ ≔
                 add 3
               end
             end
         in M1.addIter M1.eight
         end --> ⋆ : ⊤

14. Universe levels. Level is a type, with the literals 0l, 1l, …, and the operations succl and maxl; levels are compared by normalization, so maxl 1l (succl 2l) is 3l. Type@{t} is the universe at the level t, and Type@n abbreviates Type@{nl}.

eval maxl 1l (succl 2l)
output
Evaluate maxl 1l (succl 2l) --> 3l : Level
eval Type@{maxl 1l 2l}
output
Evaluate Type@{maxl 1l 2l} --> Type@2 : Type@3

A level-polymorphic definition takes its level as an argument. A function type of types of Type@{u} is in Type@{u}, even for a variable u.

def applyTwice (u : Level) (A : Type@{u}) (f : ∀ (a : A) → A) : ∀ (a : A) → A ≔
  λ (a : A) → f (f a)
end

eval applyTwice 0l ℕ double 1
output
Evaluate applyTwice 0l ℕ double 1 --> 4 : ℕ
eval applyTwice 1l Type@0 (λ (A : Type@0) → ∀ (a : A) → A) ℕ
output
Evaluate applyTwice 1l Type@0 (λ (A1 : Type@0) → ∀ (x1 : A1) → A1) ℕ
  --> ∀ (x1 : ∀ (x2 : ℕ) → ℕ)
        (x3 : ℕ)
        → ℕ : Type@0

Cumulativity: a type of Type@{u} is also one of Type@{maxl u v}.

def widen (u : Level) (v : Level) (A : Type@{u}) : Type@{maxl u v} ≔ A end

A module may take a level, so that all its members share it: the Prelude's Prelude›Function›Iter takes (u : Level) (A : Type@{u}), and Iter.iter 0l ℕ iterates on numbers.

module Pointed (u : Level) (A : Type@{u}) (a : A) where
  def point : A ≔ a end
end

eval Pointed.point 1l Type@0 ℕ
output
Evaluate Pointed.point 1l Type@0 ℕ --> ℕ : Type@0

A Church encoding quantifies over a universe, so it lives one level up: the conjunction of the Prelude, Prelude›Logic.Conj u, is in Type@{succl u}. A type quantifying over levels themselves is large, in Type@ω, above every Type@{u}.

eval ∀ (u : Level) → Type@{u}
output
Evaluate ∀ (x1 : Level) → Type@{x1} --> ∀ (x1 : Level) → Type@{x1} : Type@ω
