The Fibonacci numbers, computed in linear time by iterating on a pair of consecutive values.

module Prelude›Arith›Fibonacci where

import Prelude›Arith›Plus use (plus)

fibFrom n a b is the n-th term of the Fibonacci-like sequence that starts with a and b: fibFrom 0 a b is a, and fibFrom (succ n) a b is fibFrom n b (plus a b). The pair a, b holds two consecutive terms.

def fibFrom (n : ℕ) (a : ℕ) (b : ℕ) : ℕ ≔
  (rec n return y . (∀ (x : ℕ) (z : ℕ) → ℕ)
   | zero ⇒ λ (x : ℕ) (z : ℕ) → x
   | succ p, r ⇒ λ (x : ℕ) (z : ℕ) → r z (plus x z)
   end) a b
end

The Fibonacci numbers 0, 1, 1, 2, 3, 5, ....

def fib (n : ℕ) : ℕ ≔ fibFrom n 0 1 end
