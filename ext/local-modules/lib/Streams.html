A client of Prelude›Data›Stream and its laws: the natural numbers, the even and odd numbers, the squares and two Fibonacci-like streams are read with nth and summed through take, and closed instances of the laws normalize to ⋆.

Streams of numbers.

module S ≔ St 0l ℕ

def square (x : ℕ) : ℕ ≔ mult x x end

The even numbers 0, 2, 4, ....

def evens : S.Stream ≔ S.map ℕ double nats end

The odd numbers 1, 3, 5, ..., iterating + 2 from 1.

def odds : S.Stream ≔ S.iterate (λ (x : ℕ) → succ (succ x)) 1 end

def squares : S.Stream ≔ S.map ℕ square nats end

The Fibonacci-like stream from the seeds a and b: the first components of the iterated Fibonacci step on pairs.

module FibLike (a : ℕ) (b : ℕ) where

Pairs of numbers, the step on them, and the seeds: the implementation of stream, private to the module.

private module Pairs where

A pair of numbers, as a function from the index 0 or 1.

def Pair : Type@0 ≔ ∀ (i : ℕ) → ℕ end

One Fibonacci step (x, y) to (y, x + y).

def fibStep (p : Pair) : Pair ≔
  λ (i : ℕ) →
    rec i return y . ℕ
    | zero ⇒ p 1
    | succ q, r ⇒ plus (p 0) (p 1)
    end
end

The seeds, as a pair.

def seed : Pair ≔
  λ (i : ℕ) → rec i return y . ℕ | zero ⇒ a | succ q, r ⇒ b end
end

end

open Pairs use (Pair; fibStep; seed)

def stream : S.Stream ≔
  St.map 0l Pair ℕ (λ (p : Pair) → p 0) (St.iterate 0l Pair fibStep seed)
end

end

def fibs : S.Stream ≔ FibLike.stream 0 1 end

def lucas : S.Stream ≔ FibLike.stream 2 1 end
