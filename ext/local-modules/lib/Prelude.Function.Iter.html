Prelude::Function::Iter

Contents
  • def iter

Iteration of an arbitrary function: a unit parameterized by the level u of the type, the type A and the function, so each client instantiates it as it needs: Iter.iter 0l Nat f n a iterates on numbers, Iter.iter 1l Type@0 F n A iterates a type former.

module Prelude::Function::Iter (u : Level) (A : Type@{u}) (f : forall (a : A) -> A) where

def iter (n : Nat) (a : A) : A :=
  rec n return y . A
  | zero => a
  | succ p, r => f r
  end
end

end
