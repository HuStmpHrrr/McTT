Combinatorics

Contents

    A client of Prelude::Arith::Binomial and Prelude::Arith::Fibonacci: the first rows of Pascal's triangle and of the Fibonacci numbers, and closed instances of their laws, which normalize to true.

    module Combinatorics where

import Prelude::Arith::Binomial use (choose)
import Prelude::Arith::Binomial::Properties.Basic use (chooseZero; chooseSelf; chooseOne; chooseOver; pascal)
open Prelude::Arith::Binomial::Properties.Symmetry use (chooseSymm; chooseSymmSub)
open Prelude::Arith::Binomial::Properties.Row use (rowSum)
import Prelude::Arith::Fibonacci use (fib)
import Prelude::Arith::Fibonacci::Properties.Basic use (fibSucc)
open Prelude::Arith::Fibonacci::Properties.Growth use (fibPos; fibMono; fibMonoPlus)
open Prelude::Arith::Fibonacci::Properties.Identities use (fibSum; fibPlus)
import Prelude::Arith::Sum use (sumTo)

    A proof of a closed proposition normalizes to true, of type True. The numbers stay small: checking Eq n n takes time exponential in n.

    eval chooseZero 5

eval chooseSelf 5

eval chooseOne 5

eval chooseOver 3 5 true

eval pascal 4 2

eval chooseSymm 2 3

eval chooseSymmSub 5 2 true

eval rowSum 4
