Generalizable All Variables.

The codomain of a Π whose codomain is a family value f: in the environment of f, #1 $ #0 is f at the argument. The types of the arguments of a function shape and of their recursive results are such Πs (d_shfam, d_ihfam): their codomains are computed by the families, so no term is built.
Definition fam_cod : exp := a_app (a_var 1) (a_var 0).

The Kinds of Members of Module Values

A local open declares, for each item, a definition or an alias, by the kind of the member it names (items_gen). Evaluation must tell them apart without a type: the kind of a member is read off the module value and the syntax of the units it closes over. A body is read through the entries it makes (kenv), as evaluation would but with a placeholder for every definition, so that no term is evaluated: a kind does not depend on the values of terms, nor on a module's arguments, which are terms (kpad). The relations mirror member_type with the types left out, and read a closure or a submodule closure as selection on module values does (eval_selm).
n placeholders for parameters, terms, over ρ.
Definition kpad (n : nat) (ρ : env) : env := List.repeat (de_term d_true) n ++ ρ.

The entry a body's entry adds over ρ, as kinds read it: a module, its closure; any other, a placeholder, as in body_ctx.
Definition kbentry (ρ : env) (E : gentry) : dentry :=
  match E with
  | ge_mod _ U => de_mod (dm_local ρ U nil)
  | _ => de_term d_true
  end.

The entries generated items add over ρ, as kinds read them, the k-th under the k before it: an alias, the closure of its unit; a definition, a placeholder.
Definition kentry (ρ : env) (k : nat) (g : igen) : dentry :=
  match g with
  | ig_alias _ _ E => de_mod (dm_local ρ (gu_mk nil (md_alias (modexp_wk E (wk_shiftn k)))) nil)
  | _ => de_term d_true
  end.

Fixpoint kgens_env (ρ : env) (k : nat) (gs : list igen) : env :=
  match gs with
  | nil => ρ
  | g :: gs' => kgens_env (kentry ρ k g :: ρ) (S k) gs'
  end.

| kg_self : forall ρ H d pv its gs,

Evaluation of Expressions

The relations are mutually defined: evaluation of terms, the eliminator's cases and semantic application; evaluation of module expressions and the operations on module values (application, selection of a submodule or a member, along a chain); and the environment a body unit's members see. All are relative to the global context Θ ⍮ Ξ, which does not change during NbE. A global is resolved by lookup in Θ ⍮ Ξ: a transparent definition unfolds to its body, and any other global is a neutral at its type. No rule applies a syntactic operation such as substitution to a term, and none builds syntax: a global is looked up, never rebuilt.
A module value is saturated when it has as many arguments as its unit has parameters. Selection on a saturated module is δ: it gives the bound value, by evaluating the body up to the member, or by selecting from the alias's target. Selection on an unsaturated one gives a member closure (d_member, dm_member), which the remaining arguments complete. A global module needs neither: its members are stored generalized over its parameters, so selection applies the generalized member to the arguments there are.
Inductive eval_exp (Θ : gdeps) (Ξ : gstack) : exp -> env -> domain -> Prop :=
A universe is its own value.
| eval_exp_typ :
  `( ⟦ Typeω@i ⟧ Θ ⍮ Ξ ⍮ ρ ↘ 𝕌ω@i )
A small universe evaluates its level.
| eval_exp_univ :
  `( ⟦ M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ l ->
     ⟦ Type⟨M⟩ ⟧ Θ ⍮ Ξ ⍮ ρ ↘ 𝕌@l )
Level is a value.
| eval_exp_level :
  `( ⟦ Level@n ⟧ Θ ⍮ Ξ ⍮ ρ ↘ Levelᵈ@n )
A level literal is the flat level with that constant and no atom.
| eval_exp_llit :
  `( ⟦ 𝕃ᵒ o ⟧ Θ ⍮ Ξ ⍮ ρ ↘ dlvl_lit o )
The level operations only flatten: they add to the offsets, or join the constants and concatenate the atoms. Canonicalisation is readback's.
| eval_exp_succl :
  `( ⟦ M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ m ->
     ⟦ succl M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ dlvl_suc m )
| eval_exp_maxl :
  `( ⟦ M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ m ->
     ⟦ N ⟧ Θ ⍮ Ξ ⍮ ρ ↘ n ->
     ⟦ maxl M N ⟧ Θ ⍮ Ξ ⍮ ρ ↘ dlvl_max m n )
A variable is read off the environment.
| eval_exp_var :
  `( ⟦ #x ⟧ Θ ⍮ Ξ ⍮ ρ ↘ ρ x )
⊤ is a value.
| eval_exp_True :
  `( ⟦ ⊤ ⟧ Θ ⍮ Ξ ⍮ ρ ↘ ⊤ᵈ )
So is ⋆.
| eval_exp_true :
  `( ⟦ ⋆ ⟧ Θ ⍮ Ξ ⍮ ρ ↘ ⋆ᵈ )
⊥ is a value.
| eval_exp_False :
  `( ⟦ ⊥ ⟧ Θ ⍮ Ξ ⍮ ρ ↘ ⊥ᵈ )
⊥ has no canonical values, so the eliminator only meets a neutral.
| eval_exp_exfalso :
  `( ⟦ M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ ⇑ b m ->
     ⟦ A ⟧ Θ ⍮ Ξ ⍮ ρ ↦ ⇑ b m ↘ a ->
     ⟦ efq M return A ⟧ Θ ⍮ Ξ ⍮ ρ ↘ ⇑ a (efqᵈ m under ρ return A) )
The type former and a constructor of an inductive type are values, with no argument yet.
| eval_exp_indty :
  `( ⟦ a_ind p ⟧ Θ ⍮ Ξ ⍮ ρ ↘ d_ind p nil )
| eval_exp_con :
  `( ⟦ a_con p c ⟧ Θ ⍮ Ξ ⍮ ρ ↘ d_con p c nil )
The eliminator evaluates its scrutinee, then eliminates the value.
| eval_exp_elim :
  `( ⟦ M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ m ->
     ⟦elim m under nm A Bs ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r ->
     ⟦ a_elim nm A Bs M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r )
A Π evaluates its domain and closes over its codomain.
| eval_exp_pi :
  `( ⟦ A ⟧ Θ ⍮ Ξ ⍮ ρ ↘ a ->
     ⟦ Π A B ⟧ Θ ⍮ Ξ ⍮ ρ ↘ Πᵈ a ρ B )
A function closes over its body.
| eval_exp_fn :
  `( ⟦ λ A M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ λᵈ ρ M )
An application applies the value of the function to that of the argument.
| eval_exp_app :
  `( ⟦ M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ m ->
     ⟦ N ⟧ Θ ⍮ Ξ ⍮ ρ ↘ n ->
     $| m & n | Θ ⍮ Ξ ↘ r ->
     ⟦ M $ N ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r )
A local definition extends the environment by the value of its body; nothing is substituted.
| eval_exp_let :
  `( ⟦ M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ m ->
     ⟦ B ⟧ Θ ⍮ Ξ ⍮ ρ ↦ m ↘ r ->
     ⟦ a_let (b_def oA M) B ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r )
A local module extends it by the unit's closure.
| eval_exp_let_mod :
  `( ⟦ B ⟧ Θ ⍮ Ξ ⍮ ρ ↦ᵐ dm_local ρ U nil ↘ r ->
     ⟦ ℓₘ U in B ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r )
A member is read off the root of its module expression, then applied to the module's arguments: arguments commute with selection. Without arguments this is selection from the module's value.
| eval_exp_mem :
  `( modexp_spine H = (R, args, pre) ->
     ⟦ R ⟧ᵐ Θ ⍮ Ξ ⍮ ρ ↘ h ->
     h ·ₜ* (pre ++ x :: nil) Θ ⍮ Ξ ↘ f ->
     ⟦ args ⟧* Θ ⍮ Ξ ⍮ ρ ↘ ns ->
     $*| f & ns | Θ ⍮ Ξ ↘ r ->
     ⟦ a_mem H x ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r )
where "'⟦' e '⟧' Θ '⍮' Ξ '⍮' ρ '↘' r" := (eval_exp Θ Ξ e ρ r)
The eliminator of an inductive type, on a value. On a constructor at all its parameters and arguments, the branch of the constructor, with its non-uniform parameters, its arguments and the recursive results. On a neutral of the type, a neutral at the motive's instance; the neutral records the inductive type and its parameters, which readback needs.
with eval_elim (Θ : gdeps) (Ξ : gstack) : env -> nat -> exp -> list (string * nat * exp) -> domain -> domain -> Prop :=
| eval_elim_con :
  `( ind_lookup Θ Ξ p = Some D ->
     ind_con D c = Some gs ->
     List.length vs = (ind_np D + List.length gs)%nat ->
     brs_lookup Bs c = Some (n, B) ->
     n = (ind_nn D + List.length gs + cargs_nrec gs)%nat ->
     ⟦ihs skipn (ind_np D) vs of gs under nm A Bs ⟧ Θ ⍮ Ξ ⍮ ρ ↘ ihs ->
     ⟦ B ⟧ Θ ⍮ Ξ ⍮ env_args ρ (skipn (ind_nu D) (firstn (ind_np D) vs) ++ skipn (ind_np D) vs ++ ihs) ↘ r ->
     ⟦elim d_con p c vs under nm A Bs ⟧ Θ ⍮ Ξ ⍮ ρ ↘ r )
| eval_elim_neut :
  `( ind_lookup Θ Ξ p = Some D ->
     List.length as' = ind_np D ->
     nm = S (ind_nn D) ->
     ⟦ A ⟧ Θ ⍮ Ξ ⍮ env_args ρ (skipn (ind_nu D) as' ++ ⇑ (d_ind p as') m :: nil) ↘ a ->
     ⟦elim ⇑ (d_ind p as') m under nm A Bs ⟧ Θ ⍮ Ξ ⍮ ρ ↘ ⇑ a (d_elim ρ nm A Bs p as' m) )
where "'⟦elim' m 'under' nm A Bs '⟧' Θ '⍮' Ξ '⍮' ρ '↘' r" := (eval_elim Θ Ξ ρ nm A Bs m r)
The recursive results of the arguments vs, one per recursive argument.

| eval_ihs_arg :

A function's body, at the argument.
| eval_app_fn :
  `( ⟦ M ⟧ Θ ⍮ Ξ ⍮ ρ ↦ n ↘ m ->

  `( ⟦ B ⟧ Θ ⍮ Ξ ⍮ ρ ↦ n ↘ b ->

Evaluation of Substitutions

Evaluation of a substitution is pointwise: at every variable x, ρσ x is the entry σ x denotes in ρ: the entry of a variable, the value of a term, or the value of a module expression. Past its end ρσ reads the term ⋆ᵈ, so a result exists only when, from some index on, every σ x denotes it, for example as a variable past the end of ρ.
Definition eval_sentry (Θ : gdeps) (Ξ : gstack) (e : sentry) (ρ : env) (d : dentry) : Prop :=
  match e with
  | se_var y => d = env_entry ρ y
  | se_exp M => exists m, d = de_term m /\ ⟦ M ⟧ Θ ⍮ Ξ ⍮ ρ ↘ m
  | se_mod H => exists h, d = de_mod h /\ ⟦ H ⟧ᵐ Θ ⍮ Ξ ⍮ ρ ↘ h
  end.

Definition eval_sub (Θ : gdeps) (Ξ : gstack) (σ : sub) (ρ ρσ : env) : Prop :=
  forall x, eval_sentry Θ Ξ (σ x) ρ (env_entry ρσ x).
Arguments eval_sub : simpl never.

Notation "'⟦' σ '⟧s' Θ '⍮' Ξ '⍮' ρ '↘' ρσ" := (eval_sub Θ Ξ σ ρ ρσ) : mctt_scope.

The variables of a term and of a module expression read the entry their substitution denotes, at the right sort; at the wrong one both sides read the default.
Lemma eval_sub_var : forall {Θ Ξ} σ ρ ρσ x,
    ⟦ σ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ρσ ->
    ⟦ #x[σ] ⟧ Θ ⍮ Ξ ⍮ ρ ↘ ρσ x.
Proof.
  intros * Hσ; specialize (Hσ x); cbn; unfold env_var.
  destruct (σ x) as [y | M | H]; cbn in Hσ |- *.
  - rewrite Hσ; apply eval_exp_var.
  - destruct Hσ as (m & -> & Hm); exact Hm.
  - destruct Hσ as (h & -> & _); constructor.
Qed.

Lemma eval_sub_mvar : forall {Θ Ξ} σ ρ ρσ x,
    ⟦ σ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ρσ ->
    ⟦ (me_var x)[σ]ᵐ ⟧ᵐ Θ ⍮ Ξ ⍮ ρ ↘ env_mod ρσ x.
Proof.
  intros * Hσ; specialize (Hσ x); cbn; unfold env_mod.
  destruct (σ x) as [y | M | H]; cbn in Hσ |- *.
  - rewrite Hσ; apply eval_me_var.
  - destruct Hσ as (m & -> & _); apply eval_me_unit.
  - destruct Hσ as (h & -> & Hh); exact Hh.
Qed.

The Substitutions that Compute

Evaluation of the substitutions that occur in practice:
  • the image under ι of an order-preserving weakening, for which ⟪φ⟫ ρ is ρ ∘ φ at every index;
  • weakened extensions and lifts;
  • precomposition by a weakening.
Lemma eval_sub_of_wk : forall {Θ Ξ} φ ρ `{Hφ : WkMono φ},
    ⟦ ι φ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ⟪φ⟫ ρ.
Proof.
  intros Θ Ξ φ ρ Hφ x; cbn; rewrite (eval_wk_entry _ _ Hφ x); reflexivity.
Qed.

A weakened extension.
Lemma eval_sub_wk_extend : forall {Θ Ξ} σ M φ ρ ρσ m,
    ⟦ sb_wk σ φ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ρσ ->
    ⟦ M[φ]ʷ ⟧ Θ ⍮ Ξ ⍮ ρ ↘ m ->
    ⟦ sb_wk (σ,,M) φ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ρσ ↦ m.
Proof. intros * ? ? [| x]; [ exists m; split; [ reflexivity | assumption ] | apply H ]. Qed.

A lifted substitution, plain and weakened. q σ extends σ[↑] by the variable 0, so its head is the entry already in ρ.
Lemma eval_sub_q : forall {Θ Ξ} σ ρ ρσ,
    ⟦ sb_wk σ ↑ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ρσ ->
    ⟦ q σ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ env_entry ρ 0 :: ρσ.
Proof.
  intros * H [| x]; [ reflexivity |].
  rewrite sb_q_succ; exact (H x).
Qed.

Lemma eval_sub_wk_q : forall {Θ Ξ} σ φ ρ ρσ,
    ⟦ sb_wk (sb_wk σ ↑) φ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ρσ ->
    ⟦ sb_wk (q σ) φ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ env_entry ρ (φ 0) :: ρσ.
Proof.
  intros * H [| x]; cbn [sb_wk]; [ rewrite sb_q_zero; reflexivity |].
  rewrite sb_q_succ; exact (H x).
Qed.

Precomposition by a weakening reindexes the environment σ evaluates to.
Lemma eval_sub_wk_pre : forall {Θ Ξ} φ σ ρ ρσ `{Hφ : WkMono φ},
    ⟦ σ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ρσ ->
    ⟦ (ι φ) ⨟ σ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ⟪φ⟫ ρσ.
Proof.
  intros Θ Ξ φ σ ρ ρσ Hφ H x; rewrite (eval_wk_entry _ _ Hφ x); exact (H (φ x)).
Qed.

Corollary eval_sub_shift_pre : forall {Θ Ξ} σ ρ ρσ,
    ⟦ σ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ρσ ->
    ⟦ Wk ⨟ σ ⟧s Θ ⍮ Ξ ⍮ ρ ↘ ρσ↯.
Proof. intros * H x; rewrite env_entry_drop; exact (H (S x)). Qed.
