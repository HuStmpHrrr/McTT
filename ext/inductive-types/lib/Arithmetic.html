Arithmetic

Contents

    A client of the arithmetic in Prelude: closed instances of the laws of addition and multiplication, and a few computations.

    module Arithmetic where

import Prelude›Arith›Equality use (refl; cong)
import Prelude›Arith›Plus use (plus)
open Prelude›Arith›Plus.Algebra use (plusAssoc)
open Prelude›Arith›Plus.Cancel use (plusCancelLeft; plusCancelRight; plusEqZero)
import Prelude›Arith›Mult use (mult)
open Prelude›Arith›Mult.Algebra
  use (multComm; multAssoc; multDistribLeft; multDistribRight)
open Prelude›Arith›Mult.Cancel use (multEqZero)

eval mult 6 7
    output
    Evaluate mult 6 7 --> 42 : ℕ
    eval plus (mult 3 4) (mult 2 5)
    output
    Evaluate plus (mult 3 4) (mult 2 5) --> 22 : ℕ

    A proof of a closed equation normalizes to ⋆, of type ⊤.

    eval plusAssoc 1 2 3
    output
    Evaluate plusAssoc 1 2 3 --> ⋆ : ⊤
    eval multComm 3 4
    output
    Evaluate multComm 3 4 --> ⋆ : ⊤
    eval multAssoc 2 3 4
    output
    Evaluate multAssoc 2 3 4 --> ⋆ : ⊤
    eval multDistribLeft 2 3 4
    output
    Evaluate multDistribLeft 2 3 4 --> ⋆ : ⊤
    eval multDistribRight 2 3 4
    output
    Evaluate multDistribRight 2 3 4 --> ⋆ : ⊤
    eval cong (λ (x : ℕ) → mult x x) 3 3 (refl 3)
    output
    Evaluate cong (λ (x1 : ℕ) → mult x1 x1) 3 3 (refl 3) --> ⋆ : ⊤
    eval plusCancelLeft 2 3 3 ⋆
    output
    Evaluate plusCancelLeft 2 3 3 ⋆ --> ⋆ : ⊤
    eval plusCancelRight 4 4 1 ⋆
    output
    Evaluate plusCancelRight 4 4 1 ⋆ --> ⋆ : ⊤
    eval plusEqZero 0 0 ⋆
    output
    Evaluate plusEqZero 0 0 ⋆ --> ⋆ : ⊤

    Not (Eq 2 0) computes to ⊥ → ⊥.

    eval multEqZero 2 0 ⋆ (λ (h : ⊥) → h)
    output
    Evaluate multEqZero 2 0 ⋆ (λ (x1 : ⊥) → x1) --> ⋆ : ⊤
    end
