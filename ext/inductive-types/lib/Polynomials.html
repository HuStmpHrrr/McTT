Polynomials

Polynomials with natural coefficients, evaluated at a point. A polynomial of length n is a coefficient function c read at the indices below n, so c i is the coefficient of x to the i.

The point x is fixed across an evaluation, so the evaluators live in a module At (x : ℕ). Horner's scheme and the sum of monomials agree at every point (At.hornerNaive); at the point 1 both give the sum of the coefficients (hornerAtOne).

def Coeffs : Type@0 ≔ ∀ (i : ℕ) → ℕ end

The coefficients a, b, c, d, then zeros.

def cubic (a : ℕ) (b : ℕ) (c : ℕ) (d : ℕ) : Coeffs ≔
  λ (i : ℕ) →
    elim i return y . ℕ
    | zero ⇒ a
    | succ j, r ⇒
        elim j return z . ℕ
        | zero ⇒ b
        | succ k, s ⇒ elim k return w . ℕ | zero ⇒ c | succ l, t ⇒ d end
        end
    end
end

The pieces of Horner's scheme, private to At: the shifted coefficients, the monomials, and the scheme generalized over the coefficients.

private module Scheme where

The coefficients of (c - c 0) / x: the polynomial shifted down.

def shift (c : Coeffs) : Coeffs ≔ λ (i : ℕ) → c (succ i) end

The monomial of index i.

def term (c : Coeffs) (i : ℕ) : ℕ ≔ mult (c i) (pow x i) end

Horner's scheme, c 0 + x * (c 1 + x * (...)), by recursion on the length, generalized over the coefficients.

def hornerFrom (n : ℕ) : ∀ (c : Coeffs) → ℕ ≔
  elim n return k . (∀ (c : Coeffs) → ℕ)
  | zero ⇒ λ (c : Coeffs) → 0
  | succ p, r ⇒ λ (c : Coeffs) → plus (c 0) (mult x (r (shift c)))
  end
end

end

open Scheme use (shift; term; hornerFrom)

def horner (c : Coeffs) (n : ℕ) : ℕ ≔ hornerFrom n c end

The sum of the monomials, each with its own power of x.

def naive (c : Coeffs) (n : ℕ) : ℕ ≔
  sumTo (λ (i : ℕ) → mult (c i) (pow x i)) n
end

Horner's scheme computes the sum of the monomials. In the step, the factor x goes into the sum (sumToScale) and into each power (multLeftComm), and the first monomial is split off (sumToShift).

theorem hornerNaive : ∀ (c : Coeffs) (n : ℕ) → Eq (horner c n) (naive c n) ≔
  λ (c : Coeffs) (n : ℕ) →
    (elim n return k . (∀ (d : Coeffs) → Eq (hornerFrom k d) (sumTo (term d) k))
     | zero ⇒ λ (d : Coeffs) → ⋆
     | succ p, ih ⇒ λ (d : Coeffs) →
         let rest ≔ hornerFrom p (shift d);
             tail ≔ sumTo (term (shift d)) p;
             scaled ≔ sumTo (λ (i : ℕ) → mult x (term (shift d) i)) p;
             shifted ≔ sumTo (λ (i : ℕ) → term d (succ i)) p;
             whole ≔ sumTo (term d) (succ p);
             inner : Eq (mult x rest) (mult x tail) ≔
               cong (λ (y : ℕ) → mult x y) rest tail (ih (shift d));
             scale : Eq (mult x tail) scaled ≔
               sym scaled (mult x tail) (sumToScale x (term (shift d)) p);
             powers : Eq scaled shifted ≔
               sumToExt (λ (i : ℕ) → mult x (term (shift d) i))
                 (λ (i : ℕ) → term d (succ i))
                 (λ (i : ℕ) → multLeftComm x (d (succ i)) (pow x i)) p;
             first : Eq (plus (d 0) shifted) whole ≔
               trans (plus (d 0) shifted) (plus (term d 0) shifted) whole
                 (cong (λ (y : ℕ) → plus y shifted) (d 0) (term d 0)
                    (sym (term d 0) (d 0) (multIdentityRight (d 0))))
                 (sym whole (plus (term d 0) shifted) (sumToShift (term d) p))
         in trans (plus (d 0) (mult x rest)) (plus (d 0) shifted) whole
              (cong (λ (y : ℕ) → plus (d 0) y) (mult x rest) shifted
                 (trans (mult x rest) (mult x tail) shifted inner
                    (trans (mult x tail) scaled shifted scale powers)))
              first
         end
     end) c
end

end

At the point 1, a polynomial is the sum of its coefficients. The proof instantiates At locally, and uses onePow in every monomial.

theorem hornerAtOne : ∀ (c : Coeffs) (n : ℕ) →
    Eq (At.horner 1 c n) (sumTo c n) ≔
  λ (c : Coeffs) (n : ℕ) →
    let module One ≔ At 1
    in trans (One.horner c n) (One.naive c n) (sumTo c n)
         (One.hornerNaive c n)
         (sumToExt (λ (i : ℕ) → mult (c i) (pow 1 i)) c
            (λ (i : ℕ) →
               trans (mult (c i) (pow 1 i)) (mult (c i) 1) (c i)
                 (cong (λ (y : ℕ) → mult (c i) y) (pow 1 i) 1 (onePow i))
                 (multIdentityRight (c i)))
            n)
    end
end

An evaluator for a fixed polynomial, made locally: the values at the points below k, summed, and their maximum. The maximum comes from an open inside the local body. A local body may not import, so the unit is loaded just before.

import Prelude›Arith›MinMax

eval let module Table (c : Coeffs) where
       open Prelude›Arith›MinMax use (max)
       def value (x : ℕ) : ℕ ≔ At.horner x c 4 end
       def total (k : ℕ) : ℕ ≔ sumTo value k end
       def peak (k : ℕ) : ℕ ≔
         elim k return y . ℕ | zero ⇒ 0 | succ p, r ⇒ max (value p) r end
       end
     end
     in plus (Table.total (cubic 1 1 0 0) 4) (Table.peak (cubic 0 0 1 0) 5)
     end
output
Evaluate let module M1 (x1 : Coeffs) where
               open Prelude›Arith›MinMax use (max)
               def value : ∀ (x2 : ℕ) → ℕ ≔
                 λ (x3 : ℕ) → At.horner x3 x1 4
               end
               def total : ∀ (x4 : ℕ) → ℕ ≔
                 λ (x5 : ℕ) → sumTo value x5
               end
               def peak : ∀ (x6 : ℕ) → ℕ ≔
                 λ (x7 : ℕ)
                   → elim x7 return x8 . ℕ
                     | zero ⇒ 0
                     | succ x9, x10 ⇒ max (value x9) x10
                     end
               end
             end
         in plus (M1.total (cubic 1 1 0 0) 4) (M1.peak (cubic 0 0 1 0) 5)
         end --> 26 : ℕ
