Well-founded trees, after Agda's Data.W: W u A B has the one constructor sup x f, a node of shape x : A with a subtree f p at each position p : B x, at every level u. The recursive argument f is a function into the type.

The operations over fixed A and B are in the module Ops u A B: the projections head and tail, map along a morphism of containers (shapes forward, positions backward), and foldr into a fixed type. Induction is the recursor W.rec. The laws are in Prelude›Data›W›Properties.

module Prelude›Data›W where

inductive W (u : Level) (A : Type@{u}) (B : ∀ (a : A) → Type@{u}) : Type@{u}
where
| sup (x : A) (f : ∀ (p : B x) → W u A B)
end

open W export (sup)

module Ops (u : Level) (A : Type@{u}) (B : ∀ (a : A) → Type@{u}) where

inductive T ≔ W u A B

def head (w : T) : A ≔ elim w return z . A | sup x f, h ⇒ x end end

The subtrees: a function of the positions of the head.

def tail (w : T) : ∀ (p : B (head w)) → T ≔
  elim w return z . (∀ (p : B (head z)) → T) | sup x f, h ⇒ f end
end

Along m on shapes and n on positions, which goes the other way.

def map (C : Type@{u}) (D : ∀ (c : C) → Type@{u}) (m : ∀ (a : A) → C)
    (n : ∀ (a : A) (d : D (m a)) → B a) (w : T) : W u C D ≔
  elim w return z . W u C D
  | sup x f, h ⇒ W.sup u C D (m x) (λ (d : D (m x)) → h (n x d))
  end
end

The fold: alg combines a shape and the results at its positions.

def foldr (P : Type@{u}) (alg : ∀ (x : A) (r : ∀ (p : B x) → P) → P)
    (w : T) : P ≔
  elim w return z . P | sup x f, h ⇒ alg x h end
end

end
