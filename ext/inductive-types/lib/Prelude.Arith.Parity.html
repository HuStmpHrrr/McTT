Parity of natural numbers: Even and Odd computed by recursion, with doubling and the basic laws.

Parity flags, and numbers having a given flag. Even and Odd below unfold to HasParity; the flags themselves stay private.

private module Flag where

Exchanges the parity flags 0 (even) and 1 (odd).

def flip (b : ℕ) : ℕ ≔
  elim b return y . ℕ | zero ⇒ 1 | succ q, s ⇒ 0 end
end

HasParity n b says that n has parity b, where 0 is even and 1 is odd. It recurses on n and flips b at each step, so by conversion Even (succ n) is Odd n and Odd (succ n) is Even n.

def HasParity : ∀ (n : ℕ) (b : ℕ) → Type@0 ≔
  λ (n : ℕ) →
    elim n return y . (∀ (b : ℕ) → Type@0)
    | zero ⇒ λ (b : ℕ) →
        elim b return z . Type@0 | zero ⇒ ⊤ | succ q, s ⇒ ⊥ end
    | succ p, r ⇒ λ (b : ℕ) → r (flip b)
    end
end

end

open Flag use (HasParity)

def Even (n : ℕ) : Type@0 ≔ HasParity n 0 end

def Odd (n : ℕ) : Type@0 ≔ HasParity n 1 end

def double (n : ℕ) : ℕ ≔
  elim n return y . ℕ
  | zero ⇒ 0
  | succ p, r ⇒ succ (succ r)
  end
end

Parity of doubles, successors and sums.

module Laws where

theorem evenDouble : ∀ (n : ℕ) → Even (double n) ≔
  λ (n : ℕ) →
    elim n return x . Even (double x)
    | zero ⇒ ⋆
    | succ p, ih ⇒ ih
    end
end

theorem evenSuccOdd : ∀ (n : ℕ) (h : Even n) → Odd (succ n) ≔
  λ (n : ℕ) (h : Even n) → h
end

theorem oddSuccEven : ∀ (n : ℕ) (h : Odd n) → Even (succ n) ≔
  λ (n : ℕ) (h : Odd n) → h
end

Every number is even or odd: the step swaps the two sides.

def evenOrOdd : ∀ (n : ℕ) → Or (Even n) (Odd n) ≔
  λ (n : ℕ) →
    elim n return x . Or (Even x) (Odd x)
    | zero ⇒ orInl (Even 0) (Odd 0) ⋆
    | succ p, ih ⇒ orSwap (Even p) (Odd p) ih
    end
end

No number is both even and odd. And lives in Type@1, so the negation is the one at level 1l.

theorem notEvenAndOdd : ∀ (n : ℕ) → Neg.Not 1l (And (Even n) (Odd n)) ≔
  λ (n : ℕ) →
    elim n return x . (∀ (h : And (Even x) (Odd x)) → ⊥)
    | zero ⇒ λ (h : And ⊤ ⊥) → h ⊥ (λ (a : ⊤) (b : ⊥) → b)
    | succ p, ih ⇒ λ (h : And (Odd p) (Even p)) →
        ih (andSwap (Odd p) (Even p) h)
    end
end

The sum of two even numbers is even. The induction on a carries both "even a gives even plus a b" and "odd a gives odd plus a b", which the step swaps.

theorem evenPlus : ∀ (a : ℕ) (b : ℕ) (ha : Even a) (hb : Even b) →
    Even (plus a b) ≔
  λ (a : ℕ) (b : ℕ) (ha : Even a) (hb : Even b) →
    let both : And (∀ (h : Even a) → Even (plus a b))
                   (∀ (h : Odd a) → Odd (plus a b)) ≔
          elim a return x . And (∀ (h : Even x) → Even (plus x b))
                                (∀ (h : Odd x) → Odd (plus x b))
          | zero ⇒ andIntro (∀ (h : ⊤) → Even b) (∀ (h : ⊥) → Odd b)
                      (λ (h : ⊤) → hb)
                      (λ (h : ⊥) → absurd (Odd b) h)
          | succ p, ih ⇒ andSwap (∀ (h : Even p) → Even (plus p b))
                                 (∀ (h : Odd p) → Odd (plus p b)) ih
          end
    in both (Even (plus a b)) (λ (f : ∀ (h : Even a) → Even (plus a b))
                                 (g : ∀ (h : Odd a) → Odd (plus a b)) → f ha)
    end
end

end
