Prelude›Arith›Prime

Prime numbers by trial division. smallestDivisor n tries the candidates 2, 3, ... while their square is at most n, and answers the first one that divides n, or n itself when none does. isPrime n is tt when n is at least 2 and has no such divisor, and ff otherwise; Prime n is the computed proposition IsTrue (isPrime n).

Trial division and the invariants of its search. The definitions below unfold to it, and clients see only them.

private module TrialDivision where

Trial division of n from the candidate d, for at most fuel candidates, answering in A. It answers found d for the first candidate d that divides n, and none once mult d d exceeds n or the fuel runs out. It branches with cond, so only the chosen branch, and not the recursive call, is computed.

def trialDivision (A : Type@0) (n : ℕ) (none : A) (found : ∀ (d : ℕ) → A)
    (fuel : ℕ) : ∀ (d : ℕ) → A ≔
  elim fuel return y . (∀ (d : ℕ) → A)
  | zero ⇒ λ (d : ℕ) → none
  | succ f, r ⇒ λ (d : ℕ) →
      cond A (leb (mult d d) n)
        (λ (u : ⊤) →
           cond A (eqb (mod n d) 0) (λ (v : ⊤) → found d)
             (λ (v : ⊤) → r (succ d)))
        (λ (u : ⊤) → none)
  end
end

tt when trial division finds no divisor of n, and ff otherwise.

def noSmallDivisor (n : ℕ) : Bool ≔
  trialDivision Bool n tt (λ (d : ℕ) → ff) n 2
end

Every answer of the search for a divisor divides n: a candidate is answered only when the remainder of n by it is 0.

lemma trialDivisionDivides : ∀ (n : ℕ) (fuel : ℕ) (d : ℕ) →
    Divides (trialDivision ℕ n n (λ (x : ℕ) → x) fuel d) n ≔
  λ (n : ℕ) (fuel : ℕ) →
    elim fuel return x . (∀ (d : ℕ) →
                            Divides (trialDivision ℕ n n (λ (y : ℕ) → y) x d) n)
    | zero ⇒ λ (d : ℕ) → dividesRefl n
    | succ f, ih ⇒ λ (d : ℕ) →
        let next ≔ trialDivision ℕ n n (λ (y : ℕ) → y) f (succ d);
            inner ≔ cond ℕ (eqb (mod n d) 0) (λ (v : ⊤) → d) (λ (v : ⊤) → next)
        in elim leb (mult d d) n return c .
             Divides (cond ℕ c (λ (u : ⊤) → inner) (λ (u : ⊤) → n)) n
           | tt ⇒
               eqbCases (mod n d) 0
                 (λ (c : Bool) →
                    Divides (cond ℕ c (λ (v : ⊤) → d) (λ (v : ⊤) → next)) n)
                 (λ (h : IsFalse (eqb (mod n d) 0)) → ih (succ d))
                 (λ (h : Eq (mod n d) 0) → h)
           | ff ⇒ dividesRefl n
           end
        end
    end
end

When the search for a divisor fails, the smallest divisor is the number itself: both searches run through the same candidates.

lemma trialDivisionNone : ∀ (n : ℕ) (fuel : ℕ) (d : ℕ)
    (h : IsTrue (trialDivision Bool n tt (λ (x : ℕ) → ff) fuel d)) →
    Eq (trialDivision ℕ n n (λ (x : ℕ) → x) fuel d) n ≔
  λ (n : ℕ) (fuel : ℕ) →
    elim fuel return x .
      (∀ (d : ℕ) (h : IsTrue (trialDivision Bool n tt (λ (y : ℕ) → ff) x d)) →
         Eq (trialDivision ℕ n n (λ (y : ℕ) → y) x d) n)
    | zero ⇒ λ (d : ℕ) (h : ⊤) → refl n
    | succ f, ih ⇒ λ (d : ℕ) →
        let flagNext ≔ trialDivision Bool n tt (λ (y : ℕ) → ff) f (succ d);
            next ≔ trialDivision ℕ n n (λ (y : ℕ) → y) f (succ d)
        in elim leb (mult d d) n return c .
             (∀ (h : IsTrue (cond Bool c
                               (λ (u : ⊤) →
                                  cond Bool (eqb (mod n d) 0) (λ (v : ⊤) → ff)
                                    (λ (v : ⊤) → flagNext))
                               (λ (u : ⊤) → tt))) →
                Eq (cond ℕ c
                      (λ (u : ⊤) →
                         cond ℕ (eqb (mod n d) 0) (λ (v : ⊤) → d)
                           (λ (v : ⊤) → next))
                      (λ (u : ⊤) → n)) n)
           | tt ⇒
               elim eqb (mod n d) 0 return e .
                 (∀ (h : IsTrue (cond Bool e (λ (v : ⊤) → ff)
                                   (λ (v : ⊤) → flagNext))) →
                    Eq (cond ℕ e (λ (v : ⊤) → d) (λ (v : ⊤) → next)) n)
               | tt ⇒ λ (h : ⊥) → absurd (Eq d n) h
               | ff ⇒ λ (h : IsTrue flagNext) → ih (succ d) h
               end
           | ff ⇒ λ (h : ⊤) → refl n
           end
        end
    end
end

end

The smallest divisor of n from 2 on, found by trial division up to the square root. It is n when n is prime, and also when n is 0 or 1.

def smallestDivisor (n : ℕ) : ℕ ≔
  trialDivision ℕ n n (λ (d : ℕ) → d) n 2
end

The primality test: tt for primes, ff otherwise.

def isPrime (n : ℕ) : Bool ≔
  cond Bool (leb 2 n) (λ (u : ⊤) → noSmallDivisor n) (λ (u : ⊤) → ff)
end

Prime n says that n is prime. It computes, so a closed instance is ⊤ or ⊥.

def Prime (n : ℕ) : Type@0 ≔ IsTrue (isPrime n) end

The smallest divisor divides, primes are at least 2 and are their own smallest divisor.

module Laws where

The smallest divisor divides the number.

theorem smallestDivisorDivides : ∀ (n : ℕ) → Divides (smallestDivisor n) n ≔
  λ (n : ℕ) → trialDivisionDivides n n 2
end

Every prime is at least 2: below 2, isPrime answers ff.

theorem primeGeTwo : ∀ (n : ℕ) (h : Prime n) → Le 2 n ≔
  λ (n : ℕ) →
    elim n return x . (∀ (h : Prime x) → Le 2 x)
    | zero ⇒ λ (h : ⊥) → h
    | succ p, ih ⇒
        elim p return y . (∀ (h : Prime (succ y)) → Le 2 (succ y))
        | zero ⇒ λ (h : ⊥) → h
        | succ q, s ⇒ λ (h : Prime (succ (succ q))) → ⋆
        end
    end
end

A prime is its own smallest divisor.

theorem primeSmallestDivisor : ∀ (n : ℕ) (h : Prime n) →
    Eq (smallestDivisor n) n ≔
  λ (n : ℕ) →
    elim n return x . (∀ (h : Prime x) → Eq (smallestDivisor x) x)
    | zero ⇒ λ (h : ⊥) → absurd (Eq (smallestDivisor 0) 0) h
    | succ p, ih ⇒
        elim p return y . (∀ (h : Prime (succ y)) →
                             Eq (smallestDivisor (succ y)) (succ y))
        | zero ⇒ λ (h : ⊥) → absurd (Eq (smallestDivisor 1) 1) h
        | succ q, s ⇒ λ (h : IsTrue (noSmallDivisor (succ (succ q)))) →
            trialDivisionNone (succ (succ q)) (succ (succ q)) 2 h
        end
    end
end

end

Closed facts. Prime n computes, so ⋆ proves it for a prime, and the identity refutes it otherwise.

theorem twoPrime : Prime 2 ≔ ⋆ end
