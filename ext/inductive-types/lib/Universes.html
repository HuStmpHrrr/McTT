A client of the level-polymorphic Prelude: Prelude›Universe›Levels, Prelude›Universe›Formers, Prelude›Data›Church and its laws, and the level parameters of Prelude›Logic, Prelude›Data›Vec, Prelude›Function›Iter and Prelude›Arith›Induction. Each section uses a library at a level above 0l, where its old Type@0 version could not go.

1. Levels are data. ofNat computes a level from a number, and the laws of maxl hold by conversion, so lrefl proves their closed instances.

output
Evaluate ofNat 3 --> 3l : Level
eval maxl (ofNat 2) (succl 4l)
output
Evaluate maxl (ofNat 2) (succl 4l) --> 5l : Level
eval plusl 2 (maxl 1l 3l)
output
Evaluate plusl 2 (maxl 1l 3l) --> 5l : Level
eval lrefl 3l : LEq (maxl 2l 3l) (succl 2l)
output
Evaluate lrefl 3l --> λ (x1 : ∀ (x2 : Level) → Type@0)
                        (x3 : x1 3l)
                        → x3 : LEq (maxl 2l 3l) (succl 2l)
eval lrefl 3l : LEq (ofNat (max 2 3)) (maxl (ofNat 2) (ofNat 3))
output
Evaluate lrefl 3l --> λ (x1 : ∀ (x2 : Level) → Type@0)
                        (x3 : x1 3l)
                        → x3
  : LEq (ofNat (max 2 3)) (maxl (ofNat 2) (ofNat 3))

With an open number, ofNat (max m n) is stuck, and the law needs the induction of ofNatMax. From it, ofNat m is below ofNat (max m n).

def ofNatMaxBound (m : ℕ) (n : ℕ) : LLe (ofNat m) (ofNat (max m n)) ≔
  let a ≔ ofNat m;
      b ≔ ofNat n;
      x ≔ ofNat (max m n);
      e : LEq x (maxl a b) ≔ ofNatMax m n
  in ltrans (maxl a x) (maxl a b) x
       (lcong (λ (l : Level) → maxl a l) x (maxl a b) e)
       (lsym x (maxl a b) e)
  end
end

Existence proofs nest one level per quantifier: "some m has some n with m + n = 5" is an existence at 1l of existences at 0l.

def Sums (m : ℕ) : Type@1 ≔ Ex.Exists 0l (λ (n : ℕ) → Eq (plus m n) 5) end

def twoThree : Ex.Exists 1l Sums ≔
  Ex.existsIntro 1l Sums 2 (Ex.existsIntro 0l (λ (n : ℕ) → Eq (plus 2 n) 5) 3 ⋆)
end

The outer witness, then the inner one.

                                             (x2 : Sums x1)

6. Induction into a large motive. Two-step induction at 1l builds a Church numeral (a type of Type@1) by recursion: half of n.

def churchHalf (n : ℕ) : C.Numeral 0l ≔
  Large.twoStepInd (λ (k : ℕ) → C.Numeral 0l) (C.czero 0l) (C.czero 0l)
    (λ (k : ℕ) (r : C.Numeral 0l) → C.csucc 0l r) n
end

eval C.toNat 0l (churchHalf 9)
output
Evaluate C.toNat 0l (churchHalf 9) --> 4 : ℕ

7. Sorted levels. The Prelude is polymorphic over Level, the finite levels; the levels from ω on are in sorted types of levels. Level@n holds the levels below ω·(n+1), and Level is Level@0; Level@{n} is another spelling of Level@n. A sort is included in every larger one, Level@m ⊆ Level@n for m ≤ n, and every Level@n is in Type@0. The literals beyond 0l, 1l, … are ω, ω + b and ω·a + b, with * the ASCII spelling of ·.

eval ω + 1 : Level@1
output
Evaluate ω+1 --> ω+1 : Level@1
eval maxl 3l (ω·2 + 1) : Level@2
output
Evaluate maxl 3l ω·2+1 --> ω·2+1 : Level@2
eval Level@2
output
Evaluate Level@2 --> Level@2 : Type@0

A finite level is a level of every sort, so the Prelude's levels are levels of Level@1 too.

def liftLevel (u : Level) : Level@1 ≔ u end

eval liftLevel (ofNat 3)
output
Evaluate liftLevel (ofNat 3) --> 3l : Level@1
